Admin templates

Complete, ready-to-use pages built with Orion Admin. Copy a file, point it at your API and you are live. Every page uses the same shared shell (assets/shell.js) so your navigation stays in one place.

Try dark mode — every template follows the theme.
Documentation

How to use a template

  1. Copy the template's .html file plus assets/shell.js and assets/shell.css into your project.
  2. Point the <script src="…/orion.min.js"> tag at the CDN or your copy of the library.
  3. Edit the NAV array in shell.js and replace the demo data with your API calls (Orion.http.get('/api/…')).
