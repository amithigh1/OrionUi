Rating

<o-rating> is a form-associated star (or heart/thumb/custom icon) rating with keyboard support, hover preview, and optional half-star (or finer) precision.

Basic

Fractional precision

precision="0.5" lets the user (and the display) land on half-stars; any finer value like 0.1 also works. A readonly rating can always display an arbitrary fractional average regardless of the interactive precision.

Icons & color

icon: star (default), heart, thumb, or custom with your own icon-on/icon-off SVG markup. color accepts a semantic name or any CSS color.

Labels & clearable

item-labels gives each whole level a name, shown next to the stars while hovering/focused. clearable lets clicking the current value reset it to no rating (also Home with no value floors at 0).

Sizes, readonly, disabled & RTL

Example: product rating in a review form

Host: role="radiogroup"; each level: role="radio" with roving tabindex and aria-checked on the level matching the current value. A visually-hidden live region announces the precise (including fractional) value.
