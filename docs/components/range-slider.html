Range slider

<o-range> is a form-associated slider with a single thumb or, with dual, two independent thumbs for a min/max range. For a plain single-value native slider without a custom element, see .o-range on Form controls.

Single thumb

Dual thumb (min/max range)

With dual, the component submits two form fields: name for the start value and name-end (defaults to name + "End") for the end value. min-distance keeps the thumbs from crossing.

Marks & ticks

marks accepts an array of numbers, {value,label} objects, or a {value:label} map. ticks auto-generates an unlabeled tick at every step.

Formatting the tooltip

format accepts a quick shorthand string (currency:USD, percent, number:1) or a function (value, el) => string for full control.

Vertical

Linked number inputs

The inputs prop two-way binds the slider to one (single mode) or two (dual mode) existing <input> elements — handy for a "type an exact value" pair next to the slider.

Props / attributes

PropTypeDescription

value-start, value-endNumberDual mode (requires dual).
dualBooleanEnables the two-thumb range mode.
min, max, stepNumberDefaults 0 / 100 / 1.
min-distanceNumberMinimum gap between thumbs in dual mode.
marksArray | ObjectSee "Marks & ticks" above.
ticksBooleanAuto tick marks at every step (capped at 200).
formatFunction | String(value, el) => string, or "currency:CODE" / "percent" / "number:digits".
orientationStringhorizontal (default) | vertical.
tooltipStringauto (default, on hover/focus/drag) | always | never.
inputsArray1 (single) or 2 (dual) CSS selectors or elements to two-way sync.
name-endStringForm field name for the end value in dual mode (default name + "End").
size, name, required, disabled, readonly, texts—Standard.
