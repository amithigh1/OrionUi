Idle & Session Timeout

Orion.idle() tells you when the user stops interacting, across every open tab. Orion.sessionTimeout() builds on it: it pings your server while the user is active, shows an accessible countdown before signing out, and keeps every tab in sync — extending in one tab extends all, logging out in one logs out all.

Idle detection

This watcher goes idle after 5 seconds without mouse, keyboard, touch, wheel, scroll or focus activity. Activity in another tab of this page counts too (crossTab: true).

Session timeout warning

A 20-second session with a 10-second warning. Move the mouse to stay active, or wait: the dialog counts down (“Your session will expire in 0:09”), traps focus, announces itself, and offers Stay signed in / Log out. Once the warning is visible, only an explicit choice extends the session. Without an onTimeout handler the dialog shows a “Session expired” state.

      const session = Orion.sessionTimeout({
        timeout: 15 * 60e3,                 // 15 minutes of inactivity
        warning: 60e3,                      // warn during the last minute
        keepAlive: () => fetch('/api/session/ping', { method: 'POST' }),   // throttled, only while active
        onTimeout: ({ reason }) => { location.href = '/login?reason=' + reason; },   // 'timeout' | 'logout' | 'remote'
      });
      session.on('warning', ({ remaining }) => console.log('warning', remaining));

Across tabs

Controllers with the same key talk over a BroadcastChannel (falling back to localStorage events). Activity in any tab keeps every tab alive, Stay signed in closes the dialog everywhere and Log out (or expiry) signs out every tab. Only one tab calls keepAlive per interval. Open this page in another tab, start a session in both, and try it — or simulate the other tab below.

Texts & i18n

Every string can be passed as an option (a string with {time}, or a function) or translated globally with Orion.i18n.add(locale, { session: { … } }).

      Orion.sessionTimeout({
        timeout: 30 * 60e3, warning: 2 * 60e3,
        title: 'Still working?',
        message: 'We will sign you out in {time} to protect your account.',
        stayText: 'Keep me signed in', logoutText: 'Sign out now',
        logoutUrl: '/logout',           // used when there is no onTimeout
      });
      Orion.i18n.add('ms', { session: { title: 'Masih di sana?', message: 'Sesi anda akan tamat dalam {time}.', stay: 'Kekal log masuk', logout: 'Log keluar' } });

Keyboard & accessibility

KeyAction
Tab / Shift+TabCycle between Log out and Stay signed in (focus is trapped; Stay signed in is focused first).
Enter / SpaceActivate the focused button.
EscapeSame as Stay signed in (escape: 'stay', set escape: false to ignore). In the expired state it runs the sign-in action.

The dialog is a role="alertdialog" with aria-modal, labelled by its title and described by the message, so it is announced when it opens. The remaining time is re-announced at 30 and 10 seconds (not every second). While the warning is visible the tab title shows the countdown (titleAlert), so users notice it in a background tab. The countdown and progress bar honour reduced motion.

Frameworks

Create the controller once after login (e.g. in your root component's mount effect) and call destroy() on logout/unmount. Server-side the functions return inert controllers.
