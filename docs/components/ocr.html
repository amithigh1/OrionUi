OCR

This library ships no third-party OCR code. <o-ocr> is a UI shell — image/drop/camera input, drag-to-select a region, progress, an editable result panel — around whatever engine you register with Orion.ocr.use(engine). Every demo on this page runs against the bundled, fully offline fixture engine.

Fixture engine

Pick a bundled sample, then Recognize. The fixture engine matches the image by its data-ocr-fixture id (set here) or by exact pixel size, and returns canned text — everything below works with no network calls.

Region selection

Load the invoice sample, Recognize once, then drag a small box over just the "Total: $75.00" line near the bottom — the result narrows to whatever bundled words fall inside your selection, and re-recognizes automatically. "Clear region" (shown once a region is set) goes back to the full image.

Word boxes & confidence

After recognizing, "Show word boxes" overlays each returned word's bounding box on the image. The confidence badge is colour-coded and labelled with the percentage — never colour alone.

Progress & abort

Recognizing shows a progress bar (three intermediate steps, then done); "Cancel" aborts via the engine's AbortSignal.

Engine registration

Orion.ocr.use() validates engines and throws a clear error for a missing name or recognize(), instead of failing silently later.

Tesseract.js adapter (developer opt-in)

Nothing is fetched by default. To use real OCR, host a Tesseract.js build yourself and register it — see src/components/ocr/README.md and 20-adapters.js for the full contract:

Orion.ocr.use(Orion.ocr.tesseract({
  scriptUrl: 'https://your-cdn/tesseract.min.js',   // you choose/host this — never fetched automatically
  workerOptions: { langPath: 'https://your-cdn/lang-data' },
}));
await document.querySelector('o-ocr').recognize();  // now runs real OCR
