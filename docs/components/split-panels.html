Split panels

<o-split> makes any number of children resizable with pointer, touch and keyboard (WAI-ARIA window splitter). Panes respect min / max sizes, snap to collapsed, restore on double-click or Enter, nest into grids and persist their sizes. <o-split-view> is the responsive list–detail pattern.

Basic

sizes takes percentages; min / max accept px or % for all panes and data-min / data-max per pane. Drag the gutter or focus it and use the arrow keys (Shift for bigger steps).

Three panes & nesting

Use any number of panes, and nest <o-split direction="vertical"> for IDE-style layouts.

Collapsible panes

collapsible (or data-collapsible) lets a pane snap closed when dragged below half its minimum, on double-click of the gutter or with Enter. data-collapsed-size keeps a rail visible. Sizes are remembered with persist.

List–detail split view

<o-split-view breakpoint="md"> shows list and detail side by side when it is at least breakpoint wide (md = 768px by default; this demo uses sm). Narrower, it shows the list; choosing an item ([data-o-item]) slides the detail in with a Back button. hash="mail" keeps the selection in the URL so the browser Back button returns to the list. The second example is forced narrow to show the mobile behaviour.

Frameworks

Render panes as normal children: gutters are inserted between them and re-synced when panes are added or removed. Sizes are applied as inline flex styles, so do not bind style.flex on panes yourself. For <o-split-view> mark the list and detail with slot="list" / slot="detail" and render the detail in response to o-select.
