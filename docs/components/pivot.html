Pivot Table

<o-pivot> summarises records by any combination of row and column fields: drag fields between Rows, Columns, Values and Filters (or use the keyboard), pick the aggregation, filter values, expand and collapse groups, sort by label or value, see subtotals, grand totals and a heatmap, and export the result to CSV or Excel. 100,000 records aggregate in a few dozen milliseconds.

Sales by region × year

Drag a field from the list into a zone, or press Enter on it to choose where it goes. Click a value header to sort rows by that column; click the row field in the corner to sort labels.

Several levels, subtotals & filters

Row and column fields nest to any depth. Group rows show subtotals (turn them off with showSubtotals: false), column groups get a total column, and showTotals adds the grand totals. Date fields also offer derived Year, Quarter and Month fields ('date:year').

Aggregations & custom measures

agg is sum, count, avg, min, max, distinct or a function (values, records) → number — for example a margin that is computed from the underlying records instead of averaged. format accepts number, integer, currency, a currency code, percent, compact, Intl options or a function.

Performance & export

The engine stores accumulators per row × column group in flat typed arrays, so 100,000 records with two row levels and one column level aggregate in a few dozen milliseconds. O.pivot.compute(data, config) runs without the UI (e.g. in a worker). pivot.export('csv' | 'xlsx') writes what is on screen — Excel files get merged, frozen, bold header rows.

config

KeyDescription
rows, columnsArrays of field keys (dot paths and derived 'date:year' | 'date:quarter' | 'date:month' work).
values[{ field, agg, format, label }]; a string means { field, agg: 'sum' }.
filters{ field: [allowed values] }; null keeps a field in the Filters zone without restricting it. filter(record) adds a custom predicate.
sort{ rows: { by: 'label' | 'value', dir: 'asc' | 'desc', value: index, col: [path], level }, columns: { dir } }.
showTotals, showSubtotalsGrand totals and group subtotals (default true).
heatmapColour detail cells with the sequential palette (--o-seq-100 … 700).
collapsed{ rows: [path…], columns: [path…] } — collapsed groups (kept in getConfig()).

CSS variables

--o-pivot-h sets the height of the table area (34rem). Heatmap colours come from --o-seq-100 … --o-seq-700.

Frameworks

Set data and config as properties (React 19, Vue :data, Angular [data]); React 18 can pass JSON strings. Listen to o-change to persist the layout.
