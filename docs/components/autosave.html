Autosave

Orion.autosave(form, options) (or data-o-autosave="key") saves a form's values automatically as the visitor types, restores drafts on return, and gives you a status indicator and an unload warning — with zero server required (local/session storage or IndexedDB), or wire onSave to send drafts to your backend.

Realistic example: profile form with autosave

Type into any field — the status indicator below the form updates after a short (500ms) debounce. Reload this page and you'll see the restore banner (a draft was pre-seeded for this demo).

Storage backends & excluding fields

storage: 'session' keeps the draft only for the current tab session; exclude keeps sensitive fields out of the saved draft entirely (password and file inputs are always excluded automatically).

Unload warning

Pass warn: true (or the data-o-autosave-warn attribute) to prompt the browser's native "leave site?" dialog while there are unsaved changes. It isn't demoed live on this page (it would interrupt browsing the docs) — wire it exactly like the other options:

<form data-o-autosave="checkout" data-o-autosave-warn>…</form>

API

OptionDescription
keyStorage key suffix (defaults to the form's id/name/the page path).
storage'local' (default) · 'session' · 'idb' (falls back to local if IndexedDB is unavailable).
delayDebounce in ms, default 800.
restore'prompt' (default, shows a banner) · 'auto' · false.
excludeArray of field names to never persist.
warnbeforeunload warning while dirty, default false.
maxAgeMilliseconds; a draft older than this found on load is discarded.
onSave(data, form)Makes saves remote; retried with backoff and offline-aware.
onRestore(data, meta) / onDiscard()Callbacks for the restore banner's actions.
MemberDescription
save(opts?) / restore(record?) / discard()Manual control; save({ force, manual }).
clear()Forgets the draft and treats the current values as the new baseline (called automatically after a successful submit or reset).
isDirty / lastSaved / draftGetters.
destroy()Removes listeners.
o-autosave / o-restore / o-discard / o-autosave-errorEvents fired on the form.

Declarative attributes: data-o-autosave="key", data-o-autosave-storage, data-o-autosave-delay, data-o-autosave-restore, data-o-autosave-warn, data-o-autosave-exclude="a,b", data-o-autosave-onsave="globalFnName", a status element via [data-o-autosave-status] (optionally scoped to one key: data-o-autosave-status="key"), and a manual save button via data-o-action="save-draft".
