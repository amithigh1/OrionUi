Virtual List

<o-virtual-list> renders only the rows near the viewport — however many items the array holds — so a list of 100,000 people scrolls exactly like a list of ten. Fixed or auto-measured row heights, sticky group headers, horizontal strips, auto-fit grids and listbox keyboard selection, in one dependency-free element.

Overview

Give it items (an array) and a renderItem(item, index) function that returns a Node or an HTML string; only the rows near the visible window are ever created. Size the element with CSS (default 24rem tall) — it also works as a flex child, shrinking correctly inside a card body.

100,000 rows — variable height & sticky letter headers

Set item-height="auto" to let each row size itself (measured with a ResizeObserver and cached); group-by flattens already-sorted data into group-header rows and keeps the current letter pinned to the top as you scroll, pushed off by the next one. Try scrolling, or jump straight to a row.

Grid mode

Set grid to lay items out in auto-fit columns (min-column-width, or an explicit columns) instead of one column per row — the same recycled-node windowing applies to the cells.

Horizontal

Set horizontal to virtualize a wide strip instead of a tall column — item-width replaces item-height.

Listbox keyboard selection

Set selectable="single" or "multiple" to turn the list into a role="listbox": focus stays on the list itself and moves a virtual (aria-activedescendant) cursor with the arrow keys — the standard pattern for a composite widget whose rows come and go from the DOM. Click, or press Enter / Space, to (de)select.

Events & methods

Keyboard

KeyAction
↓ / ↑Move the active row by one (by one grid row / column in grid mode).
← / →Move by one item — grid and horizontal modes.
Home / EndFirst / last item.
Page Down / Page UpMove by one viewport's worth of rows.
Enter / Spaceselectable: toggle the active item.

ARIA: the host is a listbox (or grid when grid is set) with aria-activedescendant pointing at the currently focused row's id; rows are options with aria-selected. Group headers are role="presentation" (decorative dividers, not part of the option list).

CSS variables & classes

Parts: .o-vlist-row (.o-vlist-group for headers, .is-active, [aria-selected]), .o-vlist-cell (grid), .o-vlist-sticky. The host has no default block size beyond 24rem — size it with ordinary CSS (height, flex, block-size), including 100% of a flex parent.

Orion.virtualList()

Orion.virtualList(container, options) → <o-virtual-list> — creates (or configures, if container already is one) the element; options.on attaches listeners (o- prefix optional).
