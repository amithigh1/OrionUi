Password

Behaviors for a plain <input type="password">: a show/hide toggle, a cryptographically-random generator, a Caps Lock warning, and a pattern-aware strength meter. The input stays the real form field throughout.

Show / hide toggle

Wrap the input in .o-input-wrap (created automatically if missing) and add data-o-password-toggle.

Generate a strong password

data-o-password-generate="20" adds a button that fills the field with a random password (crypto.getRandomValues, guarantees at least one of each enabled character set). Pass JSON for options: data-o-password-generate='{"length":24,"symbols":false}'.

Strength meter

data-o-strength renders a 5-bar meter and a checklist under the field. The estimator is pattern-aware: common passwords, dictionary words, sequences (abc, 987), keyboard walks (qwerty), repeats and dates all cost fewer bits of entropy than random characters. data-o-strength-min="2" makes the field invalid below "Fair". data-o-strength-rules customises the checklist (default length:8,upper,lower,number,symbol,common,repeat); data-o-strength-user="#name,#email" penalises passwords containing the user's own name or email.

Caps Lock warning

Shown automatically under any toggle/strength field while typing with Caps Lock on. Focus the field below and press Caps Lock to see it (disable with data-o-capslock="false").

JS API

Attributes

AttributeDescription
data-o-password-toggleAdds the show/hide button.
data-o-password-generate="16" | '{...}'Adds the generate button; a number sets length, or pass JSON options (see Orion.password.generate).
data-o-strengthRenders the strength meter and checklist after the field.
data-o-strength-rulesComma list, e.g. length:12,upper,lower,number,symbol,common,repeat.
data-o-strength-minMinimum acceptable score (0-4); below it the field is invalid.
data-o-strength-checklist="false"Hide the rules list, keep only the bar.
data-o-strength-target="#el"Render the meter into an existing element instead of after the field.
data-o-strength-user="#name,#email"Comma list of selectors whose values penalise the score when reused in the password.
data-o-capslock="false"Disable the Caps Lock hint for a field.

MemberDescription
