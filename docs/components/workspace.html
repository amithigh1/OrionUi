Workspace tabs

<o-workspace> is a multi-document tab strip like a browser or IDE: icons, dirty dots, pinned tabs, middle-click close, a context menu (Close, Close others, Close to the right, Close all, Pin, Duplicate), drag reordering, an overflow list, keep-alive panes, confirmation before closing unsaved work and restoring open tabs on reload.

Editing documents

Type in a document to mark it dirty (●); closing it asks for confirmation. Right-click a tab (or press Shift+F10) for more actions. Switching tabs keeps each pane alive — scroll position, text and iframes are preserved. Reload the page: open tabs come back (persist + resolver).

Opening tabs from code

Descriptors are plain objects. Supply content as a Node or text, trusted html, a lazy render(tab) function (called on first activation) or a url (iframe). Opening an existing id focuses that tab. With persist, only serializable fields are stored (id, title, icon, pinned, url, data); the resolver property rebuilds the content of restored tabs, or listen to o-render.

      const ws = document.querySelector('o-workspace');
      ws.resolver = d => ({ render: () => buildEditor(d.data.fileId) });   // rebuild restored tabs
      ws.confirm = tab => myDialog.ask(`Discard changes to ${tab.title}?`);  // optional custom confirmation
      ws.open({ id: 'file-42', title: 'report.md', icon: 'file', data: { fileId: 42 }, render: tab => buildEditor(42) });
      ws.setDirty('file-42', true);
      ws.addEventListener('o-close', e => { if (e.detail.reason === 'max') e.preventDefault(); });
      await ws.close('file-42');           // resolves false when the user keeps the tab

API

Attribute / propertyTypeDescription
persiststringSave open tabs and the active one (orion:workspace:<key>); restored automatically or with restore().
maxnumberMaximum open tabs; the least recently used clean, unpinned tab closes first (o-close with reason: 'max').
labelstringaria-label of the tab list.
resolver(tab) => Node | { content, html, render, url }Rebuilds content for restored tabs.
confirm(tab) => boolean | Promise<boolean>Custom confirmation for dirty tabs (default: Orion.confirm when present, else window.confirm).
[slot="empty"] child—Shown when no tab is open (a default empty state otherwise).

Events

EventDetailDescription
o-open{ tab }A new tab was created.

Frameworks

The workspace owns its tab and pane elements, so drive it through the API: call open() from your router or store, and render framework components into e.detail.pane in o-render (unmount them in o-close). Panes are never moved, so component state survives switching.
