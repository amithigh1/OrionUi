Compare

Collect a handful of items with Orion.compare, pick them via data-o-action="compare" buttons, review the running selection in a sticky <o-compare-tray>, and line their attributes up with <o-compare-table>.

Tray + table

Add a few products to compare. The tray is a sticky bar (scoped to this demo box here — normally you'd place it once at the end of your page body); pressing "Compare" reveals the table below it.

Differences & best value

The toolbar toggles "Highlight differences" (tints rows that differ) and "Only show differences" (hides rows that don't). Numeric rows mark the best value automatically (best: 'low' for price, 'high' for rating).
