Global Search

<o-global-search> is the search box that usually lives in an app header: it expands into a floating panel of results grouped by category, coming from one or more async providers. It remembers your search history and shows recent items, favorites and suggested queries when the box is empty, and turns full-screen on phones.

Providers

Focus the box below (or press / anywhere on the page) and type. Each provider is { id, title, icon, limit, search(query, { signal }) }; results are { id, title, subtitle, url, icon, avatar, meta, badge }. A category with more matches than its limit gets a See all row.

Empty state: history, recent, favorites & trending

With an empty query the panel shows, in order: recent searches (removable, with a Clear history link), favorites and recent items from Orion.favorites/Orion.recent when that package is loaded (a built-in localStorage fallback is used otherwise), and any trending suggested queries you configure. Try searching for something above, close the panel, then re-open it — your search is remembered.

Provider & result shapes

      interface Provider {
        id: string; title: string | (() => string); icon?: string; limit?: number /* 5 */;
        search(query: string, ctx: { signal: AbortSignal }): Promise<Result[]>;
        seeAllHref?: string | ((query: string) => string);
        onSeeAll?(query: string): void;
      }
      interface Result {
        id: string; title: string; subtitle?: string; url?: string; icon?: string; avatar?: string;
        meta?: string; badge?: string | number; onSelect?(item: Result): void;   // called instead of navigating to `url`
      }

KeyAction
