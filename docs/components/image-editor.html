Image editor

<o-cropper> is a full crop box (8 handles, aspect presets, round mode, zoom, rotation, flip) with a live preview target, Orion.image is a set of canvas helpers (compress, resize, rotate, flip, crop, filters, EXIF orientation), and Orion.cropImage(file, opts) combines both into a one-line modal editor.

Crop box

Drag the box or its 8 handles, drag inside to pan, scroll / pinch to zoom, or use the toolbar. The preview on the right updates live from o-crop.

Round mode (avatar cropper)

round clips the crop area (and the output canvas) to an ellipse — perfect for avatars. EXIF orientation in portrait.jpg is corrected automatically.

Methods & export

Every editing action is a method, and the crop can be exported as a canvas, blob or data URL at any resolution.

Orion.image helpers

Canvas helpers that accept a File, Blob, URL, <img> or <canvas> and return a Promise. compress() iterates quality (then size) until the result fits maxSizeKB, and reports before/after sizes on .report.

Orion.cropImage(file, opts)

A one-line modal cropper for upload flows: opens a dialog around <o-cropper> and resolves the cropped Blob (or null if cancelled). Uses Orion.modal when it is loaded, otherwise its own dialog on the core overlay stack.

Frameworks & accessibility

The crop area is a focusable role="application" region with a live-updating accessible label (current size), and every toolbar control has a label and a tooltip. preview accepts any selector so multiple live previews (e.g. an avatar and a banner) can watch the same cropper.
