Gauges & sparklines

Single numbers against a limit and tiny inline trends: gauges with a target and status bands, progress rings, <o-sparkline> (line, area, bar, win/loss) and KPI tiles that pair a figure with its trend.

Gauge with target & bands

Bands tint the track with a lighter step of their color; with status bands the value arc takes the color of the band it falls in ("the fill carries severity"), and the status is always spelled out below the figure — never color alone. The target is a tick across the arc.

Semicircle, needle & plain gauges

gauge.arc sets the sweep (90–300°, default 240), gauge.needle draws a needle instead of the center figure, and without bands the track is a light step of the value's own hue.

Progress ring

A full ring whose track is a lighter step of the same hue. Values are shown as a percentage of progress.max (default 100).

Sparklines

<o-sparkline values="…"> draws an inline trend sized by CSS (default 6rem × 1.75rem). By default the trend wears the de-emphasis gray and the current period the accent; set color (slot number, token or CSS color) to paint it all. Hover for values; screen readers get a spoken summary.

KPI tiles

The stat-tile contract: label (sentence case) · value (proportional figures, auto-compact) · signed delta against a named period · a 12-point trend. Build it from the .o-stat classes and Orion.sparkline().
