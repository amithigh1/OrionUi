Biometric / Passkeys

Orion.webauthn wraps navigator.credentials with base64url conversion, accepting the WebAuthn Level 3 JSON option format most server SDKs already produce. <o-biometric-login> is a ready-made button with idle/waiting/success/failed/unsupported states. The real signature check must happen server-side — this only collects the ceremony result.

Support in this browser

<o-biometric-login>

Headless Chrome (used for automated testing of this page) has no authenticator, so the button below always ends in failed unless you mock navigator.credentials — which is exactly how this package's own tests drive the state machine. Click it to see the waiting → failed transition, then "Try again".

Testing without a real authenticator

Mock navigator.credentials.get / .create to exercise every state without a physical key or platform authenticator:

      navigator.credentials.get = async () => ({
        id: 'cred1', rawId: new Uint8Array([1,2,3]).buffer, type: 'public-key',
        response: { clientDataJSON: new TextEncoder().encode('{}').buffer, authenticatorData: new Uint8Array(37).buffer, signature: new Uint8Array(8).buffer, userHandle: null },
        getClientExtensionResults: () => ({}),
      });
      document.querySelector('o-biometric-login').authenticate({ challenge: 'AA', rpId: 'localhost' });
