Select

<o-select> replaces the native select with a searchable, keyboard-friendly dropdown: single or multiple values (chips or a count), groups, icons, avatars and descriptions, remote search with infinite scroll, virtual scrolling for 10k+ options, creatable tags, custom templates and native form participation.

Basic

Options come from <option> / <optgroup> children (read again when they change) or from the options property. The search box appears automatically for more than 8 options (searchable forces it on, searchable="false" off). Type a letter on a closed select to jump to the next matching option.

Multiple

Add multiple for chips (Backspace removes the last one). display="count" shows “3 selected” instead, max caps the selection and the Select all / Clear bar can be hidden with select-all="false". The form value is submitted as one entry per value.

Groups, icons, avatars & descriptions

Options are objects { value, label, description, icon, avatar, disabled, group } (plain strings work too). avatar takes an image URL or a name (initials in a stable colour); icon takes any Orion icon name.

10,000 options (virtual scrolling)

Lists above virtual-threshold rows (150 by default) render only the visible rows, so 10k+ options open, filter and scroll instantly. Rows must share a height per type (plain / with description / group header).

Remote search & infinite scroll

Set source = async (query, { page, signal }) => ({ options, hasMore }) (or return an array). Requests are debounced (debounce, 250 ms), aborted when the query changes, cached per query, and the next page loads when the list is scrolled to the end. Loading, empty and error states (with Retry) are built in. The example searches 500 users on a fake server with 400 ms latency.

Loading from a URL

url with a {q} (and optional {page}) placeholder queries the server on every search, e.g. /api/users?q={q}&page={page}. Without {q} the JSON is fetched once — lazily, on first open — and filtered locally. Responses may be an array or { options | items | results | data | rows, hasMore | total }; map fields with fields.

Tags & creatable

tags turns the control into a free-form tag input (multiple + creatable): Enter, comma or semicolon adds a tag, pasting “a, b, c” adds several and Backspace removes the last. creatable adds an “Add …” option to the search results of a normal select. Both fire a cancelable o-create — listeners may validate or rewrite detail.value / detail.label.

Custom templates

renderOption(option, { query, selected, disabled }) and renderValue(option, { chip }) return an HTML string or a Node. option.raw is your original object. Escape user data (Orion.util.esc / Orion.util.html).

Sizes & states

Enhancing a native select

<select data-o-select> renders an <o-select> next to the native element and keeps both in sync — the native select stays in the form, submits the value and shows the browser's validation bubble, so server-rendered forms keep working. A leading empty option becomes the placeholder; options go in the attribute value as JSON or as data-o-select-* attributes.

Forms & validation

<o-select> is form-associated: it has a name, participates in FormData, required validation, :invalid, reset and disabled fieldsets. Invalid controls get a red border after the first submit or blur.

Inside dialogs & scrolling containers

Panels are portaled to <body> (or into the open native <dialog>, so they stay in the top layer), follow their control while scrolling, flip when there is no room below, and close together with their parent overlay. On phones they become bottom sheets.

Frameworks

Set options, value, source and the render functions as properties (React 19, Vue :options, Angular [options]); with React 18 pass arrays as JSON strings. Listen to o-change (Vue @o-change, Angular (o-change), React via a ref). Children rendered later by a framework are picked up automatically.

// React 19
<o-select ref={ref} name="owner" options={users} value={owner} clearable />
useEffect(() => { const el = ref.current; const f = e => setOwner(e.detail.value); el.addEventListener('o-change', f); return () => el.removeEventListener('o-change', f); }, []);
