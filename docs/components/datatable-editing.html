Data Table: editing & selection

Edit cells in place with validation and an async save hook, edit whole rows, select with click, Shift-ranges or Ctrl, run bulk actions on the selection and add per-row actions.

Inline cell editing

Double-click a cell, or focus it and press Enter / F2. Enter saves, Esc cancels, Tab saves and moves to the next editable cell. Edited cells get a corner marker; Ctrl+Z undoes the last edit. onSave(row, changes) may be async — throw (or return false) to roll back.

Row edit mode

With edit-mode="row" an Edit action (or double-click / Enter) turns every editable cell of the row into an editor with Save and Cancel. All fields are validated before onSave(row, changes) runs once with every change.

Selection & bulk actions

Add selectable for a checkbox column. Click a checkbox, Shift+click for a range, Ctrl+click a row to toggle it, Space on a focused row, Ctrl+A for everything. The header checkbox selects the page and offers Select all N results. Selection is kept across pages by row id (row-key, default id). bulkActions appear in a bar with the count.

Row actions

rowActions adds an actions column. Up to two actions (or those with inline: true) render as icon buttons; the rest go into a “⋯” menu (Orion.menu when available, otherwise a built-in menu). confirm asks first (Orion.confirm or a built-in popover); hidden(row) and disabled(row) control per-row state.
