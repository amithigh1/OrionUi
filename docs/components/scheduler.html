Scheduler

Set view="resource-day", resource-week or resource-month on <o-calendar> to get a resource timeline: a sticky column of rooms, staff or equipment on the left and a scrollable time axis across the top. Bookings on the same resource that overlap are flagged as conflicts, and a resource's capacity is checked against an event's attendees.

Meeting-room scheduler

Five rooms grouped by floor. Drag a booking to another room or time, drag its edges to change its length, drag on empty space to create a new booking, and hold Ctrl and scroll (or pinch) to zoom the timeline. The double-booked slot on Room A and the over-capacity workshop on the Boardroom are highlighted automatically.

Resource week & zoom

resource-week shows a full week per resource; resource-month collapses each day to a single column (good for equipment or vehicle bookings that span days). The toolbar's zoom buttons (or zoomBy(n)) step through 5 zoom levels.

API

Resource views use the same <o-calendar> API as Calendar — see its full prop, event and method tables. The additions specific to resource scheduling are below.

Prop / attributeTypeDescription
resourcesarray{ id, title, subtitle, color, capacity, group, avatar }[] — one row per resource, grouped by group when present.
viewstringresource-day · resource-week · resource-month.
conflictsbooleanOutline overlapping bookings on the same resource in red (default on).
zoomnumber0–4; also zoomBy(n) and Ctrl/Cmd+scroll on the timeline.

Events assigned to a resource set resourceId to match a resource's id; events with no matching resource are grouped into an "Unassigned" row. An event's capacity check compares resources[].capacity against event.attendees.length (or a numeric event.attendees / event.guests), showing an over-capacity badge and tooltip.
