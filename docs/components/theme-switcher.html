Theme & Language Switchers

<o-theme-switch> is a small control bound to Orion.theme (light/dark/auto, plus optional high-contrast and text-size steppers). <o-lang-switch> lists the locales registered with Orion.i18n.add() and switches with Orion.i18n.set(). Both update live and reflect external changes (e.g. the docs site's own theme button in the header).

CSS

.o-theme-switch, .o-lang-switch and their variant sub-elements — see the source for the full class list. Both reuse core control classes (.o-btn, .o-segmented, .o-select, .o-switch, .o-floating) so they inherit any theme customization automatically.

Frameworks

Both elements have no props that need to be set from JavaScript for the common case — attributes are enough. They listen for Orion.theme.onChange() / the global locale bus internally, so external changes (another switcher, a keyboard shortcut, a saved preference restored on boot) keep every instance on the page in sync without any wiring.
