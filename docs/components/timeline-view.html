Timeline view

<o-timeline-view> lays items — ranges, points and background bands — on an adaptive time axis (minutes to centuries), stacked automatically inside optional nested, collapsible lanes. Pan and zoom with a mouse, wheel, touch pinch or the keyboard; drag to move or resize editable items; dense points cluster and expand on demand. For a project plan with dependencies and a task tree, see Gantt chart; for CSS-only activity feeds, see Timeline & Stats.

Team activity

Incidents, deployments and on-call shifts across three teams. Groups can nest (each team has a sub-lane for on-call); drag an editable item to move it, drag its edges to resize a range, and shift-drag the background to zoom into a period. o-item-change is cancelable — this demo refuses to move an item into the past.

Pan & zoom

The toolbar's zoom buttons and Fit all, Ctrl/pinch to zoom around the pointer, drag the background to pan (with inertia), or hold Shift and drag to draw a box that zooms straight to that range. The axis adapts its unit automatically — from minutes up to centuries — as you zoom.

Item types & clustering

Three item types: range (has end), point (a single instant) and background (a shaded band behind everything, never selectable). Dense points within ~26px of each other cluster into a count bubble; double-click (or Enter) a cluster to zoom into it.

Frameworks

Set items/groups as properties (React 19, Vue :items, Angular [items]) and listen for o-item-change to write edits back to your store; getItems()/getGroups() return plain JSON-safe objects (dates as real Date instances). Reassigning items re-normalizes the model but keeps the current window and selection.

      <!-- Vue -->
      <o-timeline-view :items="items" :groups="groups" editable @o-item-change="save($event.detail)" />
      <!-- Angular -->
      <o-timeline-view [items]="items" (o-select)="onSelect($event.detail)"></o-timeline-view>

Events

EventCancelableDetail
o-item-change✓{ item, changes, previous, revert() } — a user drag (move/resize) or the Alt+arrow keyboard nudge. revert() undoes just this change later.
o-item-click{ id, item, originalEvent }
o-item-dblclick{ id, item, originalEvent }
o-select{ ids, items } — click, Ctrl/Shift-click or Enter. Not fired by setSelection().
o-range-change{ start, end } — the visible window changed (pan, zoom, setWindow/fit/moveTo without { silent: true }).
o-group-collapse / o-group-expand{ id, group } — a lane toggle, including toggleGroup()/collapseGroup()/expandGroup().

CSS variables

--o-tv-h, --o-tv-range, --o-tv-point, --o-tv-now, --o-tv-weekend, --o-tv-sel, --o-tv-brush. A per-item color overrides --o-tv-color on that item only.

Keyboard

The chart is a focusable role="region"; arrow keys move focus between items (chronologically) and recenter the view, without changing the selection until Enter. Changes are announced to screen readers.

KeysAction
→ / ←Focus the next/previous item and recenter the view on it (or pan when there are no items).
Home / EndFocus the first/last item.
EnterToggle-select the focused item.
Alt + ← / →Move the focused item one snap unit earlier/later (when editable).

+ / −Zoom in/out.
0Fit all items.

Ctrl/Cmd + wheel, or pinchContinuous zoom around the pointer.
