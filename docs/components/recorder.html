Recorder

<o-audio-recorder> and <o-video-recorder> wrap MediaRecorder with pause/resume, a live level meter and waveform (audio) or camera/screen preview (video), a duration limit that auto-stops, playback and download. <o-video-recorder source="both"> composites a screen share with a rounded camera picture-in-picture and mixes both audio tracks.

<o-audio-recorder>

Form-associated — its value is the recorded File. max-duration (in seconds) auto-stops and shows a progress bar; level-meter/waveform (both default on) visualize the input in real time.

<o-video-recorder>

source selects camera (default), screen (getDisplayMedia) or both. Stopping the browser's native "stop sharing" control also stops the recording.

<o-video-recorder source="camera"></o-video-recorder>
<o-video-recorder source="screen"></o-video-recorder>
<o-video-recorder source="both"></o-video-recorder>   <!-- screen + camera PiP, composited on canvas -->

No microphone/camera at all: the stream property

Set stream to a MediaStream-like value and start() records it directly, skipping getUserMedia()/getDisplayMedia() entirely — a real MediaRecorder round trip with no hardware. This demo feeds <o-audio-recorder> a silent oscillator tone and <o-video-recorder> a plain animated canvas.captureStream().

JavaScript API

Orion.recorder.audio({ maxDuration, deviceId, title, size }) -> Promise<File | null>   // modal helper
Orion.recorder.video({ source, maxDuration, facing, title, size }) -> Promise<File | null>

Accessibility

Recording/paused/saved/discarded states are all announced via announce(); permission and hardware failures are shown as readable text with a retry button where retrying makes sense, not just an icon.

Limitations

  • Every mode requires a secure context (HTTPS or localhost); source="screen"/"both" additionally require getDisplayMedia support.
  • MediaRecorder output format depends on the browser (Chromium: WebM/VP9+Opus by default); pass format to force a specific mimeType your support matrix requires.
  • A stream fixture bypasses the composite/mix logic for source="both" — it records whatever single stream is assigned, unmixed.
