Undo / Redo

Orion.UndoManager records commands (do / undo) with merging of rapid edits, batching into single steps, a size limit and Ctrl Z bindings. Orion.undoable(form) makes any form undoable and <o-undo-controls> adds buttons with a history menu.

A small editor

Every change goes through execute(). “Add 3 samples” is one batch(); dragging the hue slider is merged into one step (merge: true within mergeWindow). Press Ctrl Z / Ctrl Y (⌘ Z / ⌘ ⇧ Z on Mac) inside the editor.

Undoable forms

Orion.undoable(form) tracks text fields (typing grouped per field), selects, checkboxes, radio groups, contenteditable and Orion form controls. Resetting the form is a single undoable step. The form's id registers the manager, so <o-undo-controls for="profile"> just works.

Commands, merging & batches

      const um = new Orion.UndoManager({ id: 'canvas', limit: 100, mergeWindow: 800, onChange: ({ canUndo, canRedo }) => toolbar.update(canUndo, canRedo) });

      // execute() runs do() and records the command
      um.execute({ label: 'Add shape', do: () => shapes.add(s), undo: () => shapes.delete(s) });

      // push() records something that already happened (e.g. a drag that just ended)
      um.push({ label: 'Move shape', undo: () => s.moveTo(from), do: () => s.moveTo(to) });

      // merge rapid commands: compose (true) or absorb into the previous command (function)
      um.push({ label: 'Resize', mergeKey: 'resize:' + s.id, merge: true, undo, do });
      um.push({ el, from, to, merge(prev) { if (prev.el !== this.el) return false; prev.to = this.to; return true; }, undo() { … }, do() { … } });

      // batch: many commands -> one history entry (async works; errors roll back)
      await um.batch('Paste 12 shapes', async () => { for (const s of pasted) um.execute(addCmd(s)); });
      const end = um.batch('Drag'); /* … */ end();

      um.undo(); um.redo(); um.goto(3); um.canUndo; um.history; um.clear();
      const unbind = um.bind(document);   // mod+Z · mod+Shift+Z · mod+Y

Keyboard

KeyAction
Ctrl+Z / ⌘ZUndo (inside the bound element; bind(document) leaves native undo alone in text fields unless allowInInputs).
Ctrl+Y · Ctrl+Shift+Z / ⌘⇧ZRedo.
History menu: ↑ ↓ Home End · EnterMove and jump to a history state; Escape closes.

Undo and redo are announced to screen readers (“Undone: Add ‘Plan sprint’”). Buttons use aria-disabled so focus is never lost when the last step is undone.

Command

FieldDescription
undo()Required. Revert the change (may return a Promise).

labelShown in menus, tooltips and announcements.
merge · mergeKeytrue composes with the previous command of the same mergeKey (or label); a function (prev) => boolean absorbs this command into prev.

Orion.undoable(formOrField, options) → UndoManager

Options are UndoManager options plus manager (use an existing one), bind (default true) and id (defaults to the element id). Add data-o-undo-ignore to skip a field. The returned manager gains untrack(); destroy() also stops tracking.
