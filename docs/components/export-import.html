Export & Import

Download any array of rows as CSV, Excel (.xlsx), a PDF report, JSON or HTML with one call, and bring data back in from CSV, TSV, Excel or JSON — with a guided wizard that maps columns, validates every cell and lets users fix errors. Everything is hand-written: an RFC 4180 CSV engine, a ZIP writer/reader, a SpreadsheetML writer/reader and a PDF 1.4 generator. No libraries.

Overview

O.export.csv / tsv
UTF-8 BOM for Excel, RFC 4180 quoting, formula-injection guard.
O.export.xlsx
Typed cells, number formats, bold header, frozen row, autofilter, auto widths, multiple sheets.
O.export.pdf
Report layout: title, logo, generated date, repeating table header, totals, “Page 1 of N”.
O.importFile / Orion.importWizard
Auto-detects CSV, TSV, XLSX and JSON; maps, converts and validates.

Export rows

Every helper takes the rows and an optional columns list, triggers a download and resolves with the Blob. Columns use key (dot paths work), title, type and an optional format(value, row).

Columns, types & formatting

type keeps values native where the format supports it (Excel numbers, dates and booleans with proper number formats) and formats them for CSV-to-humans, PDF and HTML. A format function wins for display formats; pass raw: true to write raw values to CSV.

      Orion.export.xlsx(orders, {
        filename: 'orders-{date}',               // {date} -> 2026-09-11
        sheetName: 'Orders',
        columns: [
          { key: 'id', title: 'Order', type: 'integer' },
          { key: 'customer.name', title: 'Customer' },          // dot path
          { key: 'total', title: 'Total', type: 'currency', currency: 'EUR' },
          { key: 'discount', title: 'Discount', type: 'percent', decimals: 1 },
          { key: 'placed', title: 'Placed', type: 'datetime' },
          { key: 'paid', title: 'Paid', type: 'boolean' },
          { key: 'weight', title: 'Weight', format: '0.0 "kg"' },  // any Excel number format
          { key: 'status', title: 'Status', format: v => v.toUpperCase() },
        ],
      });

Large data

Exports yield to the browser between chunks, so 50,000 rows never freeze the page. Watch the spinner keep turning while the file is built.

CSV parser

O.csv.parse(text, options) follows RFC 4180: quoted fields, escaped quotes, embedded line breaks, CRLF/LF/CR, a UTF-8 BOM and automatic delimiter detection among , ; tab |. dynamicTyping converts numbers, booleans and ISO dates while keeping codes such as 007 as text. For big files use O.csv.parseAsync(file), which streams the file and yields to the UI.

      const { rows, fields, errors, meta } = Orion.csv.parse(text, { delimiter: 'auto', header: true, dynamicTyping: true, comment: '#' });
      const csv = Orion.csv.stringify(rows, { columns: [{ key: 'name', title: 'Name' }], delimiter: ';', bom: true, quote: 'auto' });
      // streaming: rows arrive in chunks, memory stays flat
      await Orion.csv.parseAsync(file, { onChunk: (rows, meta) => store.add(rows), chunkSize: 5000, onProgress: r => bar.value = r });

Import a file

O.importFile(file) detects the format from the content (ZIP → Excel, JSON/NDJSON, otherwise CSV/TSV with delimiter sniffing), decodes UTF-8, UTF-16 and Windows-1252 text and returns every sheet. With columns the fields are mapped and converted for you.

Import wizard

Orion.importWizard(options) opens a guided dialog: upload (drag & drop, browse or paste rows from Excel), sheet choice for workbooks, column mapping (auto-matched by key, title, aliases and fuzzy matching), a review with every invalid cell highlighted and fixable in place, then import with progress. It resolves with the imported rows, or null when cancelled. Try it with the sample CSV or sample workbook — they contain a bad email, a missing name, a duplicate, an unknown department and a non-numeric salary.

Keyboard

Tab / Shift+TabMove between controls (focus is trapped inside the dialog).

Lower-level helpers — Orion.importer

The wizard's Map and Review steps are built on three standalone functions, exposed as Orion.importer for building a custom import flow: autoMap(fields, columns) guesses a field→column mapping, coerce(value, column) converts and validates one raw cell against a ColumnDef, and validate(rows, mapping, columns) runs coerce over every row.

ZIP & Excel engines

The building blocks are public. O.zip writes and reads archives (deflate through the native CompressionStream, CRC-32, UTF-8 names, data descriptors, ZIP64 reading). O.xlsx writes and reads SpreadsheetML directly.

O.export.html(rows, opts)Standalone, print-friendly HTML document.
O.export.clipboard(rows, opts)Copies tab-separated text (pastes into Excel/Sheets). Resolves with the text.

O.export.tableHTML(rows, opts)Escaped <table> markup for the rows (tableClass).

Frameworks

These are plain functions: call them from event handlers in React, Vue or Angular. Pass { download: false } to upload the Blob instead of saving it.
