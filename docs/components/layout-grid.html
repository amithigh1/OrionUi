Layout & Grid

A mobile-first, 12-column flexbox grid (Bootstrap-compatible naming), a CSS-grid system, containers and composition primitives. All class names use the o- prefix, so they never clash with other CSS.

Breakpoints

InfixMin widthTypical device
(none)0Phones (portrait)
sm576pxPhones (landscape)
md768pxTablets
lg992pxLaptops
xl1200pxDesktops
xxl1400pxLarge desktops

Responsive classes apply at the breakpoint and up: .o-col-md-6, .o-d-lg-none, .o-text-md-center, .o-mt-lg-4, .o-grid-cols-xl-4.

Containers

.o-container is centered with responsive max-widths. .o-container-fluid is always full width, and .o-container-{bp} is full width until the breakpoint.

12-column grid

Gutters, offsets, row columns

Gutter scale: .o-g-0 … .o-g-5 (0, .25, .5, 1, 1.5, 3rem), separately .o-gx-* / .o-gy-*, all responsive (.o-g-md-4).

CSS grid

.o-grid with .o-grid-cols-{1-12} (responsive) and .o-span-{1-12|full}. Set the gap with --o-gap or .o-gap-*.

Auto-fit cards

.o-grid-auto fills rows with as many columns as fit, each at least --o-min (default 16rem) wide. No breakpoints are needed.
