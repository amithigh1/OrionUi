PDF Generator

new Orion.PDF() writes real PDF 1.4 files in the browser (and in Node): wrapped and justified text with exact Helvetica/Times metrics, shapes, JPEG and canvas images, links, headers and footers with “Page 1 of N”, and data tables that break across pages with a repeating header. Coordinates start at the top-left corner.

Your first document

      const pdf = new Orion.PDF({ size: 'A4', orientation: 'portrait', margin: 48, title: 'Invoice 1042' });
      pdf.text('Hello, PDF!', 48, 48, { size: 26, bold: true, color: '#4f46e5' });
      pdf.rect(48, 120, pdf.contentWidth, 90, { fill: '#eef2ff', radius: 10 });
      pdf.text(longText, 64, 136, { maxWidth: 400, align: 'justify' });
      await pdf.save('hello.pdf');          // or: const blob = await pdf.toBlob();

Text & shapes

Standard fonts Helvetica, Times and Courier with bold and italic; alignment, justification, line height, underline, strike-through, rotation and opacity; lines, dashed lines, rectangles with rounded corners, circles, ellipses and polygons.

Images

JPEG bytes and data:image/jpeg URLs are embedded as-is (DCTDecode). Canvases, <img> elements, ImageBitmaps and PNG files are converted to RGB with a soft mask for transparency (FlateDecode). URLs and Blobs are fetched while the file is generated; pass width and/or height (aspect ratio is kept) and fit: 'contain' | 'cover'.

Tables across pages

pdf.table() measures columns (or uses width / columnWidths, numbers or percentages), wraps cell text, repeats the header on every page and right-aligns numbers. header and footer callbacks run for every page when the file is written, so page counts are exact. Use await pdf.tableAsync() for thousands of rows.

One-call report

Orion.export.pdf(rows, options) builds a complete report: logo, title, subtitle, generation date, record count, accent rule, the table with a repeating header, an optional totals row and “Page X of N” footers. orientation: 'auto' switches to landscape when the table is wide.

Character set & Unicode

Latin text only

To stay dependency-free and small, text uses the 14 standard PDF fonts, which every viewer has built in, with WinAnsi encoding: ASCII, Latin-1 (é ü ñ ß ø …) and the Windows-1252 extras (€ ‘ ’ “ ” • – — … ™ Š Œ Ÿ). Accented letters outside that set are folded (ł → l, ą → a, ő → o), a few symbols are substituted (− → -, → → ->, ₹ → Rs), and everything else — Greek, Cyrillic, Arabic, Hebrew, CJK, emoji — becomes “?”. Document properties (title, author) support full Unicode. For multilingual output use the browser’s print-to-PDF path: Orion.printPreview() renders any HTML with system fonts and the print dialog’s “Save as PDF”.

      Orion.PDF.encode('Łódź café – €5 · 東京')   // -> "Lódz café – €5 · ??"  (WinAnsi bytes: ó is Latin-1 and stays accented, ź has no WinAnsi match and folds to z)
      Orion.PDF.measure('Invoice', { size: 12, bold: true })   // -> width in points
