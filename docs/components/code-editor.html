Code Editor

<o-code-editor> is a zero-dependency code editor: a native <textarea> (real selection, IME and clipboard) under a synchronized, virtualized, tokenizer-highlighted overlay. It has its own undo history, auto-indent, bracket/quote autoclose, comment toggle, line move/duplicate, a search & replace panel and pluggable validation (JSON built in), and renders multi-thousand-line documents smoothly.

Basic usage & JSON validation

Give it a language and either a value property/attribute or initial content (a child <template>, <textarea>, or plain text — common leading indentation is stripped automatically). language="json" runs the built-in JSON validator by default (or pass your own function/global name to validate); errors show as a wavy underline, a marker in the gutter, and a message in the problems bar below the editor. Try deleting a closing brace, adding a trailing comma, or typing an unquoted key.

Languages

Highlighting covers JavaScript/TypeScript, JSON, HTML/XML (with embedded <script>/<style>), CSS/SCSS, SQL, Python, PHP, Java, C#, Go, Rust, Bash, YAML and Markdown — see the README for the full alias list. line-numbers adds a gutter; tab-size controls indent width for Tab, auto-indent and indent()/outdent().

Read-only

Set readonly to display code without allowing edits (search still works; typing, auto-indent and auto-close are disabled). Pair with disabled to also remove it from tab order and form submission.

Search & replace

Ctrl/Cmd+F opens find, Ctrl/Cmd+H opens find & replace; F3 / Shift+F3 repeat the search even with the panel closed. The same actions are scriptable through find(), findNext()/findPrev(), replaceCurrent() and replaceAll().

Large documents

The highlighted overlay and gutter are virtualized once a document passes 150 lines (with wrap off): only the visible lines get DOM nodes. Tokenization is cached per line and re-validated incrementally, so editing stays responsive even in very large files.

Static highlighting

For code that never needs editing, add data-o-highlight="<language>" to a plain <pre><code> block — no JavaScript required beyond loading the bundle. Add data-o-line-numbers for a numbered gutter. This uses the same tokenizer and CSS as the editor (Orion.highlight).
