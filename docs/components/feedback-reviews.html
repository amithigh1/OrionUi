Feedback and Reviews

Orion.feedback(options) is a floating corner launcher for quick site-wide feedback (rating + category + message). <o-reviews> is a rating-summary histogram, sortable/filterable review list, and a write-a-review form, all in one element.

Orion.feedback()

Click below to attach the launcher to this page (bottom-right corner) and open it once so you can see the panel immediately.

<o-reviews>

Seed data via the reviews property/attribute, or a <script type="application/json"> child as shown here. Try sorting, filtering by star rating (click a histogram row), voting a review helpful, and writing your own.

API

Orion.feedback(options)

OptionDescription
idOmit to replace the single default launcher on repeat calls; pass a value to run several independently.
positionbottom-end (default) · bottom-start · top-end · top-start
categoriesArray of category chip labels; omit for rating + message only.
buttonTextOptional visible label on the launcher (icon-only otherwise).
onSubmit(data)data: { rating, category, message, url, userAgent, viewport, timestamp }

Returns { open(), close(), destroy() }. Built on the core floating/overlay primitives — Escape, outside-click, and a focus trap all work automatically.

<o-reviews>

MemberDescription
reviews{ id, author, avatar, rating, title, body, date, verified, helpful, unhelpful, response }[]
summaryDefault true — average + 5-row histogram (click a row to filter).
allowWrite / sort / filterStarssort: recent (default) · helpful · highest · lowest.
nameStorage key so a "helpful" vote is only counted once per browser.
addReview(review) / getReviews() / setReviews(list)Methods.
voteHelpful(id, helpful)Records a Yes/No vote; returns false if this browser already voted.
o-review { review } / o-vote-helpful { id, helpful }Events.

Keyboard & accessibility

The feedback panel traps focus while open and returns it to the launcher on close (Escape or outside click both work). Star pickers are native radiogroups (arrow keys move between them). The review list's sort/filter controls are a native <select> and buttons; the average rating and each review's stars expose an aria-label ("4.2 out of 5 stars") since the stars themselves are decorative.
