Orion.ai

A provider-agnostic AI client: one chat()/stream() call that works against your own backend proxy, an OpenAI-compatible endpoint, Anthropic's Messages API, or a built-in mock provider — with retries, abort, prompt "tasks", and Markdown rendering of the reply. <o-chatbot>, <o-assistant> and every aitools helper (ghost-text, summarize, fill-form, analyze, AI search) are built on top of this one API.

Security model

This is the part the project owner considers non-negotiable:

  • The bundle contains no third-party code and no API keys, ever.
  • The documented default is Orion.ai.http({ url: '/api/ai' }) — your own backend proxy, which attaches the real key server-side. This is what Orion.ai.openAICompatible() also expects by default.
  • Calling a vendor's API directly from the browser — Orion.ai.anthropic() or Orion.ai.openAICompatible() with an apiKey — throws unless you also pass dangerouslyAllowBrowser: true, and even then logs a console.warn every time, because every visitor can read the key from the network tab.
  • A built-in mock provider (Orion.ai.mock()) streams deterministic canned answers entirely offline, so every demo on this page — and your own tests — never touch the network.
// Recommended default: your own backend proxy (never a key in the browser)
Orion.ai.configure({ provider: Orion.ai.http({ url: '/api/ai', stream: 'sse' }) });

// Throws: an apiKey without the explicit opt-in
Orion.ai.anthropic({ apiKey: 'sk-...' });

// Opt-in (dev/demo only) — throws no more, but logs a console.warn every call
Orion.ai.configure({ provider: Orion.ai.anthropic({ apiKey: 'sk-...', dangerouslyAllowBrowser: true }) });

// Offline, zero-key, used by every demo on this site
Orion.ai.configure({ provider: Orion.ai.mock() });

The mock provider & streaming chat

Orion.ai.mock({ latency, speed, responses }) returns a provider that waits latencyms, then streams the reply token by token (paced by speed). responses can be a function of the last user message, or a map of keyword → reply (plus an optional default). Every demo below configures it once and reuses it for chat(), stream() and the tasks.

const controller = new AbortController();
const it = Orion.ai.stream(messages, { onToken: (tok, full) => render(full), signal: controller.signal });
try { for await (const _tok of it) { /* it.controller / it.cancel() also abort */ } }
catch (err) { if (err.name !== 'AbortError') showError(err); }
controller.abort();               // or: it.cancel('user-stop')

const text = await Orion.ai.chat(messages, { system: 'Be concise.' });   // non-streaming
const one = await Orion.ai.complete('Summarize this page');              // chat() with a single user message

Tasks — reusable prompt templates

Orion.ai.tasks.{summarize,rewrite,translate,extract,classify}(input, options) return { system, messages } — pass them straight to chat()/stream(). They are plain overridable functions (Orion.ai.tasks.summarize = myVersion replaces the built-in one), and every aitools helper is built from them.

Adapters

An adapter is just a function (ctx) => string | AsyncIterable<string> — write your own, or use one of these:

AdapterUse for
Orion.ai.http({ url, headers, body, parse, stream, streamParse })Your own backend proxy — any shape. stream: 'sse' | 'ndjson' | 'text' | false.
Orion.ai.openAICompatible({ url, model, headers })/chat/completions-shaped backend (SSE deltas). Needs apiKey + dangerouslyAllowBrowser to call a vendor directly.
Orion.ai.anthropic({ url, model, headers })Claude Messages API SSE. Same dangerouslyAllowBrowser gate.
Orion.ai.mock({ latency, speed, responses })Offline, deterministic — docs, demos and tests.
 
// Your own proxy, NDJSON streaming, custom auth header
Orion.ai.configure({
  provider: Orion.ai.http({
    url: '/api/ai/chat', stream: 'ndjson',
    headers: () => ({ Authorization: 'Bearer ' + getSessionToken() }),
    streamParse: (evt) => evt.delta || '',
  }),
});

// Canned per-keyword mock responses for a demo
Orion.ai.configure({
  provider: Orion.ai.mock({
    responses: { pricing: 'Plans start at $12/month.', default: (q) => `You asked: "${q}"` },
  }),
});

Markdown rendering

Orion.ai.markdown(text) → SafeHTML renders headings, emphasis, strikethrough, lists (incl. task lists), links, inline/fenced code (with a copy button), tables and blockquotes from AI replies. Every character is escaped before any markup is generated and the result is passed through sanitize(), so HTML or script hidden inside a model's reply is always inert text — safe to insert directly.

API

MemberDescription
configure({ provider, ...defaults }) / configure(fn)Set the active provider (and default call options merged into every call).
chat(messages, opts) → Promise<string>opts: system, signal, provider, retries, retryDelay, onToken (used by stream internally too).
stream(messages, opts) → AsyncGenerator<string>Same opts + onToken(tok, fullSoFar). Result also has .cancel(reason) and .controller.
complete(prompt, opts) → Promise<string>chat() with a single user message.
tasks.summarize/rewrite/translate/extract/classify(input, options)Return { system, messages }; overridable.
markdown(text) → SafeHTMLSanitized Markdown → HTML for chat bubbles / results.
http / openAICompatible / anthropic / mock(cfg) → providerAdapters, see above.
sseEvents(chunks) / ndjsonEvents(chunks)Low-level stream parsers for a custom adapter.
providerRead-only getter — the currently configured provider function, or null.

Every call accepts signal (an AbortSignal — merged with an internal controller so either side can cancel), and retries transient failures (429/5xx/network errors) with backoff via retries (default 2) / retryDelay (default 500ms); pass retries: 0 to fail fast (used by aitools' ghost-text so a slow request never blocks typing).

Frameworks

Orion.ai is a plain JS API — call it the same way from a React effect, a Vue composable or an Angular service. <o-chatbot> and <o-assistant> (see Chatbot & Assistant) wrap it in a ready-made UI; everything else in aitools works on plain inputs/textareas/forms so it needs no framework-specific glue.
