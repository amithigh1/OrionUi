Mega Menu

.o-megamenu opens a full-width, multi-column panel from a navbar item — hover-intent on desktop, click and full keyboard support everywhere, and an automatic inline accordion fallback on mobile (below 992px) so it works inside a collapsed navbar drawer.

Basic

Hover "Solutions" (or click / focus it and press ↓). The panel spans the full width of its containing navbar. Try ←/→ on the top-level links, and Escape to close.

Mobile accordion fallback

Below 992px (or inside any container whose --o-megamenu-mode is switched to collapsed), the same markup renders as a plain inline accordion — no overlay, no floating panel. Resize your browser narrower than 992px to see the "Solutions" item above switch automatically, or preview it directly at mobile width in the shell examples on the App Shell page.

API

Class / attributeDescription
.o-megamenu-itemWraps the trigger and the panel (usually an <li> inside .o-navbar-nav).
data-o-megamenu-toggleThe trigger; needs aria-haspopup="true". aria-expanded / aria-controls are managed automatically.
.o-megamenuThe panel — the sibling immediately after the trigger.
.o-megamenu-innerCentering row (matches --o-container-max).
.o-megamenu-col, .o-megamenu-heading, .o-megamenu-linkA column of links with an icon, title and description.
.o-megamenu-promoOptional feature/promo card, hidden automatically on the mobile accordion.

Keyboard

KeyAction
Enter / SpaceToggle the panel (focuses the first link when opening).
↓ (on the trigger)Open and focus the first link.
↓ / ↑ (inside the panel)Move between links in document order.
← / → (on a top-level trigger)Move to the previous/next navbar item (mirrored in RTL).
EscapeClose and return focus to the trigger.
Tab / click outsideCloses the panel.
