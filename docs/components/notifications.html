Notifications

Orion.notifications is a shared, event-emitting store (push, read state, pagination, cross-tab sync); <o-notification-bell> and <o-notifications> both read it live, so any number of them on a page always agree with each other.

Bell + center

<o-notification-bell> needs no setup beyond notifications existing in the store — click it to open the list in a floating panel. The same list also works standalone (right), e.g. for a dedicated notifications page.

Mark read, dismiss, and push

Clicking a row marks it read; the × button removes it. push() prepends a brand-new item (optionally bridged to Orion.toast — off by default, turn it on with configure({ toast: true })).

Day grouping & compact mode

group-by-day (default on) inserts a divider between calendar days. compact — used internally by the bell's panel — tightens the rows for a small popover.

Real-time source (connect())

Orion.notifications.connect(client, { event }) wires any Emitter-shaped realtime client as a push source — every matching event calls push(). This demo uses an in-browser mock WebSocket server ticking every few seconds.

Persistence & cross-tab sync

configure({ persist: true }) round-trips items (including read state) through localStorage; crossTab (on by default) mirrors every push/read/remove to other tabs of the same origin via BroadcastChannel — open this page in two tabs and mark one read.

Orion.notifications.configure({ persist: true, storageKey: 'orion:notifications:items', crossTab: true });
