Keyboard Shortcuts

Orion.shortcuts registers hotkeys (mod+k), sequences (g i) and alternatives (mod+s, ctrl+shift+s). mod is ⌘ on Mac and Ctrl elsewhere. Scopes let dialogs own keys, labels follow the platform, and ? opens a searchable list of everything available.

Register shortcuts

add() returns a function that removes the binding. By default shortcuts do not fire while typing in a text field and call preventDefault().

      const off = Orion.shortcuts.add('mod+k', () => palette.open(), { description: 'Open command palette', group: 'General' });
      Orion.shortcuts.add({ 'alt+n': newRecord, 'shift+ArrowRight': nextRecord }, { group: 'Records' });   // many at once
      off();   // remove

Shortcuts on elements

data-o-shortcut clicks the element (or focuses it when it is a field), sets aria-keyshortcuts and adds the hint to its title. data-o-shortcut-hint="kbd" renders the keys inside the element. Disabled or hidden elements are skipped, so the key stays free for others.

Sequences

Space-separated steps form a sequence; each key must follow within one second (configure({ sequenceTimeout })). A continuing sequence wins over a single-key binding.

Scopes

Bindings with a scope only fire while that scope is on top of the stack. Global bindings keep working unless the scope is pushed with { exclusive: true } (typical for modal dialogs). Bindings with scope: '*' (like the help key) always work.

Platform-aware labels

format(combo) returns text for titles and menus; kbd(combo) returns key caps; ariaKeys(combo) gives the aria-keyshortcuts value.

Help overlay

Press ? anywhere (outside a text field) or call Orion.shortcuts.help(). It lists every binding that has a description and is active in the current scope, grouped, with fuzzy search. Change the key with configure({ helpKey: 'shift+/' }) or disable it with helpKey: false.

Record a shortcut

await Orion.shortcuts.record() captures the next key combination as a portable string (with mod), ready to store in user preferences.

Inside text fields

Pass allowInInputs: true for keys that make sense while typing, like submitting with Ctrl Enter.

Combo syntax

Modifiers mod ctrl alt/option shift meta/cmd joined with +; keys are KeyboardEvent.key names (case-insensitive) plus aliases esc up down left right space plus comma pgup pgdn del. Symbols such as ? imply Shift. Letters and digits also match by physical key when a layout or Option produces another character.

Events

Bus events: shortcuts:change (bindings added/removed), shortcuts:help { open }.

Frameworks

Register in a mount effect and call the returned function on unmount. Elements rendered by React/Vue/Angular with data-o-shortcut are picked up and cleaned up automatically.
