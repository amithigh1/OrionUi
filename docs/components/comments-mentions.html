Comments & Mentions

Caret-positioned autocomplete for @mentions, #tags and :emoji:, for plain <textarea>/<input> fields, contenteditable regions, and the <o-editor> rich text editor. Built from three pieces you can use independently: Orion.mentions() (the autocomplete engine), Orion.mentions.emoji (a ~300-entry searchable emoji set with a picker popup), and Orion.editorKit (the shared popover/menu/caret-rect primitives all of the above — and the rich editor's toolbar — are built on).

Overview

There is no <o-mentions> custom element — mentions is a behavior + service. Either add data-o-mentions to existing markup for a zero-JS setup, or call Orion.mentions(target, options) yourself for full control (async sources, multiple trigger characters, custom rendering). Both attach to the same target types:

  • <textarea> / <input> — positions the popup with an off-screen mirror-div technique (Orion.editorKit.caretRect) and inserts plain text.
  • Any contenteditable element — positions the popup against the live selection Range and inserts an inline <span class="o-mention"> token.
  • An <o-editor> host — same as contenteditable, but anchored/scoped to its internal content area.

See the README.md next to the source for the full API reference (every option, every method, and the exact shape the data-o-mentions behavior expects).

Declarative: data-o-mentions

The fastest way to add mentions to a plain field: no JavaScript at all. The attribute value is JSON (an array of strings or objects) or a dotted path to a global. data-o-mentions-trigger changes the trigger character (default @).

JS API: async / remote source

Orion.mentions(el, options) gives you the full MentionsOptions shape — here a source function simulates a network round-trip (700 ms) and returns objects with label/description so each row gets a description line and an avatar. While a request is in flight the popup shows a spinner (mentions.loading); once it resolves the list re-renders in place.

Contenteditable

The same Orion.mentions() call works on any contenteditable element. Picking a suggestion inserts a non-editable <span class="o-mention"> token (followed by a caret-escape space) instead of plain text.

Emoji

Orion.mentions.emoji is a standalone, dependency-free emoji set: a search index over ~300 entries and a picker popover. It also plugs straight into Orion.mentions() as a trigger source — that's exactly how <o-editor> wires up its : emoji autocomplete.

The : trigger

Pass Orion.mentions.emoji.source as a trigger source (with minChars: 1, since an empty query would list all ~300 entries) to get inline :name autocomplete anywhere Orion.mentions() works.

Search

Orion.mentions.emoji.search(query, limit) is the plain function behind both the picker and the : trigger — useful for building your own UI over the same data.

      Orion.mentions.emoji.search('smile', 5);
      // -> [{ char: '😀', name: 'grinning', keywords: ['smile','happy'], category: 'smileys', search: '…' }, …]

API

Orion.mentions(target, options)

OptionTypeDefaultDescription
triggers{ char: source | TriggerConfig }{ '@': options.source }One entry per trigger character. A bare value is shorthand for { source }.
trigger · sourcestring · Source'@' · —Shorthand for a single trigger when triggers is omitted.
limit · minChars · debouncenumber8 · 0 · 120Max suggestions · min query length before searching · debounce (ms) for async sources while already open.
allowSpaces · maxLengthboolean · numbertrue · 40Allow up to 3 space-separated words in the query · max query length before the trigger is abandoned.
insert(item, trigger)function—Returns the string/Node to insert. Default: "{trigger}{label} " for fields, an .o-mention token for rich text.
render(item, query, trigger)function—Custom suggestion row (HTML string or Node). Strings are inserted as-is (not escaped) — escape your own data.
onSelect(item, trigger)function—Called after a pick (in addition to the o-mention event).
classNamestring—Extra class on the suggestion popover.

Source (per trigger): an array of strings/objects ({ id, label, avatar, description }, matched with fuzzy search), an async (query, trigger) => items function, or a dotted string path resolved against window. A TriggerConfig object can override insert, render, onSelect, allowSpaces, maxLength, minChars, limit, className per trigger, plus startOfLine (only match at the start of a line/block) and hideEmpty (close instead of showing "No matches").
