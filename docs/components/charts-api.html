Chart API

Everything the chart engine exposes: the configuration object, the <o-chart> element, instance methods, events, live updates and streaming, SVG/PNG/CSV export, theming tokens and the accessibility model.

Creating a chart

Use the element (frameworks set the config property; plain HTML can use a JSON attribute) or the factory, which accepts any element or selector and returns the Chart instance. Functions (formatters) can only be passed through properties.

      <o-chart id="sales" type="line" height="280"
        config='{"labels":["Q1","Q2","Q3"],"series":[{"name":"Sales","data":[12,19,15]}]}'></o-chart>

      <script>
        // or from JS: returns the Chart instance
        const chart = Orion.chart('#panel', {
          type: 'column',
          labels: ['Q1', 'Q2', 'Q3'],
          series: [{ name: 'Sales', data: [12, 19, 15] }],
          yAxis: { format: v => '$' + v + 'K' },
        });
        document.getElementById('sales').chart;   // instance behind an element
      </script>

Frameworks

      // React 19 (sets properties)
      <o-chart config={cfg} ref={ref} />   // events: ref.current.addEventListener('o-point-click', fn)
      // React 18 (sets attributes)
      <o-chart config={JSON.stringify(cfg)} />
      // Vue 3 — compilerOptions.isCustomElement = t => t.startsWith('o-')
      <o-chart :config="cfg" @o-point-click="onPoint" />
      // Angular — schemas: [CUSTOM_ELEMENTS_SCHEMA]
      <o-chart [config]="cfg" (o-point-click)="onPoint($event)"></o-chart>
      // A new config object animates from the previous state; cleanup happens when the element leaves the DOM.

Updates & streaming

Every change animates from the previous state: values and the value axis tween, hidden series fade out of the stack, new slices grow. append() slides the window; the x axis tweens with it.

Export

Exports inline the resolved theme colors, so the file looks the same outside the page. Enable the corner menu with toolbar: { download: true }.

Theming & color

All marks read CSS custom properties, so switching the theme (try the header toggle) recolors charts without a re-render. Dark mode is selected, not inverted: each slot has its own dark step validated against the dark surface, and sequential ramps flip their anchor so that "near zero" recedes into the background.

TokenRole
--o-chart-1 … --o-chart-8Categorical slots in fixed order (blue, orange, aqua, yellow, magenta, green, violet, red). Never cycled; the ninth series folds into "Other".
--o-chart-otherDe-emphasis gray for "Other" and emphasis mode.
--o-seq-100 … --o-seq-700Sequential blue ramp (heatmaps, choropleths, calendar); exposed to marks as --o-ch-q1…7, reversed in dark mode.
--o-ch-o1 … --o-ch-o5Ordinal ramp for ordered stages (funnel): seq 700→300 light, 200→600 dark.
--o-div-neg / mid / posDiverging poles and neutral midpoint (--o-ch-d1…7 steps).
--o-status-good / warning / serious / criticalReserved for state (gauge bands, candle direction, win/loss) — always with a label or shape.
--o-chart-grid / --o-chart-axis / --o-chart-surfaceHairline grid, baseline, and the surface used for gaps and rings (set it if your card isn't --o-surface).

The default palette was checked with the data-viz validator against Orion's real surfaces (#ffffff light, #121a2b dark): lightness band, chroma floor, adjacent CVD separation (worst ΔE 9.1 light / 8.4 dark), normal-vision floor (19.6 / 19.3) all pass; the first three slots also pass all-pairs (scatter, maps). Three light slots (aqua, yellow, magenta) sit below 3:1 on white, which is why every chart ships a table view and direct labels. If you replace the palette with Orion.theme.set({ '--o-chart-1': … }), re-validate it.

Accessibility

  • The plot is a focusable role="img" whose accessible name summarises the chart (type, series, range, extremes); the toolbar, legend buttons and table are regular controls.
  • Keyboard: arrows move between points (and series), Home/End jump, Enter clicks, Esc clears. Each move is announced through the live region and shows the same tooltip as hover.
  • "View as table" reveals the data; when closed, the same table stays available to screen readers (up to 400 rows).
  • Identity never depends on color alone: legends for ≥ 2 series, selective direct labels, hollow vs. filled candles, labelled status.
  • Tooltips enhance, never gate — every value is also in the table. Motion is disabled under prefers-reduced-motion; forced-colors adds outlines.
  • All strings are translatable under chart.* (Orion.i18n.add('fr', { chart: { viewTable: 'Voir le tableau' } })) and numbers/dates follow the active locale.
