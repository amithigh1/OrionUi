Charts

A hand-written SVG chart engine: line, area, column, bar, stacked, 100% and mixed charts that theme with CSS tokens, animate, stream, zoom, speak to screen readers and export to SVG, PNG or CSV — from one <script> tag.

Overview

Create a chart with the <o-chart> element (config as a property or a JSON attribute) or with Orion.chart(el, config). Colors come from the validated categorical palette --o-chart-1…8 in a fixed order, so a series keeps its color when others are hidden. Hover shows a crosshair and one tooltip listing every series; the table button in the corner shows the same data as an accessible table.

Line

Lines are 2px with round joins. Up to four series get a direct label at their end (with leader lines if ends converge) in addition to the legend. Use curve: 'smooth' (monotone, never overshoots) or 'step', and dashed: true for targets or forecasts.

Area & time axis

Pass { x, y } points with dates (or date labels) and the x axis becomes a time axis with calendar-aligned, localized ticks (hours, days, weeks, months, years). Areas are a 10% wash under a 2px line; stacked: true stacks them.

Column (grouped)

Bars are at most 24px thick with a 4px rounded data end and a square baseline; neighbours are separated by a 2px surface gap. The whole band is the hover target, and each bar has its own tooltip.

Bar (horizontal)

type: 'bar' (or horizontal: true) puts long category names down the side. A single series needs no legend — the title names it — and values sit at the bar tips when they fit.

Stacked & 100%

stacked: true stacks every bar series (or group them with stack: 'name'); stacked: 'percent' shows each segment's share. Only the outermost segment is rounded. Segment labels appear only when they fit — the tooltip and table carry the rest.

Mixed bar + line

Give each series a type to combine columns and lines on one value axis. There is deliberately no second y-axis: two measures on different scales belong in two charts (or indexed to a common base).

Zoom & annotations

zoom: { x: true } lets users drag across the plot to zoom (the y axis refits); the reset button, a double-click or chart.resetZoom() restores it. annotations draw target lines and highlighted bands.

Large data

Line and area series with more than 2,000 points are downsampled with Largest-Triangle-Three-Buckets to about 1.5 points per pixel, keeping peaks and troughs. Hover still reads the exact nearest point through a binary search over the full data.

Real-time stream

chart.append(points, { max }) pushes new points (one per series) and drops the oldest; the line slides smoothly and the value axis refits. This server-load panel updates every second.

Emphasis & legend

Click a legend item to hide a series — survivors keep their colors. Hover a legend item (or call chart.highlight(i)) to emphasise one series and gray the rest. A ninth series is never given a generated color: it folds into "Other".
