Organization Chart

<o-orgchart> lays out a flat list of people ({ id, parentId, name, title, ... }) as a tidy tree. It handles collapse/expand, fuzzy search with highlighting, keyboard tree navigation, optional drag-to-reassign, and SVG/PNG export. No dependencies beyond the shared diagram viewport/layout/export kit.

Team directory

A four-level company tree (CEO → VPs → managers → individual contributors), searchable and collapsible. Click a card to select it; click the +/− toggle (or press Space on a focused card) to collapse a branch.

Direction & compact

direction is 'TB' | 'BT' | 'LR' | 'RL'; compact shrinks the cards to name + department only. Both re-layout instantly (animated).

Drag to reassign

With draggable, dragging a card onto another opens a reassignment: the cancelable o-reassign event fires before the move is applied (return false / call preventDefault() to veto it — dropping a card onto its own descendant is always rejected). Try dragging "Noor Haddad" onto "Sales".

Custom cards & export

renderNode(node) replaces the default card body (an Element, or an HTML string that is sanitized). exportSVG() / exportPNG({scale}) / download(format) work the same as <o-diagram>.

Keyboard & accessibility

Cards are a role="tree"/treeitem" structure with roving tabindex, aria-expanded and aria-selected, and a live aria-label summary on the canvas region.

API

Input

el.nodes = [{ id, parentId, name, title, department, avatar, email, badge, color, data }]

Attributes & properties

CSS variables

--o-org-height, --o-org-bg, --o-org-card-bg, --o-org-card-border, --o-org-link, --o-org-select. Per-node color (or the department color ramp) sets --o-org-accent on that card.

Frameworks

Set nodes and renderNode as properties (React 19, Vue :nodes, Angular [nodes]); React 18 may pass nodes as a JSON string.
