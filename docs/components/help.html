Help

Register articles once with Orion.help.register(), then link into them from anywhere: an inline <o-help> "?", a full <o-help-panel> with search and history, or a data-o-help hook lit up by "What's this?" mode. Press F1 or ? anywhere on this page to try it.

Register articles

      Orion.help.register({
        billing: { title: 'Billing & invoices', content: '<p>Your plan renews monthly on the 1st.</p>', related: ['payment-methods'] },
        'payment-methods': { title: 'Payment methods', content: '<p>Add a card in Settings → Billing.</p>' },
        notifications: { title: 'Notification settings', content: '<p>Control email and push notifications per project.</p>' },
      });

Contextual help over a settings page

Turn on "What's this?" and click a highlighted card.

API — Orion.help

register(map){ key: { title, content, related?, video? } }, merged into the registry.
get(key) / keys() / search(query)Read the registry / fuzzy search.
open(key?) / close() / toggle(key?)Show/hide the shared <o-help-panel> (auto-created).
whatsThis(on?) / inspectingToggle inspect mode.

<o-help text placement article>

An inline "?" popover; add article="key" to link into the full panel.

data-o-help="key"

Inert until Orion.help.whatsThis(true); then outlined, and a click opens that article.

Keyboard

F1Open the help panel anywhere on the page.
?Same, when focus isn't in a text field.
EscapeCancel "What's this?" inspect mode, or close the panel.
