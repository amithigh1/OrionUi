Chatbot & Assistant

<o-chatbot> is a floating launcher + chat window (or an inline panel) with streamed Markdown replies, suggested prompts, feedback thumbs and transcript export. <o-assistant> is a resizable side panel with context actions — summarize this page, explain the selection, draft a reply — that insert or replace text back where you were working. Both stream from Orion.ai, so configure a provider (the mock below, or your own) before using either.

<o-chatbot> — floating launcher

Click the launcher (bottom corner of the box below) to open the window. Try a suggested prompt, send a message, thumbs-up/down a reply, and use the export button (⬇ in the header) to download the transcript.

<o-chatbot title="Orion Assistant" welcome="Hi! How can I help?"
  suggestions='["How do I export to CSV?", "Can columns be resized?"]' persist="support"></o-chatbot>
<script>
  Orion.ai.configure({ provider: Orion.ai.http({ url: '/api/ai/chat', stream: 'sse' }) });
  document.querySelector('o-chatbot').addEventListener('o-feedback', e => logFeedback(e.detail));
</script>

Inline mode, keyboard & JavaScript API

launcher="false" renders the window in place (no floating button) — handy inside a docked panel or a help tab. Enter sends, Shift+Enter inserts a newline, Esc stops a reply in progress (or closes the window when floating), ↑ on an empty input recalls the last message.

<o-assistant> — context-aware side panel

Select some text in the paragraph below, then open the panel and try Explain selection — or just use Summarize this page / Draft a reply. Insert / Replace selection write the result back into the last field or selection you had focused.

<o-assistant title="Page assistant" id="asst"></o-assistant>
<script>
  const asst = document.getElementById('asst');
  asst.templates = [{ label: 'Write a title', build: ctx => `Suggest a short page title for: ${ctx}` }];   // property only — "templates" is not attribute-parsed
  document.getElementById('open-btn').onclick = () => asst.open();
  asst.addEventListener('o-insert', e => console.log(e.detail.mode, e.detail.text));
</script>

Frameworks

Both are plain custom elements: set provider/context/templates as properties from React/Vue/Angular (they are functions/objects, so attributes won't do), and listen for o-response/o-insert/o-feedback through a ref. Neither touches Orion.ai.configure() for you — call it once at app startup (or pass a per-instance provider).
