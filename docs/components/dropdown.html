Dropdown & Context Menu

A WAI-ARIA menu button (data-o-toggle="dropdown", <o-dropdown>, Orion.menu()) sharing one renderer and keyboard controller with custom right-click menus (Orion.contextMenu()): submenus, checkbox/radio items, headers, dividers, shortcuts and full keyboard support.

Basic dropdown

data-o-toggle="dropdown" opens the next sibling .o-dropdown-menu (or data-o-target).

Submenus, checkbox & radio items

Hover intent (or → / ←, mirrored in RTL) opens nested .o-dropdown-sub menus. Checkbox/radio items keep the menu open (data-o-keep-open).

<o-dropdown> element

Wrap a trigger and a .o-dropdown-menu in <o-dropdown> for a scriptable open/close API and reflected open state.

Orion.menu(anchor, items, options)

Builds a menu from plain objects and returns a promise. anchor may be an element or a viewport point { x, y }.

Context menu (right-click)

Orion.contextMenu(selector, itemsOrFn, options) registers a delegated right-click (and long-press / Shift+F10) menu. Items can be computed per row. Shift + right-click keeps the native browser menu.

Declarative data-o-context-menu

Point data-o-context-menu="#id" at a <template> (cloned per use) or an existing .o-dropdown-menu.

API

Triggers

TriggerDescription
data-o-toggle="dropdown"The menu is the next sibling .o-dropdown-menu or data-o-target="#menu". data-o-placement sets the placement (default bottom-start).
<o-dropdown placement disabled>First non-menu child = trigger, .o-dropdown-menu child = menu. open attribute / isOpen property (reflected). Methods open(focus?), close(), toggle(). focus: 'first'｜'last'｜'menu'.

.o-dropdown-header, .o-dropdown-dividerSection title, separator.

Orion.contextMenu(target, items, options) → off()

ArgumentDescription
targetElement, or a CSS selector (delegated from document, so future elements work). The innermost match wins.
itemsItem array (see above) or (event, targetEl) => items. Return null/[] to let the native menu open.
options.placementPlacement relative to the pointer (default bottom-start, RTL aware).
options.onSelect(item, targetEl, event)Selection callback (item onClick handlers run too).
options.onOpen(targetEl), options.onClose(reason, targetEl)Callbacks.
options.className, options.minWidthMenu styling.

data-o-context-menu="#id": #id is a <template> (cloned each time) or an existing .o-dropdown-menu element. Events (o-open cancelable, o-select, o-close) dispatch on the target element.

Keyboard

KeyAction
Enter / Space / ↓ on the triggerOpen and focus the first item (↑: last item).
↓ ↑ Home End PageDown PageUpMove between items (wraps).
Printable charactersTypeahead.
Enter / SpaceActivate the item (toggle checkbox/radio).
→ (← in RTL)Open a submenu and focus its first item.
← (→ in RTL)Close the submenu, back to its parent item.
EscapeClose the current (sub)menu, focus returns to its trigger.

CSS variables

--o-menu-pad, --o-menu-min-w, --o-menu-max-w. Context menus add the .o-context-menu class on top of .o-dropdown-menu (no extra styling needed).
