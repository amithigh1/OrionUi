Auth

<o-auth-form> is one element that renders six sign-in flows — login, register, forgot password, reset password, a lock screen and a passwordless magic link — with correct autocomplete/inputmode attributes, inline validation, a password strength meter, social buttons and "check your inbox" success states. See also Two-factor and Biometric / passkeys.

Login

A working form against a mocked backend — try demo@orion.dev / password123, or anything else to see the error alert. The password field's show/hide toggle, caps-lock hint and strength meter come from the inputs package's data-o-password-toggle / data-o-strength behaviors when it is part of the build; they are plain, harmless attributes otherwise.

Register

Confirm-password matching is live as you type; the terms checkbox is required. Type a password to see the strength meter (only rendered when the inputs package is present).

Forgot password & magic link

Both end with a "check your inbox" screen and a resend countdown.

Methods

submit()Validate and submit programmatically.
reset()Clear fields, errors and the success screen.
showSuccess() / showError(err)Force the success screen / render an error.
focus()Focus the first field.

Events

o-submit{ type, data } — cancelable; prevent to take over submission entirely.
o-success{ type, data, result }
o-error{ type, error }
o-social{ provider }
o-mode{ type } — cancelable; default switches type.
o-resend{ type, data } — cancelable.
