Theme Builder

<o-theme-builder> edits Orion.theme live: brand colors with generated palettes, a WCAG contrast checker, radius/density/shadow/sidebar controls, side-by-side light/dark previews built from real components, presets, JSON/CSS import-export and "save as tenant". See Theming for the token reference this editor writes to.

Live demo

MemberDescription
