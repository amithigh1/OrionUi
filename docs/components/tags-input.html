Tags input

<o-tags> turns a text field into a chip list: press Enter/Tab/comma or paste a delimited list to add tags, drag chips to reorder, double-click or F2 to rename in place, and wire up suggestions or an async source for autocomplete.

Basic

Suggestions

suggestions filters a static list with fuzzy matching as you type. Use strict to only allow values from the list.

Async source

source is an async (query) => items function — great for a remote search API.

Colors

colors maps a tag's text to a semantic color name or any CSS color; color-for is a function for computed colors (e.g. hashing a category to a palette).

Pattern, max & duplicates

Drag reorder & inline edit

Drag a chip to reorder (pointer events, works with touch too); double-click or press F2/Enter on a focused chip to rename it; Alt+←/→ reorders from the keyboard.

Sizes, readonly & RTL
