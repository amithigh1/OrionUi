Diagram Builder & Flowchart

<o-diagram> is an infinite-canvas diagram editor and viewer: drag shapes from a palette, connect them from their ports, and edges route around boxes with rounded orthogonal lines. It includes snapping, alignment guides, auto layout, undo/redo, copy/paste, groups, a minimap, keyboard control and SVG/PNG/JSON export. No dependencies, everything is hand-written.

Flowchart viewer

An order-processing flowchart in read-only mode. The JSON has no coordinates: layout('layered') places it (longest-path ranking, barycenter crossing reduction, quadratic coordinate assignment). Drag to pan, use the wheel or pinch to zoom, and press Tab to step through the shapes.

Diagram builder

With palette, properties and toolbar it becomes a full editor. Drag a shape onto the canvas, hover a shape and drag from one of its ports to connect it, double-click to edit a label, drag a label along its connection, and right-click for more actions. Hold Alt while dragging to turn off snapping and guides.

Shapes

Built-in types: rect rounded terminator ellipse circle diamond parallelogram hexagon cylinder document note text image html. Labels wrap automatically inside each shape's text area. Style any node with style: { fill, stroke, textColor, fontSize, dashed, bold }; CSS variables (tokens) keep dark mode working.

Connections

Edges connect ports (fromPort / toPort — t r b l by default, or custom ports on a node). Without ports the best facing sides are chosen automatically. type is orthogonal (routed around shapes), straight or curve; arrow is end both start none; plus label, labelPos (0–1 along the line), dashed, animated and style: { stroke, width }.

Auto layout

layout('layered', { direction }) is a Sugiyama-style layered layout for flowcharts (cycles are broken, long edges get dummy nodes); layout('tree') is a tidy tree. Both accept direction: 'TB' | 'LR' | 'BT' | 'RL', rankSep, nodeSep and animate. The functions are also available without a diagram as Orion.diagram.layout.layered(nodes, edges, opts) and .tree().

Connection rules & events

canConnect(from, to, { fromPort, toPort, edge }) vetoes connections while dragging (the preview turns red). The cancelable o-connect event can also change detail.edge before it is added. Here: Start accepts no incoming lines and End no outgoing lines.

Custom shapes & HTML nodes

Register a shape once with Orion.diagram.shapes.register(name, { size, path(w, h), text?(w, h), ports?(w, h) }). Nodes of type html render the result of renderNode(node) (trusted HTML or an Element) or the sanitized node.html.

Export & import

exportSVG() returns standalone markup with computed colors inlined, exportPNG({ scale }) resolves to a Blob, and download('svg' | 'png' | 'json') saves a file. import(value) loads JSON as an undoable change.

Large diagrams

Pan and zoom only change one transform; rendering is keyed and incremental, routing uses a spatial hash, and labels are hidden when zoomed far out. This generates 1,000 shapes and 1,500 connections.

Keyboard & accessibility

The canvas is a focusable role="application" region with a summary label; shapes are options of a multi-select listbox, and a visually hidden list describes every shape and connection for screen readers. Actions are announced through a live region.

Frameworks

Set value, canConnect and renderNode as properties (React 19, Vue :value, Angular [value]); React 18 may pass value as a JSON string. Feeding the o-change value back into value is safe: identical values are ignored, so undo history survives controlled usage.
