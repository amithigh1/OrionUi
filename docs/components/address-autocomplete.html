Address Autocomplete

<o-address-input> is a debounced address search field built on top of <o-autocomplete> (keyboard, highlighting, loading/empty/error states are inherited) and Orion.geocode, a small forward/reverse geocoding provider registry. The default provider is a tiny offline dataset, so this whole page — including every demo below — works with no network connection.

Basic

Type at least 2 characters (fuzzy-matched against the address label). Selecting a suggestion — by click or keyboard (↓ then Enter) — sets the element's value to a structured address object and fires o-change. Typing again without picking clears the value.

The default provider="mock" matches against a small built-in list of Malaysia/Singapore landmarks — see Providers below for the full offline/online picture.

Auto-filling other fields

fill='{"city":"#shipping-city", ...}' maps result fields (street, houseNumber, postcode, city, state, country, countryCode) onto other form controls by selector, dispatching input/change on each so masks, validators and frameworks see it.

Custom offline dataset (fixture provider)

Register your own provider with Orion.geocode.addProvider(name, { search, reverse }) — or set the source property directly on one element — to plug in any dataset. This demo loads docs/fixtures/geocode/addresses.json (a small fixture file, not the built-in mock list) with fetch() and matches it with Orion.util.fuzzySearch, entirely offline. The same technique is how you would wire up a company directory, a warehouse list or a recorded HTTP fixture in tests.

Country filter & required validation

country-codes="sg" is forwarded to the active provider (Nominatim/Photon/Google honour it; the offline mock provider ignores it since its dataset is fixed). A plain required address field reports a validation message like any other form control.

Providers

ProviderNetwork?Notes
mock (default)No~12 built-in Malaysia/Singapore landmarks. Deterministic, used by this whole doc site and by tests.
nominatimYesOpenStreetMap's public Nominatim API. Throttled to ≥1 request/second and cached in-memory; pass email to identify your app per their usage policy. Requires the http package in custom builds.
photonYesKomoot's Photon API (no throttling requirement). Also requires http.
googleYesGoogle Places Autocomplete + Geocoder, via Orion.maps.google — see the Google Maps page. Never used unless you supply your own API key.
customYour choiceOrion.geocode.addProvider(name, { search(q, opts), reverse(lat, lng, opts) }), or set the element's source property directly (skips the registry entirely). See Custom offline dataset above.

This documentation site runs with no network access, so every live demo here uses mock or a fixture provider. nominatim/photon/google work exactly the same way from the developer's side — set provider="nominatim" — they just need a real connection (and for Google, a key).

required, disabled, readonlybooleanfalseStandard form-control behaviour.
placeholderstringDefaults to a localized "Search for an address".
textsobjectPer-instance string overrides (placeholder, noResults, error, useLocation, locating, locateError).

Events

EventDetailDescription
o-change{ value }Fires on selection and on clear; value is the structured address or null. Native input/change also fire on the host.
o-input(from the inner autocomplete)Bubbles as the user types; used internally to clear value once the text no longer matches a selection.

MemberDescription

Address shape: { label, lat, lng, street, houseNumber, postcode, city, state, country, countryCode, raw } — raw is the untouched provider response.

Keyboard

Inherited from <o-autocomplete>: ↓/↑ move through suggestions, Enter selects the highlighted one, Escape closes the panel, Tab moves on.
