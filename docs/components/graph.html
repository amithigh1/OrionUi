Network Graph

<o-graph> is a force-directed network graph: velocity-Verlet integration over a Barnes-Hut quadtree charge approximation, link springs, center gravity and spatial-hash collision. Drag a node to pin it, hover to highlight its neighbours, and pan/zoom/export the same way as the other diagram-family widgets.

Force layout

A random graph with three groups. The layout runs until it settles (o-settle) or you interact with it. The legend on the right toggles a group's visibility by dimming it — click "Ops".

Pin, freeze & reheat

Dragging a node always pins it (o-pin, pinned: true); double-click a pinned node to release it. frozen stops the whole simulation loop (dragging still re-pins, it just doesn't move anything else); reheat(alpha) restarts it without touching pins.

Edge labels & weight

An edge's label is drawn at its midpoint; weight thickens the line (and softens the spring so heavier links pull tighter).

Keyboard & accessibility

The canvas is a focusable role="application" region with a live aria-label summary (node/edge counts). Dragging, hover-to-highlight and double-click-to-unpin are pointer-only.
