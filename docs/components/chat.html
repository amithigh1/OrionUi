Chat

<o-chat> is a conversation list + threaded message pane + composer: day dividers, reactions, replies, editing, attachments, a voice-note hook, in-thread search, an emoji picker (via Orion.mentions.emoji) and read/typing/unread state — all driven by plain data, no framework required.

Conversations, thread & read receipts

Feed conversations and messages as plain arrays (or the set…() methods). The active conversation shows an unread divider at the point where the last markRead() left off, day dividers between calendar days, and per-message ticks (sending → sent → delivered → read, or tap to retry on failed). Try ↑ in the empty composer to edit your last message.

@mentions and emoji

Type @ in the composer for suggestions from Orion.mentions (wired onto the textarea — <o-chat> does not assume you want mentions, so attach it yourself once). The emoji button opens Orion.mentions.emoji.picker() automatically whenever that package is loaded (it falls back to a small built-in grid otherwise); shortcodes like :thumbsup: also auto-convert as you send.

Typing indicator

setTyping(userId, isTyping, conversationId?) drives the header subtitle, an animated dots bubble in the thread, and the conversation list preview; it auto-clears after 6 seconds if you never call it with false.

Widget layout

layout="widget" turns <o-chat> into a floating support-chat bubble; toggle it with the open property/attribute or let the built-in launcher handle it. It positions itself fixed to the browser viewport (like a real support widget would), so on this page look for its round launcher button pinned to the bottom-right corner of the window, not inside the box below.

Real-time (Orion.chat.connect)

Orion.chat.connect(chatEl, client, opts?) is a template adapter over any Emitter-shaped realtime client. This demo uses a mock WebSocket server that echoes a reply a second after you send.

Frameworks

Set conversations/messages/currentUser/onSend as properties (they are Arrays/Objects/Functions, so React 18's attribute-only diffing needs the JSON-string form or a ref). Listen for o-send/o-react/etc. through a ref's addEventListener in React; Vue/Angular bind them natively as @o-send / (o-send).
