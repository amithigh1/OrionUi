Autocomplete

<o-autocomplete> is a text input with suggestions: local items or an async source, highlighted matches, groups and templates, inline (ghost) completion, recent searches, and either free text or a strict “must pick” mode. Use Select when the value must come from a list and the text itself does not matter.

Basic

Pass strings or objects to items. Matching is fuzzy (every word must match, substring matches rank first) and the matched characters are highlighted. By default the value is the typed text.

Inline completion & recent searches

inline shows the rest of the best prefix match as ghost text — press Tab or → to accept it. recent remembers the last searches in localStorage (key orion:autocomplete:<recent-key | id | name>) and shows them when the field is focused while empty; they can be cleared from the panel.

Async source, groups & strict mode

source(query, { signal }) returns items (or a Promise of them); requests are debounced, aborted when superseded and show a spinner. With strict the value is the picked item's value and unmatched text is reverted on blur; the control reports badInput while the text does not match an item. Items with group are listed under headers.

Custom templates

renderItem(item, { query }) returns HTML (escape your data) or a Node. The built-in highlighter is available as Orion.util.highlight(text, query).

Forms

The value is submitted under name. Free mode submits the text; strict mode submits the picked item's value (or nothing).

Sizes & states

Keyboard

KeyAction
TypingFilter suggestions (after min-chars).
↓ / ↑ · PageDown / PageUpOpen / move the active suggestion.
EnterPick the active suggestion, or commit the typed text (free mode).
Tab · → · EndAccept the inline completion (with inline); otherwise Tab moves on.
EscClose the suggestions; when closed, clear the text.
Home / EndMove the caret in the input.

ARIA: the input is a combobox with aria-autocomplete="list" ("both" with inline), aria-expanded, aria-controls and aria-activedescendant; the completion hint is exposed through aria-describedby and result counts are announced.
