Bottom Nav

.o-bottom-nav is a fixed mobile tab bar with icons, labels, badges, an active indicator, safe-area insets for notched phones, an optional raised center action button, and a hide-on-scroll option. It only renders on screens narrower than 768px by default (add .o-bottom-nav-always to show it everywhere, e.g. inside the mobile preview below).

Basic

Center action button

Auto-detected active link & hide-on-scroll

Active state is detected from href vs. the current URL (like the sidebar) unless data-o-bottom-nav="manual" is set. data-o-bottom-nav-autohide slides the bar away on scroll-down and back on scroll-up. Scroll inside the panel below.

API

Class / attributeDescription
.o-bottom-nav[data-o-bottom-nav]Root, fixed to the bottom of the viewport (hidden ≥768px unless .o-bottom-nav-always).
.o-bottom-nav-linkIcon + label tab; .is-active / aria-current="page" for the current one.
.o-bottom-nav-actionRaised circular center action button.
data-o-bottom-nav="manual"Disables automatic URL-based active detection.
data-o-bottom-nav-autohideHide on scroll-down, show on scroll-up.

Events

EventDetailDescription
o-navigate{ href, link }Dispatched on the nav whenever the active link changes.

JavaScript API

MemberDescription
Orion.bottomNav.sync(el?)Re-run active-link detection.

CSS custom properties

--o-bottom-nav-h (bar height, default 3.75rem) and --o-bottom-nav-space (auto-computed; add as padding-bottom on your scroll container so content is not hidden behind the bar — already applied to .o-app automatically).
