Maps

Choropleth and bubble maps drawn from GeoJSON you supply — no map tiles, no downloaded datasets. Regions are projected (mercator or equirectangular), fitted to the chart, and can be zoomed and panned with buttons, the keyboard, Ctrl/⌘ + wheel or a double-click.

Bring your own GeoJSON

Pass a FeatureCollection (or an array of features) as geo.geojson. Polygon / MultiPolygon features become regions; Point features can anchor bubbles. Values join on geo.key (default: the feature id, then properties.id / properties.name). The demos use aurelia.geojson, a small hand-made map of a fictional country (12 regions, 7 cities, 3.6 KB).

      const geojson = await fetch('/maps/regions.geojson').then(r => r.json());
      Orion.chart('#map', {
        type: 'choropleth',
        geo: { geojson, key: 'properties.code', projection: 'mercator' },
        series: [{ name: 'Revenue', data: [{ id: 'CT', value: 420 }, { id: 'NM', value: 340 }] }],
      });

Choropleth

Values are binned into steps of the sequential ramp (geo.bins, default 5); regions without data use the neutral surface step and the legend says so. Hover a region for its value; the region outline lifts.

Bubble map

type: 'bubbleMap' draws the regions as a neutral base and places bubbles by { lon, lat }, coordinates, or the id of a Point feature (or a region's centroid). Bubble area encodes the value; bubbles keep their pixel size while you zoom. Several bubble series get a legend — keep it to three on a map.
