Drag & Drop

A hand-written drag and drop engine: sortable lists and grids, connected lists, clone mode, nested lists, free positioning, dropzones for internal and native (file) drops, auto-scroll, FLIP animations and full keyboard support.

Overview

Four APIs share one engine. Orion.sortable() reorders children of a container, Orion.draggable() moves an element freely, Orion.dropzone() receives Orion drags and files dropped from the desktop, and Orion.dnd.start() is the low-level primitive other components (kanban, tree, dashboards, gantt) build on.

  • Pointer events for mouse, pen and touch. On touch a 200 ms long-press starts the drag, so swiping still scrolls the page. Handles start immediately.
  • Auto-scroll near the edges of the window and of any scroll container under the pointer.
  • Keyboard: Space picks up, arrows move, Space drops, Esc cancels, with screen-reader announcements.
  • Frameworks: controlled: true restores the DOM and reports oldIndex / newIndex so React, Vue or Angular own the order.

Sortable list

Every direct child of the container is an item. Drag an item, or focus it and press Space.

Handle only

With handle the rest of the item stays interactive (inputs, buttons, text selection). Handles become focusable keyboard grips and start touch drags without a long-press.

Sortable grid

Wrapping flex and CSS grid layouts are detected automatically (direction: 'grid'); all four arrow keys move items.

Connected lists & clone

Lists with the same group exchange items. pull: 'clone' leaves a copy behind (palettes), put: false refuses drops and sort: false keeps the source order fixed.

Nested lists

Sortables can live inside items of other sortables. The innermost list under the pointer wins; a list never accepts its own ancestor.

Horizontal list

A no-wrap row is sorted horizontally; ← → follow the reading direction in RTL.

Keyboard drag & drop

Items are focusable and described by hidden instructions. Moves are announced through a live region (“Picked up Publish packages. Position 4 of 5.”). Arrows perpendicular to a list, or past its ends, jump to the nearest connected list.

KeyAction
Space / EnterPick up the focused item; press again to drop it (pickKeys).
↑ ↓Move in vertical lists and grids (a whole row in grids).
← →Move in horizontal lists and grids (mirrored in RTL); in vertical lists, move to the list on that side.
Home / EndMove to the first / last position.
EscapeCancel and return to the original position (also cancels pointer drags).
TabBlocked while an item is picked up, so focus cannot get lost.

Controlled mode (React, Vue, Angular)

With controlled: true the DOM is put back on drop and you apply the move to your own state, which then re-renders. This demo re-renders the whole list from an array, as a framework would.

      // React 19
      function Tasks({ tasks, setTasks }) {
        const ref = useRef(null);
        useEffect(() => {
          const s = Orion.sortable(ref.current, {
            controlled: true,
            onEnd: ({ oldIndex, newIndex }) => setTasks(t => { const n = [...t]; n.splice(newIndex, 0, n.splice(oldIndex, 1)[0]); return n; }),
          });
          return () => s.destroy();
        }, []);
        return <ul ref={ref}>{tasks.map(t => <li key={t.id}>{t.title}</li>)}</ul>;
      }
      // Vue 3: onMounted(() => { s = Orion.sortable(listRef.value, { controlled: true, onEnd: e => move(e) }) }); onUnmounted(() => s.destroy())

Free dragging

Orion.draggable() moves an element with a CSS translate, optionally inside bounds, on an axis and snapped to a grid. Focus a note and use the arrow keys (Shift for bigger steps).

Dropzones

Orion.dropzone() receives Orion drags (with the payload from data) and native drops of files, text and links from outside the page. accept(data) decides; .is-drop-active marks compatible zones while a drag runs.

Declarative

No JavaScript needed: behaviors initialise every current and future element, so they work with server-rendered pages and frameworks. Listen for o-sort-end on the container.

      <ul data-o-sortable data-o-sortable-group="decl">…</ul>
      <!-- -handle=".grip"  -items=".row"  -filter=".locked"  -direction="grid"  -animation="0"
           -clone  (pull: 'clone')  -put="false"  -sort="false"  -controlled -->
      <div data-o-draggable data-o-draggable-bounds="parent" data-o-draggable-handle=".title">…</div>
      <div class="o-drop-area" data-o-dropzone data-o-dropzone-accept="files">Drop files</div>  <!-- o-drop { data } -->

Orion.dnd (for component authors)

      // in a pointerdown handler
      Orion.dnd.start(e, {
        el: row, data: { id }, preview: el => myPreview(el), delayOnTouch: 200,
        onStart: s => { /* return false to abort */ },
        onMove: s => { /* s.x, s.y, s.target (element under pointer), s.dropzone */ },
        onDrop: s => s.settle(finalRect),          // animate the preview home
        onCancel: s => s.settle(originRect),
      });
      Orion.dnd.touchGuard(container);             // once: lets drags block touch scrolling
      Orion.dnd.flip(items, () => list.append(item), { duration: 180 });
