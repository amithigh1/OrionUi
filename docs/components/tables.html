Tables

CSS styles for plain HTML tables. For sorting, filtering, pagination, editing and everything else, use <o-datatable>.

Basic table

Striped, bordered, compact, sticky

Responsive tables

Wrap in .o-table-wrap for horizontal scrolling, or add .o-table-stack and a data-label on each cell to turn rows into stacked cards below 768px (resize the window to see it).

Classes

ClassDescription
.o-tableBase table.
.o-table-striped / -hover / -borderedRow striping, hover highlight, cell borders.
.o-table-sm / -lgDensity.
.o-table-stickySticky header inside a scrolling wrapper.
.o-table-wrapBordered, rounded, horizontally scrollable container.
.o-table-stack + td[data-label]Card rows on small screens.
.o-num / .o-shrink / tr.is-selectedRight-aligned numbers, shrink-to-fit column, selected row.
