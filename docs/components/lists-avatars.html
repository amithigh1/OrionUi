Lists & Avatars

List groups for menus and records, <o-avatar> with automatic initials and colors, avatar groups and presence indicators.

User avatar

<o-avatar> shows the image, falls back to initials (with a stable color per name) if the image is missing or fails, and supports status dots.

Groups & user blocks

AttributeTypeDescription
namestringUsed for initials, color and aria-label.
srcstringImage URL (lazy loaded; falls back to initials on error).
sizexs sm lg xl 2xlSize (default 2.5rem). Also --o-avatar-size.
statusonline away busy offlinePresence dot.
shapesquareRounded square.
colorcolor nameOverrides the automatic color.
iconicon nameShown when there is no name/image.

JS helpers: Orion.avatar.initials('Ada Lovelace') → "AL", Orion.avatar.colorFor(name).
