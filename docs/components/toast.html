Toast

Non-blocking notifications with Orion.toast(): six logical positions, stacked cards that expand on hover/focus, timers that pause automatically, swipe to dismiss on touch, and in-place updates by id. Toasts stay usable above open modals.

Basic & types

A plain string, or Orion.toast.success/error/warning/info/loading() for a typed toast.

Positions

Six logical positions (start/end follow text direction — try the RTL toggle in the header).

Title, action & progress

An optional title, an action button (closes the toast unless onClick returns false), a countdown progress bar, and a custom duration (0 = sticky).

Update in place & stacking

Toasts with the same id update instead of duplicating. Fire several at once to see the collapsed stack — hover or focus it to expand.

Promise tracking

Orion.toast.promise() shows a loading toast and updates it when the promise settles. Messages may be strings, option objects, or functions of the result/error.

Rich content & config

html (sanitized), a custom icon, and Orion.toast.config() to change the defaults for every future toast.

Shortcuts & helpers

FunctionDescription
toast.success/error/warning/info/loading(text, opts)Typed toasts.
toast.promise(promiseOrFn, { loading, success, error }, opts?) → PromiseLoading toast updated on settle. Messages are strings, option objects or functions of the result/error (return null to close). Returns the original promise.
toast.close(id)Close by id.
toast.clear()Close every toast.
toast.config({ position, max, duration, expand, gap, visible })Defaults: top-end, max 5 kept per position, duration 4000, expand false, gap 10px, visible 3 cards in the collapsed stack. Returns the config.

Keyboard & accessibility

KeyAction
Alt+TFocus the newest toast.
TabMove through toast buttons (the stack expands while focused).
EscapeClose the focused toast.

Each toast has role="status" (role="alert" for errors) inside a labelled region. Timers pause while hovered, focused, or when the page is hidden. Swipe left/right on touch to dismiss.

CSS variables

--o-toast-w (width, 22rem), --o-toast-offset (edge distance, 1rem). Classes: .o-toasts .o-toasts-{position}, .o-toast .o-toast-{type}, .o-toast-icon .o-toast-content .o-toast-title .o-toast-text .o-toast-action .o-toast-close .o-toast-progress.
