Tooltip & Popover

Two floating helpers built on the same core positioning (autoPlace, flip/shift, RTL aware): the tooltip is a passive hint (hover/focus only, one shared element), the popover is an interactive panel that can hold a form and stays open on click.

Tooltip — basic

data-o-tooltip="text" works on any current or future element (delegated, one shared tooltip). Shows on hover and keyboard focus, hides on Escape, scroll or blur.

Placement & truncated text

data-o-placement sets the preferred side (flips automatically near an edge). data-o-tooltip="auto" shows the element's full text only when it is visually truncated.

Orion.tooltip(el, text | options)

Programmatic tooltips: trigger: 'click' toggles on click and closes on outside press/Escape; 'manual' is controlled only through the handle.

Popover — attributes

data-o-popover="text" for plain content, or #id of a <template> (cloned) / element (moved) for richer content. Default trigger is click.

Popover with a form

Opening moves focus into the panel; Tab past the last field closes it and continues to the next page element (Shift+Tab from the first field returns to the trigger).
