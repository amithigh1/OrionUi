Faceted Filter

<o-facets> is a faceted filter panel — checkbox, radio, range, date-range and search groups with live counts — usable standalone (it filters a plain array itself) or bound to an <o-datatable> via for="#table", driving the table's own filters/facetCounts() instead of re-implementing any filtering. <o-facet-chips> renders the active selections as removable chips.

Standalone — product catalogue

Reproduces a classic e-commerce sidebar: categories and availability as checkboxes with live counts, price and minimum rating as radio buckets, a "Clear all" and removable chips. Toggle a filter and watch the grid and counts update together.

Bound to <o-datatable>

With for="#ff-table", <o-facets> drives the table's own filters property and reads live counts from its facetCounts(key) — toggling a facet updates the table's row count, and the table's own total stays the single source of truth.

Every group type

range (two number inputs), date-range (two date inputs) and search (free text) alongside checkbox/radio.
