Tabs

<o-tabs> builds a WAI-ARIA tab list from <o-tab-panel> children (or enhances your own markup) with an animated indicator, overflow scrolling or a "more" menu, closable / addable / drag-reorderable tabs, lazy panels, URL deep links and persisted selection.

Settings page (badges & deep linking)

Each <o-tab-panel> becomes a tab. hash="settings" writes the selection to the URL (#settings=security) so the page can be bookmarked or shared; reload and the same tab opens. Use query="tab" for ?tab=… instead.

Variants

variant="line" (default), pills, boxed and enclosed reuse the .o-nav visuals; the active indicator slides between tabs (disabled under reduced motion). Add fill to stretch tabs across the width.

Vertical tabs

orientation="vertical" places the list beside the panels and switches the keys to ↑ ↓. Below 520px of available width it automatically stacks into a horizontal, scrollable bar.

Closable, addable & reorderable

closable adds close buttons (also Delete and middle-click), addable shows a + button that fires o-tab-add, and reorderable enables drag reordering (long-press on touch) and Alt+←/→. o-close is cancelable.

Overflow

When tabs do not fit, overflow="scroll" (default) shows scroll buttons; overflow="menu" shows a more button listing the hidden tabs. Arrow keys always scroll the focused tab into view.

Lazy panels & keep-alive

Content inside a <template> (or a renderer function) is rendered on first show and fires o-render. With lazy alone, lazily rendered content is discarded when hidden and rebuilt next time; add keep-alive to keep it.

Manual activation & persistence

With activation="manual" arrow keys only move focus; Enter / Space selects. persist="key" remembers the tab in localStorage (orion:tabs:key).

Explicit markup

Wrap your own .o-nav and panels in <o-tabs> to get roles, keyboard support, the indicator, deep links and persistence without generated markup. Tabs reference panels with aria-controls, data-o-target or href="#id".

Plain HTML (no custom element)

Bootstrap-style triggers: data-o-toggle="tab" data-o-target="#pane". Roles, roving tabindex and arrow keys are added automatically; the trigger fires o-show (cancelable) and o-shown. Script it with Orion.tabShow(trigger).

JavaScript API

      const tabs = document.querySelector('o-tabs');
      const id = tabs.add({ label: 'Invoices', icon: 'file', badge: 2, closable: true, render: panel => buildInvoices() });
      tabs.select(id);                     // or tabs.select(0)
      tabs.addEventListener('o-before-change', e => { if (formIsDirty) e.preventDefault(); });
      tabs.addEventListener('o-change', e => console.log(e.detail.id, e.detail.previous));

Keyboard

KeyAction
TabMoves focus into the tab list (to the selected tab), then into the panel.
← / → (↑ / ↓ vertical)Previous / next tab, wrapping; mirrored in RTL. Selects it unless activation="manual".
Home / EndFirst / last tab.
Enter / SpaceSelect the focused tab (manual activation).
DeleteClose the focused tab when closable.

Frameworks

Render <o-tab-panel> elements as children from React, Vue or Angular; tabs update automatically when panels are added, removed or relabelled. The component never moves your panels, so framework reconciliation stays intact. To veto closing, call preventDefault() in o-close and remove the panel from your own state; for lazy framework content, mount into e.detail.panel in o-render.
