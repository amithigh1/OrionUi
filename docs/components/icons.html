Icons

400+ hand-drawn icons on a 24×24 grid with 2px round strokes, all drawn in currentColor. Use them with <o-icon> or Orion.icon(), scale them with one CSS variable, and look them up by name, alias or category.

Gallery

Search by name, alias (close, gear, cart…) or category. Click an icon to copy its <o-icon> tag and open its details. Arrow keys move between icons; Enter or Space copies.

Using icons

The <o-icon> element renders an inline SVG. It inherits the text color and scales with the font size (1.25em by default), so it lines up with text in buttons, inputs, menus and tables without extra CSS.

JavaScript

Orion.icon(name, options) returns the SVG markup (a trusted HTML string you can drop into templates) and Orion.iconEl(name, options) returns a ready SVGElement. Options: size, class, label and stroke.

      // markup string (SafeHTML) – use String() or insert it with Orion.h / html``
      el.innerHTML = String(Orion.icon('check', { size: 16, class: 'o-text-success' }));

      // element
      button.prepend(Orion.iconEl('download'));

      // lookups
      Orion.icons.has('gear');            // true (alias)
      Orion.icons.resolve('gear');        // 'settings'
      Orion.icons.search('cart');         // ['shopping-cart', ...]
      Orion.icons.categories.Commerce;    // ['shopping-cart', 'shopping-bag', ...]
      Orion.icons.names().length;         // canonical icons (aliases excluded)

Adding your own icons

Register inner SVG markup drawn on a 24×24 grid. Leave out fill/stroke so the shared 2px round stroke applies; add fill="currentColor" stroke="none" on shapes that must be solid. Re-registering an existing name replaces it everywhere, including already rendered <o-icon> elements.

Aliases

Common alternative names resolve to the same drawing: close → x, delete → trash, gear/cog → settings, pencil → edit, cart → shopping-cart and many more. They are registered as real icons, so they work everywhere a name is accepted. Add your own with Orion.icons.alias('name', 'target').

Sizing & stroke

Icons follow --o-icon-size (default 1.25em). The size classes set that variable, so they work on the SVG, on <o-icon> or on any parent. An explicit size attribute always wins. .o-icon-thin and .o-icon-bold change the stroke to 1.5 or 2.5.

Color & backgrounds

Strokes use currentColor: set color (or a .o-text-* utility) on the icon or its parent. .o-icon-bg adds a tinted circle from the current color context: combine it with .o-c-{color}, .o-icon-bg-solid or .o-icon-bg-rounded.

Brand marks

Simplified monochrome marks prefixed with brand-, for sign-in buttons, social links and integrations. Brand names and logos are trademarks of their owners; follow each brand's guidelines.

Right-to-left

Directional icons mirror automatically under dir="rtl": arrows, chevrons, undo/redo, reply/forward, log-in/log-out, send, indent/outdent, list, the corner-* arrows and the sidebar toggles (Orion.icons.rtl lists them). Add .o-icon-flip to mirror any other icon, or .o-icon-no-flip to keep one as drawn.

Accessibility

Icons are decorative by default: they get aria-hidden="true" and focusable="false". When an icon carries meaning on its own, give it a label: it becomes role="img" with an aria-label and a <title>. Icon-only buttons need an aria-label on the button, and color should never be the only signal (pair status icons with text).

      <!-- decorative: hidden from assistive technology -->
      <button class="o-btn"><o-icon name="download"></o-icon> Export</button>

      <!-- meaningful on its own: announced as an image -->
      <o-icon name="alert-triangle" label="Payment overdue"></o-icon>

      <!-- icon-only button: label the button -->
      <button class="o-btn o-btn-icon" aria-label="Delete row"><o-icon name="trash"></o-icon></button>

Frameworks

<o-icon> is a light-DOM custom element with string attributes, so it works as-is in React, Vue, Angular and Svelte (<o-icon name="check" />). In React you can also render markup directly: <span dangerouslySetInnerHTML={{ __html: String(Orion.icon('check')) }} />. Server-side, the bundle loads in Node and Orion.icon() returns plain markup.

API

<o-icon> attributes

AttributeTypeDescription
namestringIcon name or alias. Unknown names render an empty 24×24 box.
sizenumber | lengthWidth and height (24, 2rem). Wins over the CSS size.
labelstringAccessible name; turns the icon into role="img" with a <title>.
strokenumberStroke width (default 2).

<o-icon> fires no events and has no methods; set name/size/label/stroke as attributes or properties.
