Lazy loading

Attribute behaviors that load images, <picture> sources, iframes, videos and background images just before they scroll into view — with blur-up (LQIP) or color placeholders, a shimmer while waiting, fade-in, error fallbacks, and a hook to render any heavy content on demand. Works with markup rendered by any framework.

Image grid with blur-up placeholders

Put the real image in data-src and a tiny preview (a ~20 px JPEG as a data URI) in data-o-lazy-placeholder. The preview is shown blurred and sharpens when the full image arrives. Press Replay slowly to watch it with a simulated slow network.

Color & skeleton placeholders

A color value (#hex, rgb(), var()) paints the box in the image's dominant color. Without any placeholder a shimmer is shown until the image loads. Always give lazy images a size (width/height or CSS aspect-ratio) so the page does not jump.

Responsive images & <picture>

data-srcset and data-sizes are copied when the image becomes visible; data-sizes="auto" uses the rendered width. Inside <picture>, put data-srcset on each <source> and data-o-lazy on the <img>.

Iframes, videos & background images

Iframes use the browser's native loading="lazy" when available. Videos get their data-src / data-poster (and <source data-src>) when visible. data-o-lazy-bg preloads a background image and swaps it in once it is ready.

Error fallback

If an image fails, data-o-lazy-error (or Orion.lazy.config({ errorImage })) replaces it; otherwise a neutral “broken image” state is shown. o-lazy-error fires in both cases.

Deferred rendering

data-o-lazy-render stamps the element's <template> the first time it scrolls into view and fires o-visible — use it to mount charts, maps or other expensive widgets only when needed. With data-o-lazy-render="repeat" it fires o-visible / o-hidden every time (e.g. to pause animations offscreen).

Classes set by the behavior: .o-lazy, .is-lazy (shimmer), .is-placeholder (blurred preview), .is-loaded, .is-fade, .is-error, .is-fallback. Animations respect prefers-reduced-motion. Carousels load the data-src of slides next to the visible ones ahead of time.
