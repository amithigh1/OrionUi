Scatter, bubble & financial

Relationships and distributions: scatter and bubble plots with a nearest-point hover layer, candlestick and OHLC charts for prices, and box plots for spread and outliers.

Scatter

Points are 8px dots with a 2px surface ring so overlaps stay legible. You don't need to land on a dot: the nearest point within 24px is picked. Because any two dots can sit side by side, keep scatter plots to three series (the palette validates all-pairs for the first three slots only).

Bubble

A third value z (or r / size) sets the bubble area (radius ∝ √z). Name points with label; the tooltip shows x, y and size.

Candlestick & OHLC

Rising periods are hollow and falling periods filled, so direction never depends on color alone (status tokens: good / critical). Data points are { x, o, h, l, c } or [x, o, h, l, c]. The tooltip adds the change.

Box plot

Pass raw samples per category and the chart computes quartiles and 1.5×IQR whiskers; values beyond are drawn as hollow outliers. Or pass { min, q1, median, q3, max, outliers } directly. Several series sit side by side.
