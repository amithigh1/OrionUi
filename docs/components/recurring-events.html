Recurring events

<o-calendar> understands a practical subset of RFC 5545 RRULE, written from scratch (no third-party rrule library): daily/weekly/monthly/yearly frequencies, intervals, counts, until-dates, weekday ordinals (2MO, -1FR), month days, months, BYSETPOS, week-start and exclusions. Set an event's rrule field (a string or an object) and the calendar expands, edits and deletes it correctly across every view.

Every supported pattern

A calendar seeded directly with RRULE strings — the kind a backend would store. Notice the last Friday of the month, the second Tuesday, the quarterly BYMONTH rule and the BYSETPOS "last weekday of the month" rule, none of which a plain weekday/day-of-month picker can express.

Recurrence editor

<o-recurrence-editor> is the standalone control the calendar's own event dialog uses — a plain-language builder (does-not-repeat / daily / weekly / monthly / yearly / custom, with an end condition) that reads and writes an RRULE string, so you can embed it in your own forms. It behaves like any form control: value, input/change/o-change.

Editing and deleting a series

Dragging, resizing or editing an occurrence of a recurring event asks which occurrences the change applies to — this event, this and following events, or all events — exactly like Google Calendar or Outlook. Try dragging the Tuesday standup below to a new time.

Programmatically, updateEvent() and removeEvent() act on the whole series (matching the stored event's id); the this/following/all split only happens through the built-in drag and dialog flows, which is where o-event-change's scope field comes from.

RRULE support

PartNotes
FREQDAILY, WEEKLY, MONTHLY, YEARLY (plus HOURLY for intraday repeats).
INTERVALEvery N periods, e.g. INTERVAL=2 with FREQ=WEEKLY = fortnightly.
COUNT / UNTILMutually exclusive end conditions. UNTIL accepts a date or date-time.
BYDAYWeekday list, optionally with an ordinal: MO,WE,FR, or 2MO (2nd Monday), -1FR (last Friday).
BYMONTHDAYDay-of-month list, negative counts from the end: -1 = last day of the month.
BYMONTHRestrict to specific months (1–12).
BYYEARDAYDay-of-year list, negative counts from the end.
BYSETPOSPicks the Nth (or -Nth) match from that period's candidate set — e.g. "last weekday of the month" is BYDAY=MO,TU,WE,TH,FR;BYSETPOS=-1.
BYHOUR / BYMINUTETime-of-day restriction, mainly for HOURLY rules.
WKSTWeek-start day, affects INTERVAL grouping for weekly rules.
EXDATEExcluded occurrence dates; also settable per-event as exdates: [].

FunctionDescription
parse(input)String or object → normalised rule object (or null).
toString(rule, { full })Rule → canonical RRULE string; full adds DTSTART/EXDATE lines.
expand(rule, { dtstart, from, to, exdates, limit })Occurrence Date[] between from and to (inclusive).
