App Shell

The .o-app CSS grid shell wires together the sidebar, header, main content and footer into a responsive admin layout: full sidebar on desktop, a mini icon rail on tablet, and an off-canvas drawer with a backdrop and swipe gestures on mobile. Everything is driven by CSS custom properties and a couple of state classes, so it works from plain HTML as much as from a framework.

Markup

A shell is one .o-app element with four regions. data-o-app is added automatically to every .o-app and wires the toggle behavior, the mobile backdrop, the header scroll shadow and swipe gestures.

      <div class="o-app">
        <a class="o-skip-link" href="#main">Skip to main content</a>
        <aside class="o-app-sidebar o-sidebar" data-o-sidebar aria-label="Main">…</aside>
        <header class="o-app-header">
          <button class="o-btn o-btn-ghost o-btn-icon o-app-toggle" data-o-toggle="sidebar" aria-label="Toggle sidebar"><o-icon name="panel-left-close"></o-icon></button>
          <div class="o-app-header-end">…</div>
        </header>
        <main class="o-app-main" id="main"><div class="o-app-content">…</div></main>
        <footer class="o-app-footer">…</footer>
      </div>

Collapse, expand, mobile drawer

A minimal shell you can interact with directly on this page. The toggle button collapses the sidebar to a mini icon rail on wide viewports, or opens/closes an off-canvas drawer with a backdrop below 768px.

Variants

ClassDescription
.o-app-horizontalTop navbar layout; the sidebar (if present) becomes a drawer at every width.
.o-app-compactSmaller sidebar/header sizes and tighter gutters — good for dense, information-heavy apps.
.o-app-boxedCenters the whole shell with a max width and a border, for very wide screens.
.o-app-sidebar-endMoves the sidebar to the end (right in LTR, left in RTL).
.o-app-fixedShell fills the viewport height and only .o-app-main scrolls.
.o-app-no-miniSkips the tablet mini-rail step; the sidebar behaves like mobile (drawer) below desktop.
.is-collapsedDesktop: sidebar is a mini icon rail (persisted). Toggle with data-o-toggle="sidebar".
.is-mobile-openThe off-canvas drawer is open (tablet overlay or mobile).
.o-app-content-boxed / -narrowConstrains .o-app-content to a max width.
.o-app-header-blurTranslucent, blurred header background.

Skip link & sticky header

Include <a class="o-skip-link" href="#main">Skip to main content</a> as the first child of .o-app — it is invisible until focused (press Tab from the top of the page in the example above). .o-app-header is sticky by default and gains a .is-scrolled shadow once the page (or .o-app-main in .o-app-fixed shells) scrolls.

Print

Printing a shell hides the sidebar, header, footer and backdrop automatically and lets .o-app-content flow the full page width — no extra markup needed.

JavaScript API

MemberDescription
Orion.layout.toggleSidebar(app?, trigger?)Collapse/expand on desktop, open/close the drawer on tablet & mobile.
collapse(app?) / expand(app?)Desktop mini-rail state, persisted to localStorage.
openMobile(app?, trigger?) / closeMobile(app?)Off-canvas drawer (also reachable by swiping from the edge).
mode(app?)'desktop' | 'tablet' | 'mobile', read from --o-app-mode.
isCollapsed(app?) / isOpen(app?)Current state booleans.
setPageTitle(title, breadcrumbs?)Updates document.title, [data-o-page-title] and [data-o-page-breadcrumb] elements, and announces the change.
sync()Re-run active-link detection after a router navigation that did not fire popstate.

Actions

AttributeDescription
data-o-toggle="sidebar" [data-o-target="#app"]Toggle the sidebar (mode-aware).
data-o-dismiss="sidebar"Close the mobile drawer (used by the auto-created backdrop).

Events

EventDetailDescription
o-sidebar-toggle{ state, mode, collapsed, open }Dispatched on .o-app whenever the sidebar state changes. state is one of collapsed｜expanded｜open｜closed.
o-page-title (document){ title, breadcrumbs }Fired by setPageTitle().

--o-sidebar-w, --o-sidebar-w-mini, --o-header-h, --o-app-gutter, --o-app-boxed-max, --o-content-max (set by the content modifiers).
