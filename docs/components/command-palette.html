Command Palette

A Raycast/Linear-style command menu: register commands once with Orion.commands.register(), then open the modal palette from anywhere with Ctrl/⌘ K. Fuzzy ranking, sections, recent commands, nested pages with a breadcrumb, async providers and danger-command confirmation all work out of the box. <o-command-menu> renders the same list inline, without a dialog.

Register commands & open the palette

Press Ctrl+K (⌘K on Mac) anywhere on this page, or click the button below. Commands are grouped by section, ranked by fuzzy match against title / subtitle / keywords, and the ones you run are remembered under Recent the next time you open the palette with an empty query.

Inline variant — <o-command-menu>

The same engine without a dialog: useful embedded in a sidebar, a popover, or a settings panel. Pass a local commands list to scope it (otherwise it uses the global registry above).

Configuring the hotkey

The default shortcut is mod+k (⌘K / Ctrl+K). Change or disable it with Orion.commandPalette.hotkey(); it is wired through Orion.shortcuts when the shortcuts package is loaded, and falls back to a small built-in key listener otherwise so the palette works with just this package.

      Orion.commandPalette.hotkey('mod+shift+p');   // rebind
      Orion.commandPalette.hotkey(false);           // disable the global hotkey entirely

      Orion.commandPalette.open({ query: 'invoice' });     // open pre-filled
      Orion.commandPalette.open({ page: 'settings' });     // jump straight into a nested page
      Orion.commandPalette.close();
      Orion.commandPalette.toggle();
      Orion.commandPalette.isOpen;

Command

      interface Command {
        id?: string; title: string; subtitle?: string; icon?: string; section?: string;
        keywords?: string[]; shortcut?: string; badge?: string | number; danger?: boolean; disabled?: boolean;
        run?(ctx: { close(): void; query: string }): void;
        href?: string;                                   // used when there is no run()
        children?: Command[];                             // pushes a nested page immediately
        load?(query: string): Command[] | Promise<Command[]>;  // pushes a nested page that (re)loads per query
        when?(): boolean;                                  // hide the command when this returns false
      }
      // Provider (searched only while the query is non-empty, at the root page):
      interface CommandProvider {
        id?: string; section: string; icon?: string; minChars?: number /* 1 */; debounce?: number /* 200 */; limit?: number /* 8 */;
        search(query: string, ctx: { signal: AbortSignal }): Promise<Command[]>;
      }

Keyboard

KeyAction

↑ / ↓Move the active row (loops; typeahead also jumps to a match).
Home / EndFirst / last row.
EnterRun the active command, open its nested page, or (for a danger command) arm confirmation — press again to run.
BackspaceWith an empty query, goes back one page.
EscCloses the palette (or clears the query first, per the browser's native search-input behavior).

Frameworks

Orion.commands.register() and Orion.commandPalette are plain JS — call them from a React useEffect, a Vue onMounted, or an Angular service constructor, and call the returned unregister() on teardown.

      useEffect(() => Orion.commands.register([{ id: 'save', title: 'Save', run: () => save() }]), []);
