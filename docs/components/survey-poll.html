Survey and Poll

<o-survey> renders a multi-page survey from a JSON schema — single/multiple choice, text, rating, NPS, emoji scale, Likert/matrix, dropdown, ranking and date questions, with required fields, skip logic and a progress bar. <o-poll> is a lighter single-question poll with animated result bars. Both build on Orion.validate and Orion.conditional.

Realistic example: customer satisfaction survey

Every question type in one flow, including a page ("Tell us more") with a text field that only appears when "Other" is picked.

Skip logic across pages

"Are you a new customer?" — answering "No" skips the entire "Your first experience" page (a page-level skipIf), landing directly on the last page.

Results summary helper

Orion.survey.summarize(schema, responses) aggregates an array of collected answer-objects into per-question counts, averages and an NPS score — handy for building a results dashboard.

<o-poll>

Results-only display

Seed votes with server totals and set results-only to show a live results widget with no voting UI.

Programmatic factory — Orion.polls()

Orion.polls(target, opts) is this package's poll factory — Orion.poll (singular, no "s") is a different thing: the realtime package's live-refresh helper (Orion.poll(fn, options) for repeatedly calling a function on an interval). Don't confuse the two — they happen to share almost the same name.

Orion.polls(target, opts) configures target if it's already an <o-poll>, otherwise creates one inside it and assigns opts as properties.

typesingle · multiple · text · longtext · rating · nps · emoji · matrix (alias likert) · dropdown · ranking · date
options[]single/multiple/dropdown/ranking: strings or { value, label, goTo } — goTo branches straight to another page's id.

showIf / skipIfSame condition shapes as the conditional package; question-level conditions hide/disable just that question, page-level conditions decide whether next() visits that page at all.

Keyboard

Every question renders real native radios/checkboxes/inputs, so standard form keyboard behavior applies throughout. Enter in a text question advances the page. Ranking questions have Up/Down buttons on each row and also respond to ArrowUp/ArrowDown while their drag handle is focused.
