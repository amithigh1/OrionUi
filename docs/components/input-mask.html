Input mask

Caret-preserving pattern masks for plain <input> elements, built-in presets for dates, cards, IBANs and more, plus a character/word counter and textarea autosize. The native input stays the form field — see Form controls for the base input styles.

Basic pattern

Add data-o-mask with a pattern. Tokens: 9 digit, a letter, * letter or digit, \ escapes the next character, [ ] marks an optional part.

Presets

Pass a preset name to data-o-mask: date time datetime phone-us card cvc expiry iban ip mac postcode-us ssn hex-color. Card masks reformat automatically once the card type is detected (Amex, Visa, …) and validate with the Luhn checksum; IBAN validates with the ISO 13616 checksum; date/time honour data-o-mask-format.

JS API

Configure or read a mask programmatically with Orion.mask(el, pattern | options). The controller exposes .value, .unmasked, .complete, and fires o-mask-complete on the input once the pattern is fully satisfied (el.dataset.unmasked is always kept in sync).

Character counter

data-o-counter works on any <input> or <textarea>, reading maxlength automatically or data-o-counter-max. data-o-counter-mode="words" counts words instead of characters; data-o-counter-warn sets when the near-limit color kicks in.

Textarea autosize

data-o-autosize="8" grows a textarea from its rows up to 8 rows as the user types (no limit when the value is empty). Combine with data-o-counter freely.

Attributes

AttributeDescription
data-o-maskPattern string, preset name, fn:globalFnName, or empty (use data-o-mask-regex as a plain filter).
data-o-mask-regex / -flagsFree-form filter: only text matching the (anchored) regex is accepted.
data-o-mask-placeholderGuide character (single char fills every empty slot) or a full guide string like DD/MM/YYYY.
data-o-mask-formatDate/time token format for the date / time / datetime presets.
data-o-mask-caseupper or lower.
data-o-mask-completeRegex (string) tested against the unmasked value to decide completeness.
data-o-mask-tokensJSON map of extra pattern tokens, e.g. {"h":"[0-9a-f]"}.
data-o-mask-validate="false"Disable the built-in incomplete/invalid custom validity message.
data-o-counterCounter behavior; options: -max, -mode (chars|words|remaining), -warn, -target.
data-o-autosize="N"Textarea grows up to N rows.

JS API

MemberDescription
Orion.mask(el, pattern | options)Create or reconfigure a mask controller.
controller.value / .unmasked / .completeCurrent formatted value, raw digits/letters, and whether the pattern is satisfied.
controller.set(v) / .update(opts) / .toDate() / .destroy()Programmatic set, reconfigure, parse a date preset, remove the mask.
Orion.mask.get(el) / .unmask(el)Look up an existing controller / read the unmasked value.
Orion.mask.format(value, pattern|preset|options)One-shot formatting without attaching to an element.
Orion.mask.cardType(n) / .luhn(n) / .iban(v)Standalone validators used by the card and IBAN presets.
Orion.counter.count(text, 'words'|'chars') / .refresh(el)Counting helper / force-refresh a counter.
Orion.autosize(el)Force a textarea to refit (after setting .value in code).
