OTP input

<o-otp> renders one box per character for verification codes. Typing auto-advances, pasting distributes the code across the boxes, the first box has autocomplete="one-time-code" for iOS/Android SMS autofill, and the WebOTP API is used automatically when the browser supports it.

Basic

Separator & length

Character type & masking

type restricts input to numeric (default), alpha or alphanumeric (auto-uppercased); mask hides characters like a password field.

Resend countdown

resend-seconds shows a live countdown, then a "Resend code" button. Listen for the cancelable o-resend event to trigger your API call before the countdown restarts.

Verify & show an error

Call setError() when the server rejects the code — the boxes turn red, shake, and the message shows until the next edit.

Props / attributes

PropTypeDescription
valueStringThe entered code.
lengthNumberNumber of boxes (default 6).
typeStringnumeric (default) | alpha | alphanumeric.
maskBooleanHide entered characters.
separatorNumber | StringA group size (3 → every 3 boxes) or explicit positions ("3,6").
autofocusBooleanFocus the first empty box on connect.
resend-secondsNumberCountdown length; 0/omitted hides the resend row.
webotpBooleanUse the WebOTP API when available (default true).
invalidBooleanReflects the error state (set via setError()).
size, name, required, disabled, readonly, texts—Standard.

Methods

MethodDescription
.focus()Focus the first empty box (or the last one when full).
.clear()Empty all boxes.
.shake()Play the shake animation.
.setError(msg?)Mark invalid, shake, and show a message (default: "The code is incorrect").
.restartTimer(seconds?)(Re)start the resend countdown.

Events

EventDetail
input, changeNative, mirrored from the boxes.
o-change{ value }
o-complete{ value } — every box is filled.
o-resendCancelable; call preventDefault() to stop the countdown from restarting (e.g. while an API call is in flight).
