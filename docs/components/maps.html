Map

<o-map> is a small slippy map written from scratch — Web Mercator projection, its own tile pyramid, pointer/wheel/pinch/keyboard navigation, markers with clustering, popups and an SVG vector layer. No Leaflet, MapLibre or OpenLayers. Every demo below uses deterministic offline placeholder tiles by default so it works without a network connection; flip the switch to see real OpenStreetMap tiles.

Basic map

Set lat, lng, zoom and a tiles source. tiles="offline" draws deterministic placeholder tiles on a canvas (a grid, coordinate label and a few land shapes) — no network, so screenshots and tests never flake. tiles="osm" uses the real OpenStreetMap tile server, and any URL template (https://…/{z}/{x}/{y}.png) or your own function works too.

OpenStreetMap tile usage policy: the public tile.openstreetmap.org server is for light, low-volume evaluation only — no automated bulk downloading, and you must show the “© OpenStreetMap contributors” attribution (Orion does this for you automatically). For a real application, run your own tile server (e.g. from an .mbtiles/.pmtiles extract) or use a commercial provider (MapTiler, Mapbox, Stadia, Geoapify, …) and point tiles at its URL template, e.g. tiles="https://api.maptiler.com/maps/streets/{z}/{x}/{y}.png?key=YOUR_KEY", updating attribution to match their terms.

Markers

Pass an array to markers (or call addMarker/updateMarker/removeMarker/setMarkers). A marker can use the default pin, a solid color, a built-in icon name or fully custom html; draggable markers fire o-marker-drag-end.

Popups

Give a marker (or a vector layer) a popup — a trusted HTML string or a function (marker) => html. Click the marker or press Enter/Space while it has focus (markers are real, focusable buttons). The map pans to keep an opened popup in view, and Escape closes it.

Clustering & a store locator

With more than one marker close together, cluster (on by default) groups them into a count bubble. Click a cluster to zoom into it, or spiderfy it at the maximum zoom. The side list stays in sync with the map — a classic store-locator layout.

Accessibility: every map also exposes a “View markers as a list” button (in the control stack) that opens a full keyboard/screen-reader-friendly list of every marker — useful when a marker sits under another one or off-screen.

Vector layers & GeoJSON

An SVG overlay draws polylines, polygons, circles (metre radius) and rectangles, all repositioned as you pan/zoom. addGeoJSON() decomposes a FeatureCollection into markers/layers for you, with an optional style(feature) and popup(feature) function.

Geolocation

The locate control (controls="locate") asks for the device position, shows a pulsing dot with an accuracy circle and centres the map. Orion.geo also works standalone for distance, bearing and formatting.

Dark mode & RTL

The chrome (controls, popups, attribution, scale bar) follows the page theme automatically because it only uses design tokens. Tiles do not — set tile-filter="dark" to invert/desaturate them for a dark UI (shown above as a toggle). Controls and the scale bar switch sides automatically under dir="rtl".

Frameworks

Set markers/base-layers as a property for live objects (React/Vue/Angular), or as a JSON attribute string. Listen for o-* events through a ref. tiles as a function property lets you plug in any raster/vector source.
