Date Range

<o-daterange> picks a start and an end date: two months side by side (one on phones), a live hover preview, quick presets, minimum / maximum length, an apply / cancel footer (or instant), optional times and typed start / end inputs. It submits start/end or two named fields.

Basic with presets

Click a start day, then an end day — the band previews the range while you hover (or move with the keyboard) and the footer shows the length. Nothing changes until Apply; Cancel, Esc or clicking outside restore the previous value. The built-in presets are Today, Yesterday, Last 7 / 30 / 90 days, This / Last month and This year.

Instant mode & custom presets

instant commits as soon as the range is complete (and when a preset is clicked). presets takes built-in keys (today yesterday last7 last30 last90 thisWeek thisMonth lastMonth thisYear) and/or objects { label, value: [start, end] | () => [start, end] }; presets="false" hides the list.

Booking rules: min / max length & unavailable dates

min-days / max-days count days inclusively; while choosing the end, days that would break the rule are disabled. min, max and disabled-dates work like in Date Picker, and highlighted marks special days.

With times

time adds start / end time pickers under the calendar (defaults 00:00 → 23:59); values become YYYY-MM-DDTHH:mm.

Forms

With name the value is submitted as start/end; with name-start and name-end as two fields. required needs both ends; typed dates are validated (format, order, limits).

Events & methods

Keyboard

KeyAction
↓ / F4 (input)Open and focus the calendar (editing that end).
Enter (input)Parse the typed dates; with the panel open, apply.
Arrows · Home / End · PageUp / PageDown (Shift: year)Move in the calendar; the range previews to the focused day.
Enter / SpaceSet the start, then the end.
TabStart input → end input; inside the panel cycles presets, calendar, times and footer.
EscCancel (restore the previous range) and close.
