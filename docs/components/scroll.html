Scroll

Small scroll-driven helpers: a <o-back-to-top> button, a <o-scroll-progress> bar, a data-o-spy scroll-spy behavior for in-page navigation, and a data-o-sticky-actions behavior that adds a shadow to a sticky action bar once it is actually pinned.

Back to top

target points it at a specific scroll container instead of the window; progress draws a ring showing how far through the target the user has scrolled.

Scroll progress

Scroll-spy

data-o-spy="#selector" on the scrolling element highlights the nav link whose target heading is in view and smooth-scrolls to a section when its link is clicked, accounting for data-o-spy-offset (useful with a sticky in-box header).

Sticky action bar

data-o-sticky-actions adds .is-stuck (a shadow) to a position: sticky bar once it is actually pinned — scroll the box below.

API

<o-back-to-top>

AttributeTypeDescription

Method: scrollToTop(). Event: o-click.

<o-scroll-progress>

AttributeTypeDescription

Behaviors

AttributeDescription
data-o-spy="#nav" [data-o-spy-offset="80"]Scroll-spy on the element carrying the attribute (its nearest scrollable box, or the window for <body>). Supports nested <ul> lists (ancestor <li> get .has-active).
data-o-sticky-actionsAdds/removes .is-stuck on a position: sticky element while it is pinned.

CSS variables

--o-progress (0–1, back-to-top ring), --o-bottom-nav-space (used to offset the back-to-top button above a bottom nav on small screens).
