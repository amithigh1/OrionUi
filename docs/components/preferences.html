Preferences

<o-preferences> is a self-contained settings panel — theme mode, density, high contrast, text size, a reduced-motion override, language and notification toggles — that can be embedded inline or opened in a drawer with Orion.preferences.open().

Persistence

Reads/writes through Orion.prefs.get/set when the services-b package is present, localStorage (orion:preferences) otherwise. Theme mode, contrast and font scale are already persisted by Orion.theme itself; density and the motion override are persisted here.

Limitation

The reduced-motion override forces every CSS transition/animation to ~0 duration (html.o-motion-reduce), but cannot reach JS-driven Orion.animate() calls, which only check the OS-level prefers-reduced-motion media query. A one-line core change (reducedMotion() also checking a runtime flag) would close that gap — see this package's final report.
