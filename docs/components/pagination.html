Pagination

<o-pagination> is a standalone, accessible pager: page number buttons with smart ellipsis, a rows-per-page selector, a "go to page" jump box, first/last edges, four visual variants and full keyboard support. It does not hold any data itself — it just tracks total / page / page-size and tells you when they change, so it can drive a table, a grid, a gallery or anything else.

Basic

Set total and page-size (or just page-size and let total update as data changes); the page-count is derived. show-total renders the "1–10 of 245" range.

Variants

variant: default (page numbers with ellipsis), outline (same, outlined active page), simple ("Page 3 of 24" only) and compact (an editable page number / total, ideal for narrow toolbars).

Sizes, edges & disabled

size="sm" shrinks the page links. edges adds first/last (double-chevron) buttons. disabled greys out and disables every control.

Page-size selector

page-sizes (comma list or JSON array) shows a "rows per page" select next to the total. Changing it keeps the first visible row on screen by adjusting page.

Jump box & alignment

show-jump adds a "Go to" number input (Enter to jump). align (start | center | end | between) positions the pager inside its container — between pushes the nav to the far side when combined with a total / page-size (as used above).

Driving a list

<o-pagination> carries no data — listen for o-change (or call go()) and re-render your own rows. This example paginates 97 people entirely on the client.

Events & methods

Every button click calls go(), which fires a cancelable o-before-change then o-change. Try vetoing a change, or drive the pager programmatically.

Text overrides & RTL

Every label goes through t() (i18n keys under pagination.*) and can be overridden per instance with texts. Horizontal arrow keys and the layout follow the ambient dir automatically — toggle RTL with the header button to see the pager mirror.

Keyboard

KeyAction
TabMoves focus onto the pager; the current page button is the tab stop.
→ / ←Move focus to the next / previous enabled button (flips with dir="rtl").
Home / EndFocus the first / last enabled button.
Page Down / Page UpGo to the next / previous page from anywhere in the pager.
EnterActivate the focused button; in the jump box or the compact variant's input, navigate to the typed page.

ARIA: the control is a <nav aria-label="Pagination"> (override with label or texts.label); the current page button has aria-current="page"; every button has a descriptive aria-label ("Page 4", "Next page"...); the total/range text updates live.

Events

EventDetailDescription
o-before-change{ page, pageSize }Cancelable; fired before a user-initiated navigation (button, jump box or Enter on the compact input) is applied. preventDefault() to veto.
o-change{ page, pageSize }Fired after the page (or, via the size selector / setPageSize(n, true), the page size) changed because of user interaction.

Methods

MethodReturnsDescription
go(page)booleanpage is a 1-based number or 'prev' | 'next' | 'first' | 'last'. Clamps to range, fires o-before-change/o-change. Returns false when disabled, vetoed or the page did not change.
next() / prev()booleanShortcuts for go('next') / go('prev').
setPageSize(n, user = false)voidChanges pageSize, adjusting page so the first visible item stays on screen. Pass user: true to also fire o-change (the built-in select does this).

JS

Orion.pagination.items(page, pages, siblings = 1, boundaries = 1) — the pure function that computes the page-button layout (numbers and 'gap' markers) used internally; handy for building a custom pager UI.

CSS classes

.o-pagination (the <ul> of page links; add .o-pagination-outline / .o-pagination-sm yourself when styling raw markup), .o-page-link (.is-active), .o-page-ellipsis, .o-pager-nav, .o-pager-total, .o-pager-size, .o-pager-jump, .o-pager-current (the compact variant's input), .o-pager-edge (first/last buttons), state class .is-disabled on the host.

Frameworks

Set total, page, pageSize, pageSizes and texts as properties (React 19, Vue :page-sizes, Angular [pageSizes]); with React 18, arrays/objects may be passed as JSON strings. Listen to o-change (Vue @o-change, Angular (o-change), React via a ref) rather than watching page, since programmatic changes to the property do not emit events.
