Wizard

<o-wizard> turns a set of <section data-step> children into a multi-step form: a stepper header, Back/Next/Finish buttons, per-step validation (via Orion.validate), optional steps, and an auto-generated review step.

Realistic example: job application

Step 2 embeds an <o-repeater> for repeatable work-experience rows (see Dynamic forms). Step 3 is optional (Skip is shown). The Review step is generated automatically from every field's label/value.

Free navigation & vertical layout

linear="false" lets the visitor click ahead to any step immediately (no per-step gate).

Draft persistence

Add persist="a-unique-key" to remember the current step (and, when the autosave package is loaded, the field values too) across reloads. restore="prompt" (the default) shows a restore banner instead of restoring silently.

<o-wizard persist="job-application" restore="prompt">…</o-wizard>

API

PropDescription
current0-based active step index.
linearDefault true: can't jump ahead of the furthest step reached.
validateDefault true: runs Orion.validate on the current step before advancing.
persist / restoreStorage key; restore is 'auto' or 'prompt' (default).
orientation / stepperVariantPassed through to the internal <o-stepper> (see Stepper).
nextText / backText / finishText / skipTextButton label overrides.
guard(from, to, wizard)Return (or resolve) false to veto a navigation.
MemberDescription
next() / prev() / skip() / goTo(i, opts?)All return Promise<boolean> (whether the navigation happened).
finish()Validates every step, emits o-finish, then calls form.requestSubmit() if inside a <form>.
reset()Resets the form, clears persistence, returns to step 0.
review()Returns [{ index, title, fields: [{ name, label, value }] }] — what the auto-generated review step renders.
o-step-change { from, to, direction, waitUntil(promise) }Cancelable; call waitUntil with a promise resolving false to block.
o-finish { data }Cancelable — call preventDefault() to stop the automatic form submit.
o-step { index, from } / o-resetFired after every navigation / after reset().

Section attributes: data-step="Title" (required) · data-icon · data-description · data-optional · data-review.

Keyboard

KeyAction
Enter (in a text field)Advances to the next step, or Finish on the last step.
Arrow keys on the step headerNavigate steps when clickable (inherited from the internal stepper).
