Modal

<o-modal> is a native <dialog> in the browser top layer (never clipped by its container) with focus trap and return, scroll lock, nesting, a cancelable close and enter/leave animations. Open it with an attribute, a data action or the Orion.modal() factory.

Basic

Children become the body; an element with slot="footer" becomes the footer. data-o-toggle="modal" opens it and data-o-dismiss="modal" closes it (optionally with data-o-value).

Sizes

size="sm | md | lg | xl | full" — 25rem, 35rem (default), 50rem, 71.25rem and the full viewport width. On small screens every size fits the viewport with a gutter.

Centered, static & forced choice

centered centers vertically. static keeps the modal open when the backdrop is clicked (it shakes instead). closable="false" removes the close button and ignores Escape and the backdrop, so the user must pick an action.

Long content

By default the whole dialog scrolls inside the viewport. With scrollable only the body scrolls and the header and footer stay visible.

Nested modals

A modal opened from inside another stacks above it. Escape closes only the top-most one, and closing a parent also closes its children.

Form with validation

Validate before closing: the Save button checks the form and the modal is only closed with the data when it is valid. A cancelable o-before-close asks before discarding unsaved changes.

Fullscreen

fullscreen="sm" (or md, lg) makes the modal edge-to-edge below that breakpoint — ideal for forms on phones. fullscreen with no value is always fullscreen.

Draggable & loading

draggable lets users move the dialog by its header (it stays inside the viewport). The loading property shows an overlay spinner while work is in progress.

Programmatic modal

Orion.modal() builds a modal on the fly and returns a handle with a result promise. Buttons can be async (the button shows a spinner) and submit: true validates the form in the body and resolves with its data.

      const m = Orion.modal({
        title: 'Invite member',
        content: document.querySelector('#invite-form-template').content.cloneNode(true),
        size: 'md', centered: true, backdrop: 'static', fullscreen: 'sm',
        buttons: [
          { text: 'Cancel', value: null },
          { text: 'Invite', variant: 'primary', submit: true, onClick: (handle, event, data) => api.invite(data) },
        ],
        onClose: (value, reason) => console.log(value, reason),
      });
      m.setLoading(true); m.setTitle('Inviting…'); m.close('done');
      const value = await m.result;

Keyboard

KeyAction
Tab / Shift+TabMove focus; it stays inside the dialog.
EscapeClose the top-most modal (inner menus and pickers close first).
Enter / SpaceActivate the focused button.

Frameworks

React 19, Vue and Angular can bind open as a property (<o-modal open={isOpen}>) and listen to o-close/o-closed to sync state back. Children are moved into the dialog body: keep one stable wrapper element per slot when the framework re-renders them.
