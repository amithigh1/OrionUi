Print Preview

Orion.printPreview(target) shows any element, HTML or dataset as real paper pages before printing: choose the paper size, orientation, margins, scale and background graphics, see exactly where pages break, then print through a hidden frame with matching @page rules — or download a PDF for tabular data. Headers and footers get page numbers.

Preview an element

The element is cloned (form values kept, canvases turned into images, components flattened to their rendered markup) and split into pages between blocks, list items and table rows. Table headers repeat on every page, and break-before: page / break-inside: avoid are honoured.

Print a dataset

Orion.printTable(rows, columns, options) builds a clean report (title, generated date, record count, bordered table) and opens the preview; the toolbar’s Download PDF button produces the same report with O.export.pdf. Pass preview: false to go straight to the print dialog.

HTML, headers & footers

Pass trusted HTML directly. header and footer accept text with {page}, {pages}, {title}, {date} and {time} tokens, an object with left / center / right slots, or a function returning text or a node.

API

Function / optionDescription
Orion.printPreview(target, opts)Opens the preview. target: element, selector, trusted HTML string, or { rows, columns, title, subtitle }. Returns { el, pages, print(), close(), update(opts), closed: Promise }.
Orion.printTable(rows, columns, opts)Report preview for a dataset; preview: false prints immediately.
Orion.printPreview.print(target, opts)Print without the preview (native pagination, same paper settings).
titleDocument title (header default, print job name, PDF title).
paper'A4' | 'Letter' | 'Legal' | 'A3' | 'A5' or [width, height] in mm. Default A4.
orientation'portrait' | 'landscape'.
margins'default' (15 mm), 'narrow' (8), 'wide' (25), 'none', a number of mm or { top, right, bottom, left }.
scaleContent scale (1 = 100%) or 'fit' to shrink wide content to the page width.
backgroundPrint background colours and images (default true).
header, footer, showPageNumbersSee above. Defaults: title and date in the header, “Page X of N” in the footer. false hides one.
onPrint({ pages, paper, orientation })Called before printing; return false to cancel.
pdfShow “Download PDF” for tabular data (default true; needs rows/columns or a single table).
Orion.printPreview.paginate(flowEl, pageHeightPx)The measure-then-place pagination algorithm used internally, exposed for advanced/custom preview UIs.

Keyboard

KeyAction
TabMoves through the toolbar controls and the page area (focus stays in the dialog).
Ctrl / ⌘ + PPrint the previewed pages.
Arrow keys / Page Up / Page DownScroll the pages when the page area has focus.
EscClose the preview.

Notes

The preview measures content at the paper’s real size (96 CSS px per inch), so what you see is what the printer receives: the printed pages are the preview pages. HTML passed as a string is inserted as-is — sanitize user content with Orion.sanitize() first.
