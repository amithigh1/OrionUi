FAB

.o-fab is a plain circular (or extended, or mini) floating action button. For a set of related actions, <o-fab> turns it into a speed dial: click (or ↑/keyboard) to reveal labelled child actions in a direction of your choice, including a radial fan.

Plain buttons

Speed dial

Click the button (or focus it and press the arrow key matching direction). Arrow keys move between actions, Home/End jump to the first/last, Escape closes it.

<o-fab>

AttributeTypeDescription
iconStringTrigger icon when closed (becomes a close "×" while open). Default plus.
labelStringaria-label for the trigger.
directionup｜down｜start｜end｜radialLayout of the child actions. Default up.
backdropBooleanDim the page and close on click while open.
radiusNumberFan radius in px for direction="radial". Default 88.
openBooleanReflected; property is isOpen (el.open = true also works).

<o-fab-action>

AttributeTypeDescription
icon / labelStringIcon and text (label also becomes the aria-label).
hrefStringNavigates after the dial closes, unless o-select is prevented.
disabledBooleanSkipped by the keyboard.
