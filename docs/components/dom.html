DOM Manipulation & Utilities

A jQuery-style chainable API (Orion.$), an element builder, delegated events and a set of everyday utilities. You don't need another helper library.

Build your own components

Orion's component base classes are public, so your own widgets get the same lifecycle, props, form integration, theming and i18n:

      const { OElement, define, html } = Orion.core;
      class HelloCard extends OElement {
        static props = { name: { type: String, default: 'World' } };
        render() { this.innerHTML = String(html`<div class="o-card o-card-body">Hello, ${this.name}!</div>`); }
      }
      define('hello-card', HelloCard);   // <hello-card name="Ada"></hello-card>
