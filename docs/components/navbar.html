Navbar

.o-navbar is a responsive top bar: brand, links (with dropdown menus), a search box, action icons and a user menu. It collapses into a hamburger drawer below 992px, and offers a sticky / transparent-until-scroll style and a hide-on-scroll-down option. Dropdowns reuse the dropdown component's data-o-toggle="dropdown", so they get full keyboard support for free.

Basic

Sticky, transparent & hide-on-scroll

.o-navbar-transparent starts see-through (for a hero header) and becomes solid once scrolled; data-o-navbar-autohide slides the bar out of view on scroll-down and back in on scroll-up.

Frameworks & dropdowns

Item and user-menu dropdowns are plain data-o-toggle="dropdown" triggers next to a .o-dropdown-menu — see the dropdown docs for submenus, checkbox/radio items and the full keyboard map. Mount the navbar the same way in React/Vue/Angular as any other markup; the collapse and scroll behaviors attach automatically via a MutationObserver, so they work even when the framework renders the navbar after the initial page load.
