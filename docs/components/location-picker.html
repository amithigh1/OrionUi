Location Picker

<o-location-picker> combines <o-map> and <o-address-input> into one form control for picking a point: drag the map under a fixed centre crosshair (default) or drag a marker, search an address, or use the device location. It reverse-geocodes the chosen point and submits lat,lng plus the address text with the form. Every demo on this page uses offline tiles and the offline mock geocoder by default, so it works with no network connection.

Basic (crosshair mode)

The default mode="crosshair" keeps a pin fixed at the centre of the map; drag the map underneath it. The coordinates and reverse-geocoded address update as you drag (debounced) and once more when you stop.

Marker mode

mode="marker" shows a draggable pin instead: click anywhere on the map to move it, or drag it directly. radius (metres) draws a circle around the point — useful for "service area" style pickers.

Form integration & required validation

The submitted value is name="lat,lng" plus <name>-address (or address-name) with the label text. required is enforced like any other form control.

Programmatic control & custom dataset

setLocation(lat, lng, { address }) moves the picker like a user pick (fires o-change). This demo also swaps in the same offline fixture used on the Address Autocomplete page, so the search box and the reverse-geocoded label both come from your own dataset instead of the built-in mock.

Device location

The crosshair button next to the search box calls Orion.geo.current() (wrapping navigator.geolocation) and flies the map there.

Keyboard & accessibility

The address field and its suggestions follow <o-address-input>'s keyboard model. The embedded map is a full <o-map> — arrow keys pan, +/- zoom, and in mode="marker" the pin is a real draggable, focusable button. The coordinates readout is a button that copies lat, lng to the clipboard.
