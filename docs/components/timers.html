Timers

<o-countdown> counts down to a target timestamp and <o-stopwatch> counts up with lap splits. Both recompute from Date.now() on every tick, so they never drift even if the tab was backgrounded, and both work with a keyboard and a screen reader out of the box.

Product launch countdown

Four variants: tiles (default), inline, flip and ring. The countdown recalculates from the target time on every tick — try throttling the tab or switching away and back, the numbers stay exact. o-complete fires once, when the target is reached.

Short countdown & restart

A 15-second demo so you can see o-complete fire without waiting. restart(to?) sets a new target (or reuses the current one) and starts again.

Stopwatch with laps

Space to start/pause, L to lap while running, R to reset while stopped. The fastest and slowest laps are highlighted once there are three or more.

Persisted stopwatch

Set persist to a storage key to keep the elapsed time and laps across reloads (the running state itself still needs an explicit start() after a reload, since silently auto-resuming a background timer without the visitor asking is surprising).

<o-countdown> API

Prop / attributeTypeDescription
toDate | stringTarget timestamp.
formatstringdhms (default) · hms (hours roll past 24) · ms (minutes roll past 60).
variantstringtiles (default) · inline · flip · ring.
labelsbooleanShow unit labels (days/hours/…) under each value. Default on.
autostartbooleanStart as soon as to is set. Default on.
pause-on-hiddenbooleanStop the render loop while the tab is hidden (the underlying time is never lost — it's always recomputed from to). Default on.
complete-textstringText shown (and announced) once the countdown reaches zero.

<o-stopwatch> API

Prop / attributeTypeDescription
autostartbooleanStart immediately on connect.
formatstringhms (default) or ms.
centisecondsbooleanShow a de-emphasised .centiseconds segment. Default on.
persiststringlocalStorage key; when set, elapsed time and laps survive a reload.

Methods

MethodDescription
start() / resume()Start or resume from the current elapsed time.
pause()Stop counting, keeping the elapsed time.
toggle()Start/pause (bound to Space).
lap()Records a split (bound to L while running).
reset()Clears elapsed time and laps (bound to R while stopped).
getElapsed()Current elapsed milliseconds.
getLaps(){ n, lap, total }[] in milliseconds.
