Drawer

<o-drawer> is an off-canvas panel built on the same native-<dialog> foundation as <o-modal> (it is in fact a subclass): focus trap and return, scroll lock, nesting, a cancelable close, and swipe-to-close on touch. Slides in from any of the four edges.

Placement

placement="start | end | top | bottom" — logical, RTL aware (end is the right edge in LTR, left in RTL).

Sizes

size="sm | md | lg | xl | full" (18/24/32/44rem width, or 100%) or any CSS length (e.g. size="480px").

Modeless, static & push

backdrop="false" makes the drawer modeless (page stays interactive, no focus trap or scroll lock). push additionally shifts a target element's margin instead of overlaying it. static keeps a normal (modal) drawer open on backdrop click.

Mobile navigation pattern

A start drawer is the standard responsive sidebar-to-drawer pattern: keep the sidebar visible on desktop, collapse it into a drawer below a breakpoint.

Form & loading

Drawers support the same slot="footer", closable and loading behavior as modals.

Orion.drawer()

Same handle shape as Orion.modal(), built with buttons and a result promise.

Keyboard & touch

InputAction
Tab / Shift+TabCycle focus inside the panel (trapped, unless modeless).
EscapeClose (when closable); inner popups close first.
Swipe towards the edgeClose (a fast flick or dragging past 30% of the panel size commits it).

CSS variables

--o-drawer-size (width for start/end), --o-drawer-vsize (height for top/bottom), --o-drawer-vmax (max height, default 85vh).
