Data Table

<o-datatable> is a zero-dependency data grid: client or server processing, multi-column sorting, global search with highlighting, faceted filters, pagination, locale-aware formatting, responsive card and priority modes and full ARIA grid keyboard navigation. It handles 10,000 rows client-side and 100,000 with virtual scrolling.

Basic usage

Give it columns and rows (as properties or JSON attributes). Click a header to sort (Shift+click adds a level), type in the search box, use the filter icon in a header, or pick a page size.

Declarative (JSON attributes)

Everything that is an array or object also accepts JSON in attributes, so the table works from plain HTML, server templates or React 18 (which sets attributes). Columns can be plain strings.

Programmatic factory — Orion.datatable()

Orion.datatable(target, config) configures target if it's already an <o-datatable>, otherwise creates one inside target and assigns config as properties — useful when the whole setup (columns, rows, callbacks) comes from one object built in JS rather than assigned property-by-property.

      const dt = Orion.datatable('#host', { columns: [...], source: async (query) => fetch(...).then(r => r.json()) });
      // If #host is already an <o-datatable>, this just Object.assign()s config onto it.

Column types & formatting

Built-in types format with the current locale through Orion.format: number, currency, percent, date, datetime, boolean, badge, progress, avatar, link, html and actions. Use format (Intl options or a function) or render(row, value) for anything custom — returned HTML strings are sanitized unless the column sets html: true.

Sorting

Sorting is tri-state (ascending → descending → none). Hold Shift to sort by several columns; the order is shown next to each arrow. Set the initial order with sort, provide sortFn for custom comparisons, and listen to o-sort.

Search, filters & facets

The search box matches every word against raw and formatted values and highlights hits. Filterable columns get a filter menu with the right control for their type — text, select, faceted multi-select with counts, number range, date range or boolean. Active filters appear as chips with a result count and Clear all. Toggle Filters for an inline filter row.

Advanced search hook

Pass any predicate as filterFn (for example from a query builder). It combines with search and column filters and shows as a removable chip.

Pagination

Pagination uses <o-pagination> and shows “Showing x–y of z”. Set page-size, page-sizes and page; turn it off with pagination="false" (all rows) or use virtual scrolling.

Responsive tables

responsive="scroll" (default) scrolls horizontally with frozen columns and edge shadows. stack turns rows into labelled cards below the md breakpoint (or in containers narrower than 480px). priority hides low-priority columns (priority: 1 is kept longest) as space runs out and shows them in an expandable row.

Enhance a plain table

Add data-o-table to static markup for sorting, search and pagination without writing JavaScript. Cells can carry a data-sort value; <th data-sort="false"> opts out.

Frameworks

Set columns, rows, source and callbacks as properties (they may be set before the element upgrades). Custom events are o- prefixed.

      // React 19
      <o-datatable ref={ref} columns={columns} rows={rows} selectable="multi" />
      useEffect(() => { const el = ref.current; const f = e => setSelected(e.detail.rows); el.addEventListener('o-select', f); return () => el.removeEventListener('o-select', f); }, []);

      // Vue 3  (compilerOptions.isCustomElement = t => t.startsWith('o-'))
      <o-datatable :columns="columns" :rows="rows" @o-row-click="open($event.detail.row)" />

      // Angular  (schemas: [CUSTOM_ELEMENTS_SCHEMA])
      <o-datatable [columns]="columns" [source]="load" (o-select)="onSelect($event)"></o-datatable>
