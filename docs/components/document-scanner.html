Document Scanner

<o-doc-scanner> turns a phone/webcam photo (or an uploaded image) of a paper document into a clean, perspective-corrected page: automatic edge detection with draggable corner handles and a magnifier loupe, filters, rotate, a reorderable multi-page session, and PDF/image export. It is also what <o-camera mode="document"> mounts internally.

Basic

Start the camera or upload an image; either drops you into the corner-editing step with edges already auto-detected (falling back to the full frame when no quadrilateral is found). Drag a handle (or focus it and use the arrow keys — Shift for a bigger step) to adjust, then "Add page".

A no-camera fixture: loadImage()

loadImage(source) accepts a File, Blob, data URL, <img>, <canvas>, <video> or ImageBitmap and drops straight into corner-editing — no camera involved. This demo draws a synthetic "photo of a document on a desk" (a light quadrilateral, rotated and skewed, on a dark background) so auto-detect has real edges to find.

Filters, rotate & multi-page

Each page in the session gets its own filter (original, grayscale, bw — adaptive black & white for text, enhance — contrast stretch) and rotation, set from its thumbnail's own controls, plus reorder (move earlier/later) and remove. setFilter(i, name), rotate(i, deg), reorderPage(from, to) and removePage(i) are also scriptable directly.

scanner.setFilter(0, 'bw');       // 'original' | 'grayscale' | 'bw' | 'enhance'
scanner.rotate(0, 90);
scanner.reorderPage(1, 0);        // move page 1 before page 0
scanner.removePage(0);

Export

exportPDF() builds a single multi-page A4 PDF via Orion.pdf when that package is in the bundle (each page scaled to fit, centered); otherwise it announces that PDF export is unavailable and falls back to exportImages(), which downloads every page as a separate image.

JavaScript API

scanner.pages            // read-only [{ canvas, corners, filter, rotation }, ...]
scanner.corners          // the 4 points [TL, TR, BR, BL] currently being edited, or null
scanner.autoDetect()     // re-run edge detection on the frame being edited -> corners
scanner.applyCorners()   // perspective-crop with the current corners and add the page

Accessibility

Each corner handle is a real, focusable role="button" element with an aria-label ("Top-left corner", etc.) so it can be adjusted without a pointer. Page-added/removed and export status are announced via announce().

Limitations

  • Edge detection is a lightweight JS pipeline (grayscale → blur → Sobel → convex hull), tuned for a document with reasonable contrast against its background; it always falls back to the full frame so the workflow never gets stuck, but manual corner adjustment is sometimes needed on a low-contrast photo.
  • exportPDF() needs the pdf package in the build; without it, exporting falls back to per-page images automatically.
