Booking

<o-booking> is a self-contained appointment booking wizard: pick a service, an available day on an inline calendar, a time slot (grouped morning / afternoon / evening), fill in contact details, and confirm. Availability comes from simple working-hours config or an async availability(date, service) hook for real backends.

Clinic booking

Three services with different durations. Availability is computed locally from working-hours, existing booked ranges and a 2-hour minimum notice — try tomorrow vs. later this week. Submitting calls onBook, an async hook that can reject to show an error (try the email busy@example.com, which the demo hook always declines).

Async availability from a server

Set availability to an async function receiving (date, service) and returning slots as {start,end} Date/ISO pairs, or plain "HH:mm" strings combined with the service's duration. Weekends return no slots here, simulating a real API round-trip.

Programmatic factory — Orion.booking()

Orion.booking(target, config) creates (or configures an existing) <o-booking> inside target and assigns every key of config as a property in one call — handy when the whole setup comes from a single object (e.g. loaded from an API) instead of assigning properties one at a time.

      const bk = Orion.booking('#host', { services: [...], workingHours: {...}, onBook: async (payload) => save(payload) });
      // Equivalent to: const bk = document.createElement('o-booking'); Object.assign(bk, config); host.append(bk);

API

Prop / attributeTypeDescription
servicesarray{ id, title, duration }[]. Zero or one service hides the selector; several render as cards.
working-hoursobject | array{ days:[1..5], start:"09:00", end:"17:00" }, or an array of such ranges. Ignored when availability is set.
slot-minutesnumberGrid step (and default duration when a service doesn't specify one). Default 30.
buffer-minutesnumberGap kept before/after each booked range.
bookedarray{ start, end }[] existing bookings to exclude (local computation only).
min-noticenumberMinutes from now before the earliest offered slot. Default 60.
max-days-aheadnumberHow far into the future the calendar allows picking. Default 60.
availabilityfunctionAsync (date, service) => slots; property only. Overrides local computation.
timezonestringLabel shown to the visitor; defaults to the browser's timezone.
fieldsarrayContact fields to collect, default ["name","email","phone","notes"] (name and email are required).
location / organizerstringIncluded in the confirmation card and the generated .ics file.
on-bookfunctionAsync hook called with { service, start, end, details }; throw/reject to show an inline error and stay on the form. Property only.
