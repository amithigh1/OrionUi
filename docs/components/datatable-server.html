Data Table: server-side

Give <o-datatable> a source(query) function or a url template and it asks your backend for one page at a time. It shows skeleton rows on first load, a progress line on later loads, debounces search, aborts stale requests and keeps selection across pages by row id.

source(query)

The function receives { page, pageSize, sort: [{ key, dir }], search, filters: { key: value } } plus { signal } (an AbortSignal) and resolves to { rows, total }. This demo uses docs.fakeServer with 450 ms latency over 5,000 people. Watch the query log.

      dt.source = async ({ page, pageSize, sort, search, filters }, { signal }) => {
        const res = await fetch('/api/users?' + new URLSearchParams({ page, pageSize, q: search, sort: sort.map(s => s.key + ':' + s.dir).join(',') }), { signal });
        const json = await res.json();
        return { rows: json.items, total: json.count };   // optional: facets: { role: { Admin: 12 } }, aggregates: { salary: 123456 }
      };

url template & mapResponse

Placeholders {page}, {pageSize}, {offset}, {limit}, {search}, {sort}, {sortKey}, {dir} and {filters} are filled in (without placeholders, standard query parameters are appended). Responses shaped like { rows, total }, { data, meta: { total } }, { items, totalCount } or a plain array are understood; otherwise supply mapResponse(json, query). This demo reads a static JSON fixture, so mapResponse does the paging.

Loading, empty & error states

First load shows skeleton rows; later loads keep the rows visible with a progress line and aria-busy. Errors show a message with Retry and fire o-error. An empty result shows a friendly state with Clear all when filters are active.

Infinite loading

With infinite the table loads the next page when you scroll near the end (inside its own height or with the page). It stops when total is reached.

Query & response

FieldTypeDescription
query.pagenumber1-based page.
query.pageSizenumberRows per page.
query.sort{ key, dir: 'asc'|'desc' }[]Multi-column sort, most significant first.
query.searchstringGlobal search text (debounced by search-debounce, default 250 ms).
query.filters{ [key]: value }Text: string · select: string · multiselect: string[] · number-range: { min, max } · date-range: { from, to } (ISO dates) · boolean: true/false.
options.signalAbortSignalAborted when a newer query starts (2nd argument of source).
response.rowsobject[]Rows of the requested page (also data, items, results, records).
response.totalnumberTotal matching rows (also totalCount, count, recordsFiltered, meta.total).
response.facets{ [key]: { [value]: count } }Optional counts shown in filter menus and chips.
response.aggregates{ [key]: value }Optional footer aggregates (columns with aggregate).
