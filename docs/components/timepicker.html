Time Picker

<o-timepicker> is a typed time input with either a dropdown list of times or a scroll-spinner columns panel (hours · minutes · seconds · AM/PM). It follows the locale's 12/24-hour clock, understands “2:30 pm”, “1430” or “14.30”, steps the segment under the caret with the arrow keys, and submits HH:mm.

Basic

Click the field (or press Alt+↓) for the time list; step sets its interval in minutes (15 by default). The list opens scrolled to the typed or current time.

12 / 24-hour clocks & seconds

By default the clock follows Orion.date.uses12h() for the current locale. hour12 forces 12-hour, hour12="false" forces 24-hour; seconds adds a seconds segment (HH:mm:ss).

Scroll-spinner columns

view="columns" opens hour / minute (/ second / AM-PM) columns instead of a list. Each column is a listbox: ↑/↓ change it, ←/→ switch columns, digits jump (“3”, “30”), Enter closes. inline renders the columns in the page.

Business hours (min / max)

min and max trim the list and disable out-of-range column values; a typed time outside the range is reported (rangeUnderflow / rangeOverflow).

Typing & keyboard stepping

Type in any common form — 930, 2p, 2:30 pm, 14.30, 1430 — then press Enter or leave the field. With the list closed, ↑/↓ step the segment under the caret (hours, minutes by step, seconds, AM/PM) and keep it selected, like a native time input.

Forms

Helpers & the columns widget

Orion.pickers.time exposes the parser and formatter used by all pickers, and Orion.TimeColumns is the spinner widget (also used by the datetime modes of Date Picker and Date Range).

const T = Orion.pickers.time;
T.parse('2:30 pm');                                  // { h: 14, m: 30, s: 0 }
T.format({ h: 14, m: 30 }, { hour12: true });        // '2:30 PM'  (locale aware)
T.toISO({ h: 9, m: 5, s: 7 }, true);                 // '09:05:07'
const cols = new Orion.TimeColumns(el, { hour12: false, step: 5, min: '08:00', max: '18:00', onChange: tm => … });
cols.set({ h: 9, m: 30 }); cols.reveal(); cols.focus('m');

Keyboard

KeyAction
↑ / ↓ (input, list closed)Increment / decrement the segment under the caret.
Alt+↓ · F4 · clock buttonOpen the panel (columns: focus the hours column).
Enter (input)Parse the typed time; close the panel.
↑ / ↓ · PageUp / PageDown (list)Move the active time; Enter picks it.
↑ / ↓ · Home / End · PageUp / PageDown (column)Change the column value.
← / → (column)Previous / next column (mirrored in RTL).
Digits · A / P (column)Jump to a value · set AM / PM.
EscClose and return to the input.
