Accordion & collapse

<o-accordion> implements the WAI-ARIA accordion pattern with animated height, single or multiple open items, nesting and four looks. Any markup can collapse with data-o-toggle="collapse", and <o-faq> adds search, highlighting, category chips and FAQPage structured data.

Basic

Only one item is open at a time. Headers are real buttons with aria-expanded / aria-controls; panels are labelled regions.

Multiple, icons & subtitles

multiple lets several items stay open. Items accept icon and subtitle.

Variants

variant="separated" renders each item as a card, plain removes the chrome, flush drops the outer border for use inside cards, and icon-position="start" moves the chevron before the title.

Nested accordions

Accordions can be nested; keyboard navigation and single-open rules apply per level.

Collapse panels (any markup)

Add data-o-toggle="collapse" and data-o-target (or href="#id") to any trigger. Targets use the hidden attribute for their collapsed state. All triggers pointing at a target keep aria-expanded in sync; the target fires o-show / o-shown / o-hide / o-hidden.

Accordion group from plain markup

data-o-parent="#group" on the targets (or triggers) closes the others in the group — handy for Bootstrap-style markup.

      await Orion.collapseToggle('#c-filters');        // toggle
      await Orion.collapseToggle('#c-filters', true);  // show
      document.querySelector('o-accordion').toggle(0);  // accordion item by index or id

FAQ

<o-faq searchable json-ld> filters questions as you type (all words must match the question or answer), highlights matches, opens items whose answer matched, shows category chips when items have a category, and offers Expand all. json-ld emits FAQPage structured data.

From data

Set questions to an array (answers are text; use html for sanitized rich answers).

CSS custom properties

--o-accordion-px and --o-accordion-py set the header / panel padding.

Frameworks

Items without a [data-o-panel] child get their children wrapped once. When React, Vue or Angular render the content, wrap it in <div data-o-panel> so the framework keeps ownership of its nodes. Bind open as a property and listen to o-change. Reduced motion disables the height animation.
