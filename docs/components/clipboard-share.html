Clipboard & Share

Orion.clipboard copies text, HTML, images and Blobs (with an execCommand fallback), reads pasted content, and gives copy buttons a check-mark + toast confirmation. Orion.share uses the native Web Share sheet when available and falls back to a network picker (X, Facebook, LinkedIn, WhatsApp, Telegram, Reddit, Email, QR, Copy link).

Copy

The quickest path is data-o-action="copy" with data-o-value or data-o-target; <o-copy> wraps the same behavior as an icon, button or input+button. Both animate a check icon and announce "Copied!" (or your data-o-copied text).

Paste

Orion.clipboard.onPaste(el, handler) reads text, HTML and files (auto-named images included) from a native paste event — no permission prompt needed, unlike read().

Share

<o-share> and data-o-action="share" open the OS share sheet on mobile/supported browsers, or the network picker below (with a copy-link field and a QR tile when Orion.qr is present).

Copy link (deep links)

Combine with URL state's deep links: Orion.deeplink.copy(name, value) copies a shareable #name=value link using the same clipboard helper.

      await Orion.deeplink.copy('invite', 'team-42');   // copies https://…/page#invite=team-42
