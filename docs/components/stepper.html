Stepper

<o-stepper> is a standalone step indicator — four visual variants, horizontal or vertical, clickable navigation, and an automatic "Step 2 of 4" collapse when the container is too narrow. <o-wizard> (see Wizard) uses one internally as its header. <o-progress-tracker> is a sibling widget for order/shipment-style progress.

Variants

Vertical, errors & disabled steps

Responsive collapse

When the stepper is narrower than it needs to be, it automatically collapses to a progress bar with "Step N of M" (try resizing the window, or see it forced narrow below).

Static markup (no JS)

Navigation via clicks & methods

<o-progress-tracker>

Without a steps prop, it defaults to Ordered / Packed / Shipped / Out for delivery / Delivered.

API

<o-stepper>

PropDescription
stepsArray of strings or { title, description, icon, optional, status }; an explicit status always wins over the computed one.
current0-based index.
orientationhorizontal (default) · vertical
variantdefault · dots · progress · compact (always collapsed)
clickable / responsiveresponsive defaults to true.
MemberDescription
statusOf(i)Returns complete/current/upcoming/error/disabled.
goTo(i) / next() / prev()Navigate programmatically.
setStatus(i, status?)Force (or clear) a step's status.
o-select { index, step }Cancelable; the default handler calls goTo.
o-change { index, previous }Fired after navigation.

Keyboard

KeyAction
Arrow keysMove focus between clickable steps (flips with dir="rtl").
Home / EndFocus the first / last step.
Enter / SpaceActivate the focused step.

Disabled steps are skipped by keyboard navigation; the current step has aria-current="step".
