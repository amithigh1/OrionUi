Data Table: advanced

Customizable columns with persistence, sticky headers, frozen columns, master-detail, tree grids, grouping with aggregates, 100k-row virtual scrolling, infinite loading, saved views and export / import / print.

Columns: choose, reorder, resize, freeze

Open Columns to show, hide, search, move or reset columns and to group rows. Drag a header to reorder it, drag its edge to resize, double-click the edge to fit the content. From the keyboard: focus a header, Ctrl+←/→ resizes and Ctrl+Shift+←/→ moves it. frozen: 'start' | 'end' pins columns with a shadow while scrolled. The header sticks to the page top (sticky-offset="56" clears the docs header). With state-key the layout, sort, filters, page size and density persist in localStorage — reload the page to see it.

Expandable rows & master-detail

detail(row) returns HTML, a Node or a Promise (loaded lazily, cached per row). The header chevron expands all rows on the page. Here each customer expands into a nested <o-datatable> of orders.

Tree grid

tree: { childrenKey: 'children', lazy: async row => children } renders an indented, keyboard-navigable tree (role="treegrid": → expands, ← collapses or goes to the parent). Selecting a node selects its descendants; partially selected parents are indeterminate. Search and filters keep the path to each match. Research loads its teams lazily.

Grouping & aggregates

group-by groups rows under collapsible headers (also available in the Columns panel). Columns with aggregate: 'sum' | 'avg' | 'count' | 'min' | 'max' | fn show per-group values and a footer total over all filtered rows.

Virtual scrolling — 100,000 rows

With virtual only the visible rows (plus a small buffer) exist in the DOM, at a fixed row height per density (or row-height). Sorting, search and filters still run over every row.

Infinite loading

infinite reveals page-size more rows as you reach the end (client data) or fetches the next page from a server source.

Saved views & filters

With state-key the Views menu saves the current columns, order, widths, sort, filters, search, page size, density and grouping under a name, loads or deletes them, and marks one as the default (applied on load). Provide presets with views. getState() / setState() and o-state-change let you store state on your server instead.

Export, import & print

Export offers CSV and JSON built in, Excel and PDF when the data package (Orion.export / Orion.xlsx / Orion.PDF) or a registered Orion.DataTable.exporters[format] is available, plus copy to clipboard, print and print preview — for filtered, selected, current-page or all rows, visible or all columns. Import (importable) reads CSV (and XLSX via Orion.xlsx.read) with a column-mapping preview.
