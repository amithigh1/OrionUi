QR Code

<o-qrcode> and Orion.qr are a from-scratch ISO/IEC 18004 QR encoder: versions 1–40, all four error-correction levels, numeric/alphanumeric/byte(UTF-8) modes with automatic segment planning, penalty-based mask selection, SVG/canvas/PNG output, logo overlays and payload presets (URL, Wi-Fi, vCard, email, SMS, geo). Pair it with <o-scanner> to read codes back — the two are tested against each other end to end.

Basic

value is the only required attribute. ecc (L | M | Q | H, default M) trades data redundancy for density — higher levels survive more damage (and are required once you add a logo).

Module & finder styles, colours

module-style (square | dots | rounded) and finder-style (square | dot | rounded) restyle the code purely with SVG paths — no images. color and background accept any CSS colour, including a token such as var(--o-primary), so a code can follow the current theme; keep enough contrast between the two for the code to stay scannable, and prefer a fixed light/dark pair (not a token that flips in dark mode) for codes meant to be scanned by a phone rather than just viewed on screen.

Logo overlay

A logo object ({ src, size, padding, round }) draws a light backing plate and the image over the centre of the code. size is a fraction of the code's width (default 0.22). Use a high ecc (Q or H) so the obscured modules stay recoverable — <o-qrcode> forces ecc="H" internally when a logo is set and no explicit ECC would beat it.

Download button

Setting download (the suggested file name; an empty string uses qrcode.png) adds a button that exports a 2×-scaled PNG via Orion.qr.toBlob().

Payload presets

Orion.qr builds the exact payload string for common actions — the code itself is always plain text, so any of these can go straight into value.

Generate → scan round trip

Because <o-qrcode> and <o-scanner> share the same test suite, a code generated here can be read straight back with the pure-JS decoder — no camera required. Click "Scan it back" to render this code to an offscreen canvas and decode it with Orion.scanner.decodeImage().

Accessibility

The rendered <svg> gets role="img" and an aria-label (the label prop, or a generic "QR code" fallback) — screen reader users get a description, not the raw payload. The optional download button is a normal, keyboard-operable <button>.

Limitations

  • Kanji mode is not implemented — non-Latin/CJK text is encoded as UTF-8 byte mode, which is spec-legal but less space-efficient than Kanji mode for long Japanese text.
  • Structured Append (splitting one payload across multiple QR symbols) is not supported.
  • color/background are trusted CSS colour strings (not user text), rendered as SVG attributes; they are not sanitised beyond normal attribute escaping.

Frameworks

Set logo as a property (frameworks that pass objects as attributes will JSON-stringify them, which also works since it is declared as an Object prop). All other attributes are plain strings/numbers.
