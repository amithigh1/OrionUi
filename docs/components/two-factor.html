Two-factor authentication

Orion.totp (RFC 6238 TOTP over WebCrypto), <o-2fa-setup> (the enrollment wizard) and <o-2fa-verify> (the sign-in-time check). The code shown here is checked in your browser only for this demo — a real product must verify it server-side, against the secret the server stored at enrollment.

Try Orion.totp live

A fresh secret is generated below; the code refreshes every 30 seconds and updates as you watch — compare it with any authenticator app you scan the QR code with in the next section.

Backup codes — Orion.twofa

Orion.twofa.generateBackupCodes(n) is the small standalone helper <o-2fa-setup> itself uses for its "Backup codes" step — call it directly if you're building your own enrollment UI and just need the codes (each formatted XXXXX-XXXXX from crypto.getRandomValues).

<o-2fa-setup>

Method → set up → verify → backup codes → done. The verify step checks your code against the secret shown above using Orion.totp.verify (the built-in default when onVerify is omitted).

<o-2fa-verify>

The sign-in counterpart. This demo accepts the current TOTP code for the secret generated in the setup demo above (open both on the same page and copy the manual-entry code across, or just type the 6-digit code shown at the top of this page).
