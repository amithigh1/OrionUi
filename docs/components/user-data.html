User data

Per-user, persisted, cross-tab-synced stores for the small bits of state every admin app needs: Orion.recent, Orion.favorites, Orion.searchHistory, Orion.viewed, Orion.views (saved filters) and Orion.prefs, plus the widgets that display them. Everything lives under Orion.userdata.setUser(id)'s namespace so switching users switches the data too.

Recent items & favorites

Orion.recent.add(item) records the last-opened items (deduped, newest first); <o-favorite-button> toggles Orion.favorites for one item and <o-recent-list> / <o-favorites-list> render a store as a list (favorites are drag- and Alt+arrow-reorderable).

Search history

Orion.searchHistory.add(query, scope) remembers recent searches per scope (default 10, newest first, deduped case-insensitively).

Recently viewed — data-o-track-view

Mark any element data-o-track-view='{"id":…,"title":…}' (or a bare id string) and it records itself into Orion.viewed the first time it's at least 50% visible for data-o-track-view-delay ms (default 0 — scroll it out before the delay elapses and it won't record). It fires once per element and dispatches o-track-view with the recorded item. Scroll the card below into view and hold for a moment.

Saved views / filters

<o-saved-views> saves and reapplies arbitrary state (filters, sort, columns) per scope. Provide getState() to describe what "current state" means, and listen for o-apply to restore it.

Preferences

Orion.prefs is a flat key/value store, synced across tabs, with change notifications per key.

API

NamespaceMembers
Orion.userdatauser, setUser(id, { auto }), configure({ storage }), export(), import(data), clear(), onChange(fn({store,user,source})). Follows Orion.auth.setUser() automatically unless setUser was called explicitly.
Orion.recent / Orion.viewedadd(item) (id/url required), list({ type, limit }), get(id), remove(id), clear(type?), onChange(fn). viewed.track(item) is an alias of add; max 20 / 50 entries.
Orion.favoriteslist(), has(id), get(id), add(item), remove(id), toggle(item) → boolean, update(id, patch), reorder(ids), move(id, delta) → index, clear(), onChange(fn).
Orion.searchHistoryadd(query, scope = 'global'), list(scope, limit?), remove(query, scope), clear(scope?), onChange(fn). Max 10 per scope.
Orion.viewssave(scope, name, state, { isDefault, id }) → view, list(scope), get(scope, idOrName), rename, remove, setDefault(scope, idOrName|null), getDefault(scope), clear(scope?), onChange(fn).
Orion.prefsget(key, def), set(key, value) or set({...}), toggle(key), on(key|'*', fn(value, old, key)), all(), reset(key?), onChange(fn).

Every store's item shape is free-form but conventionally includes id, title (or name), url, icon, type and meta. Storage keys: orion:ud:<user>:<store>. Bus event: userdata:change { store, user, source } (source: local | remote | user).
