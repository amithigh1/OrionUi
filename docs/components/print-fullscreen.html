Print & Fullscreen

Orion.print() prints a single element (or the whole page) in a hidden iframe with your page's styles copied over — no print stylesheet gymnastics. Orion.fullscreen wraps the Fullscreen API with a CSS "pseudo fullscreen" fallback for iOS and blocked requests.

Print an element

data-o-action="print" with data-o-target prints just that element; from code, Orion.print(target, options) does the same and returns a Promise. Canvases are rasterized to images first.

Print the page

Orion.print() with no target prints the current page (window.print()), optionally injecting page-only CSS (margins, orientation).

      await Orion.print();                                    // print the page as-is
      await Orion.print(null, { landscape: true, margins: '12mm' });
      await Orion.print('#report', { pageSize: 'A4', beforePrint: () => chart.resize() });

Print-only classes

ClassEffect
.o-print-hide / .o-no-printHidden only while printing.
.o-print-onlyHidden on screen, shown while printing.
.o-print-breakForces a page break before the element.

Fullscreen

data-o-action="fullscreen" toggles fullscreen on data-o-target (or the whole page); the trigger's maximize/minimize icon and aria-pressed update automatically. Escape always exits, including the CSS fallback.

API

MemberDescription
Orion.print(target?, options) → Promise<boolean>target: selector/Element/HTML string, or omit for the page. Options: title, landscape, margins (mm|{top,right,bottom,left}), pageSize, styles, css, bodyClass, beforePrint({window,document}), afterPrint().
Orion.print.html(target, options) → stringThe full HTML document that would be printed (preview / tests), without opening a print dialog.
Orion.fullscreen.enter(el?, { pseudo, navigationUI }) → Promise<boolean>Falls back to CSS pseudo-fullscreen when the API is unavailable, refused, or there's no user-gesture context.
Orion.fullscreen.exit() / .toggle(el?, opts?)Toggle also accepts options forwarded to enter().
Orion.fullscreen.isActive / .element / .pseudo / .supportedRead-only state getters.
Orion.fullscreen.onChange(fn({ active, element, pseudo })) → off()Also bus event fullscreen:change and DOM event o-fullscreen on the element (or document when none).

Actions

AttributeNotes
data-o-action="print"data-o-target (element to print, page if omitted), data-o-print-title, data-o-landscape, data-o-print-margins, data-o-print-size.
data-o-action="fullscreen"data-o-target (defaults to document.documentElement); the trigger needs an <o-icon name="maximize"|"minimize"> (or .o-icon-maximize/.o-icon-minimize) child to get the automatic icon swap.

CSS: .o-is-fullscreen on the fullscreen element (native or pseudo), html.o-has-fullscreen while any element is fullscreen.
