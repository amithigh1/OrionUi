PWA

Orion.pwa registers the orion.js bundle itself as a service worker (no separate file to ship), watches for updates, captures the install prompt, and drives a manifest — all from one JS API. Orion.notify adds browser notifications with an in-app toast fallback.

Requires HTTPS or localhost
Service workers only run on secure origins. This page's demos work here because the docs are served from http://127.0.0.1, which browsers treat as a secure context.

Registration

Pass precache (URLs to cache on install), routes (runtime caching per pattern) and an optional offlinePage. The scope defaults to the script's own folder — pass scope to widen it (the page must be served with a Service-Worker-Allowed header reaching that scope; build/serve.mjs already sends one for any URL ending in orion.js).

Update flow

When a new version installs while an old one still controls the page, Orion shows a toast ("A new version is available · Reload") unless toast: false. Listen for onUpdate to build your own banner and call applyUpdate() to activate the waiting worker (the page reloads once it takes control).

      await Orion.pwa.register({
        precache: ['./', './app.css'],
        offlinePage: './offline.html',
        routes: [
          { match: '/api/', strategy: 'network-first', timeout: 4000 },
          { match: '*.png', strategy: 'cache-first', maxEntries: 60, maxAge: '30d' },
          { match: '/api/', methods: ['POST', 'PUT', 'PATCH', 'DELETE'], queue: true },
        ],
        toast: false,          // build a custom prompt instead
      });
      Orion.pwa.onUpdate(({ registration }) => showMyUpdateBanner(() => Orion.pwa.applyUpdate()));
      document.addEventListener('o-sw-ready', () => console.log('ready to work offline'));

Caching strategies

Set per-route with strategy (default network-first for navigations, network-first for other routes unless queue: true which defaults to network-only). Routes also take cache (name), maxEntries, maxAge, methods and timeout (network-first only).

StrategyBehavior
network-firstTry the network; fall back to cache on failure or after timeout ms (default 4000). Best for HTML/API responses that should stay fresh.
cache-firstServe from cache when present, else fetch and cache. Best for versioned assets (fonts, hashed bundles).
stale-while-revalidateServe the cached copy immediately (if any) while refetching in the background for next time.
network-onlyAlways hit the network (still lets a queue: true route capture failures for offline replay).
cache-onlyOnly ever serve from cache; 504 when missing.

See Offline for the mutation queue (queue: true routes) and <o-offline-banner>.

Install prompt

<o-install-prompt> shows automatically when the browser fires beforeinstallprompt (Chromium) or on iOS Safari (Add to Home Screen instructions), and hides once installed or dismissed. Use force to preview it regardless of browser support, and mode to preview a specific state.

Browser notifications

Orion.notify() requests permission on first use (call it from a click handler — browsers require a user gesture), shows a native notification when granted, and falls back to an in-app toast otherwise (denied, unsupported, or fallback forced).

Manifest

Orion.pwa.manifest() builds a manifest.json as a blob URL and injects <link rel="manifest"> / <meta name="theme-color"> — no static file needed. A monogram icon is generated when none is supplied.
