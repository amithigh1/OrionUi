Stat

<o-stat> is a KPI tile: a formatted value (currency, percent, compact, bytes, duration…), a delta arrow colored by whether the direction is actually favorable (not just up/down), an optional sparkline and progress-to-goal, and an animated count-up. <o-stat-group> lays out a responsive row of them with dividers. <o-countup> / Orion.countUp() animate any number on their own.

Overview

The minimum viable stat is a label and a value. Add delta (with period) for the comparison row, and icon/color for the top-corner glyph.

Value formatting

format covers the usual KPI shapes: currency, percent (a ratio out of 100 — 12.4 renders "12.4%"), compact, bytes, duration (milliseconds) and raw (no formatting, just prefix/suffix). The same formatter is available standalone as Orion.countUp.format(value, opts).

Delta & sparkline

delta-good decides which direction is favorable — a rising refund rate is bad news, so it sets delta-good="down" to keep the arrow red. sparkline accepts a plain array (or a JSON string, for the HTML attribute); sparkline-type switches line/area/bar. Hover a sparkline for the per-point tooltip.

Progress to goal

Set goal to show progress as a bar (goal-type="bar", default) or a ring that replaces the icon slot (goal-type="ring").

Count-up

countup on <o-stat> animates from 0 to value the first time the tile scrolls into view (and re-animates on later value changes). <o-countup> is the same animation as a standalone element; Orion.countUp(el, to, opts) drives any element imperatively. All three honor prefers-reduced-motion (and the in-app override, html.o-motion-reduce) by jumping straight to the end value.

<o-stat-group>

A responsive row: columns auto-fit down to min, with dividers between tiles (plain removes the shared card chrome and dividers, useful when each <o-stat> already has its own card).

Clickable stat

Set href to make the whole tile a real, keyboard-focusable link.

JS API & events

Keyboard & accessibility

A href stat is a real anchor (.o-stat-link, tab-focusable, activates on Enter) with a computed aria-label combining the label, value and delta text. The animated digits are marked aria-hidden; a visually-hidden sibling always holds the final, stable value so screen readers never read intermediate tween frames — <o-countup announce> additionally calls Orion.announce() with the finished value. The goal bar/ring is role="progressbar" with aria-valuenow/aria-valuetext ("42% of 80 goal" or "Goal reached"). The built-in sparkline (used when the charts package isn't loaded) is role="img" with an aria-label summarizing the trend, not per-point SVG. Delta direction is never color-only: an arrow icon and screen-reader text ("Up 12.4%, favorable") always accompany it.

Orion.countUp(target, to, opts) & Orion.countUp.format(value, opts)

opts: { from, duration, format, decimals, currency, prefix, suffix, compact } (format may also be a function (n) => string). Returns { promise, cancel() }; if from is omitted it is parsed out of the element's current text, so re-triggering continues from what's on screen. Orion.countUp.format is the same value formatter used everywhere above, usable standalone.
