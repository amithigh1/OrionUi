Dock

<o-dock> arranges <o-dock-panel> children into an IDE-style workbench: a start sidebar, main area, end sidebar and bottom panel, each a resizable, minimizable tab group built on <o-split>. Drag a tab to move it between regions, float it into its own window, or drive everything from the panel menu.

Explorer / editor / terminal / properties

Drag a tab onto another region (or off the dock entirely to float it). Each region's menu offers Move to…, Float, Minimize/Expand, Maximize/Restore and Close — the keyboard path for everything a drag can do (also reachable with Shift+F10 on a focused tab). Double-click a gutter to snap a sidebar to its rail.

Layout persistence

With layout-key set, every structural change (move, float, minimize, maximize, close, or a manual gutter drag) is saved to localStorage and restored automatically next time. Read or apply a snapshot directly with getLayout() / setLayout().

Attribute / propertyTypeDescription

Methods

MethodDescription
getLayout() → objectSerializable snapshot: panel placement/order/closed, region sizes, minimized regions, the maximized region and float geometry.
setLayout(layout)Applies a snapshot from getLayout().
reset()Discards the persisted layout and rebuilds from the declared markup.
movePanel(id, region, index?)Docks a panel into start | center | end | bottom.
float(id, { x, y, w, h }?) / dockBack(id)Detach into (or return from) a floating window.
minimize(region) / expand(region) / toggleMinimize(region)Collapse/restore a region's rail (not center).
maximize(region) / restore() / toggleMaximize(region)Hide every other region so one fills the dock.
close(id) / open(id)Hide a panel (cancelable o-close) / restore it.
getPanels() → array{ id, title, icon, region, closed, floating, active } for every panel.
openPanelsMenu(anchor?)Opens the checklist menu that closes/restores any panel.

Responsive

Below ~600px wide, every open panel collapses into a single tab strip (resize this page or the demo container to see it) — region-specific actions (move, float, minimize, maximize) are hidden in favor of a plain Close, since dragging between regions and floating windows don't fit a narrow screen.
