Number & currency

<o-number> groups digits with the correct locale separators while you type, formats currency/percent/unit values, and clamps to min/max/step. A data-o-number behavior does the same formatting for a plain input that submits a clean number.

Basic

Currency & locale

The grouping and decimal separators, and the currency symbol's position, follow the given locale (or the page locale). Grouping is applied live as you type, not only on blur.

Percent

Stepper styles & wheel

controls: stepper (default, one column), split (- / + on each side) or none. wheel lets the mouse wheel step the value while the field is focused. Hold a stepper button to repeat.

Behavior for plain inputs

When you cannot use a custom element (a third-party form library, server-rendered markup), apply data-o-number to a plain <input>. It formats live and adds a hidden input carrying the clean numeric value when data-o-number-name is set.
