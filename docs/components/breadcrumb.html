Breadcrumb

<o-breadcrumb> renders a trail from a JSON items array (reusing the static .o-breadcrumb CSS already in core), with a choice of separators, an overflow "…" menu once the trail is longer than max, and an auto mode that derives the trail from the active sidebar link or the URL path.

Basic

Separators & icons

Overflow collapse

When the trail is longer than max, the middle crumbs collapse into a "…" button with a floating menu (arrow keys work, Escape closes it).

Auto mode

auto (with no items) builds the trail from the active .o-sidebar link chain when one exists on the page, otherwise from the URL path segments. It re-syncs on o-menu-active and navigation events, so it tracks a single-page app's sidebar automatically.
