Animation & Transitions

A small promise-based animation API on top of the Web Animations API. Every animation is automatically disabled when the user prefers reduced motion.

Presets

      await Orion.animate(el, 'zoomIn', { duration: 200, easing: 'ease-out', delay: 0 });
      await Orion.animate(el, [{ opacity: 0 }, { opacity: 1 }], { duration: 300 });   // custom keyframes
      Orion.anim.presets.myEffect = [{ transform: 'rotate(0)' }, { transform: 'rotate(360deg)' }];
      Orion.anim.reducedMotion();   // true when the user prefers reduced motion

Collapse (height)

      await Orion.collapse(el);          // toggle
      await Orion.collapse(el, true);    // show
      await Orion.collapse(el, false);   // hide

CSS enter/leave transitions

Orion.transition(el, 'enter'|'leave', { name }) toggles {name}-{phase}-from, -active and -to classes (Vue-style). o-fade is built in.

      .my-slide-enter-active, .my-slide-leave-active { transition: transform .25s, opacity .25s; }
      .my-slide-enter-from, .my-slide-leave-to { transform: translateY(10px); opacity: 0; }

CSS animation classes

.o-animate-spin, -pulse, -ping, -bounce, -shake, -fade-in, -slide-up, -zoom-in, .o-hover-lift, .o-transition. Keyframes are available as o-spin, o-pulse, o-shimmer and others for your own CSS.
