One file. Every admin component you need.

Orion Admin is a complete admin UI toolkit that ships as a single JavaScript file. It covers layout, forms, data tables, charts, calendars, editors, uploads, maps and more. Drop in one <script> tag and use it from plain HTML, React, Vue or Angular.

Quick start

Add the script and start writing markup. The CSS is embedded in the file and injected automatically.

      <!doctype html>
      <html lang="en">
      <head>
        <script src="https://cdn.jsdelivr.net/npm/orion-admin/dist/orion.min.js"></script>
      </head>
      <body class="o-container o-py-6">
        <button class="o-btn o-btn-primary" onclick="Orion.toast.success('Hello from Orion!')">Say hello</button>
        <o-datatable id="users"></o-datatable>
      </body>
      </html>

Why Orion Admin

Truly single-file
JS, CSS and icons in one file, via CDN, npm or download. Custom builds keep only what you use.
Framework-agnostic
Native Custom Elements and attribute behaviors work in HTML, React, Vue, Angular and Svelte.
Themes built in
Light, dark and auto modes, high contrast, font scaling, runtime brand colors, multi-tenant and white-label.
Accessible
WAI-ARIA patterns, full keyboard support, focus management, screen-reader announcements and reduced motion.
Global-ready
i18n with plurals, locale-aware numbers, dates and currency, and RTL support everywhere.
Yours to own
MIT licensed, readable source, no build step required, no vendor lock-in.
